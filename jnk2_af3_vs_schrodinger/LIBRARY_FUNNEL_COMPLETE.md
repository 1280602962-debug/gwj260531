# JNK2 丙烯酰胺发现库漏斗（完善版 v1.0）

**回答三个核心问题：**  
1）几千个商业库够不够？  
2）能否像 JACS/BTK 那样从大库取胺再装丙烯酰胺？  
3）AF3 只能上服务器时，薛定谔预筛如何写进流程才不违背 Phase 0 结论？

**依据：** Phase 0 AF3 vs Glide 对比；PaperSpine 确认贡献（框架必达 + 化学升级）；靶点 8ELC / Cys116。

---

## 0. 总判断（先读这段）

| 问题 | 结论 |
|------|------|
| 只下 Enamine ~4k acrylamide 能出 hit 吗？ | **有可能，但偏“已知化学型附近”**；适合快速验证漏斗，不利于新骨架 |
| 要不要做 BTK 式「大库胺 → 装丙烯酰胺」？ | **可以，且适合你们要新骨架**；注意这是 **JNK2 发现库枚举**，不是建 BTK 库 |
| ChEMBL ~2.9M 类药分子能用吗？ | **能作底物池**；不要 2.9M 全对接，要先切胺、装弹头、合成性/邻域过滤 |
| 先薛定谔后 AF3？ | **可以，作为算力分层**；但 Glide **只能粗筛、阈值要松**，最终排序仍以 **AF3 mPAE** 为准（Phase 0：Glide 弱于 AF3，二者不可互换） |

**完善流程一句话：**

> 多源建库（商业 acrylamide + ChEMBL/ZINC 胺装丙烯酰胺）→ 合成性与双轨化学过滤（YL5084 邻域 / 新骨架）→ 薛定谔共价对接粗缩库 → AF3 mPAE 精排与门控 → Glide pose QC / 人工检查 → 可采购或可合成清单 → 湿实验。

## 1. 为什么“几千个”和“百万级”都要出现在设计里

### 1.1 几千个商业 acrylamide（Enamine sACR 等）

**优点：** 可买、可复现、立刻能跑通框架。  
**局限：** 化学空间偏供应商已有共价集，**不一定覆盖 YL5084/56d 邻域，更难出真正新骨架。**  
**定位：** **轨道 A（可采购快车道）**，不是唯一发现引擎。

### 1.2 ChEMBL / ZINC 级大库 → 胺 → 丙烯酰胺（学 BTK 的“枚举逻辑”，不抄 BTK 靶点）

JACS 前瞻筛的关键思想是：

1. 固定 **Cys + acrylamide** 化学；  
2. 从可合成胺类骨架扩展；  
3. 在统一 warhead 下做大规模虚筛。  

你们可迁移为：

```
ChEMBL 类药子集 / ZINC in-stock
  → 优选一级/二级胺（可酰化位点）
  → 枚举装上丙烯酰胺（或 N,N-二甲氨基丙烯酰胺等文献常用变体）
  → 合成性过滤（SA Score / Enamine REAL 可合成 / 反应模板匹配）
  → 双轨化学门控（见 §3）
  → 进入对接漏斗
```

**定位：** **轨道 B（虚拟扩展 / 新骨架）**。规模目标不是 2.9M 全跑，而是过滤后 **5k–50k 丙烯酰胺枚举体**，再薛定谔缩到 **500–2k**，再 AF3。

## 3. Stage 细节（可写进方法学）

### Stage 1B —「胺 → 丙烯酰胺」枚举（BTK 逻辑的正确用法）

**输入池建议（务实，不要 Raw 2.9M 全进）：**

| 来源 | 用法 |
|------|------|
| ChEMBL 类药 / 有实测活性的小分子 | 优先：已有胺、杂环丰富 |
| ZINC in-stock / agent | 提高可采购性 |
| Enamine BB / REAL amines | 提高可合成性 |

**胺选择规则（示例）：**

- 至少 1 个可酰化的 **一级或二级胺**（芳香胺反应性需单独评估；脂肪胺优先）  
- 排除：已有强电泳基团、多胺难控位点、肽、金属螯合剂  
- 物化：装弹头后 MW 目标约 **350–650**（对齐 YL5084 窗口）

**装弹头：**

- 主变体：标准丙烯酰胺 `CH2=CH–C(=O)–NR`  
- 可选变体：`Me2N–CH2–CH=CH–C(=O)–NR`（JNK-IN/YL 系列常见）  
- 每个胺位点生成 1–2 个产物；记录 **反应位点原子映射**（供 AF3 bondedAtomPairs）

### Stage 2 — 合成性

至少满足其一再进对接：

1. **可采购**（Enamine/Molport 有货）  
2. **一步酰化可达**（胺 + 丙烯酰氯/活化酯模板）  
3. **SA Score** 低于项目阈值（需在试点集上标定）  
4. 落入 **Enamine REAL** 或内部反应枚举空间  

没有合成性标签的虚拟分子，最多进 AF3 的 **探索配额**（如 ≤20%），避免清单不可交付。

### Stage 3 — 双轨化学（呼应“类似 YL5084 / 新骨架”）

| 仓 | 目的 | 过滤思路 | 下游权重 |
|----|------|----------|----------|
| **Track-Sim** | 提高出活性概率 | 对 YL5084/YL2056/56d 指纹相似；保留关键药效团 | 湿实验优先 |
| **Track-Novel** | 化学升级/新骨架 | 低 Tc；允许不同铰链结合核，但 warhead 几何仍对准 Cys116 | AF3 配额可提高 |

**禁止**把两仓混成一个 GScore 榜再取 Top——Phase 0 已证明排序器会偏。

### Stage 4 — 薛定谔粗筛（在 AF3 限流下的正确姿势）

**允许说的话：**  
“因 AF3 需服务器，先用 Schrödinger covalent docking 将枚举库缩至可上机规模。”

**必须同时写的限制（否则与 Phase 0 矛盾）：**

1. Glide 是 **吞吐过滤器**，不是最终活性排序器；  
2. 截断要 **松**（例如保留 Top 5–10% 或几何合格全集，而不是只留 GScore Top 50）；  
3. **Track-Novel / 56d 邻域** 提高进入 AF3 的比例；  
4. 最终采购/合成名单以 **AF3 mPAE** 为主，Glide 作 pose QC；  
5. 记录：有多少 AF3 高分被 Glide 丢掉（应用 Phase 0 的 14 个假阳性/56d 教训做事后审计）。

**建议规模换算：**

| 进入 Stage 4 | 出 Stage 4（进 AF3） |
|--------------|----------------------|
| 5,000 | 500–1,000 |
| 20,000 | 1,000–2,000 |
| 50,000 | 2,000–3,000（分批 AF3） |

### Stage 5 — AF3 精排

- 共价键：Cys116-SG ↔ acrylamide β-C（FASTA 编号注意 116 vs 113）  
- 主指标：**mPAE**  
- 试点阈值：可先用 Phase 0 经验（active ~0.8–0.9 Å；decoy 最好 ~1.25 Å）→ 前瞻先用 **≤1.05–1.20 Å** 再按首轮湿实验回调  
- **不要**用 ipTM 单独 gate  

### Stage 6–7 — QC 与交付

- 人工面板：每轨各取 Top 20–30  
- 输出两张表：`purchase_list.csv`、`synthesize_list.csv`  
- 湿实验最小集：kinact/KI（JNK2/JNK1）、C116S、washout

## 4. 和“只下载几千个库”的关系：两阶段立项叙事

写报告时建议拆成：

**Phase F（框架验证，可用商业 ~4k）：**  
证明漏斗可复现：建库→Glide 粗筛→AF3 精排→清单。命中不是唯一 KPI。

**Phase C（化学扩展，启用 ChEMBL 胺装弹头）：**  
在框架冻结后扩化学空间，追求 Track-Novel + Track-Sim 双交付。

这样审稿人不会追问“为什么不一开始就 2.9M 对接”，也不会觉得你们只会下载供应商小板。

## 5. 风险与缓解

| 风险 | 缓解 |
|------|------|
| Glide 粗筛丢掉 AF3 真阳性 | 阈值放宽；双轨配额；抽检 Glide 中低分但几何合格分子送 AF3 |
| 胺装弹头产生不可合成 junk | 强制合成性/REAL/可买标签 |
| 枚举爆炸 | 限制每胺 1–2 warhead；先 ChEMBL 有活性子集再扩 ZINC |
| 与 YL5084 太像被审稿人说缺新意 | Track-Novel 单独成图/成表 |
| 把 ChEMBL 2.9M 写成已对接 | 文中明确“底物池，非对接规模” |

## 6. 开题/方法可用的标准段落（可直接改写）

> 鉴于商业丙烯酰胺 plated 库规模多为千级，虽利于可采购验证，但不足以覆盖新骨架探索。本研究采用双源建库：一方面纳入 Enamine 等可购丙烯酰胺子集；另一方面以 ChEMBL/ZINC 类药分子为底物，筛选可酰化胺并枚举丙烯酰胺加合物（借鉴共价虚筛中“统一 warhead、扩展骨架”的策略，而非构建 BTK 专用库）。全部产物经合成性与双轨化学过滤（YL5084/56d 邻域 vs 低相似新骨架）后，先以 Schrödinger 共价对接在 8ELC/Cys116 上作高通量粗筛以匹配本地算力，再将缩库后的候选提交 AlphaFold3 共价共折叠，以 mPAE 作为主排序与门控指标（Phase 0 已表明 mPAE 富集显著优于 GlideScore，且二者排序不可互换）。最终结合几何 QC 与人工评审形成可采购/可合成清单，进入 kinact/KI 与 C116S 验证。疾病适应症不作为本阶段主要声称。

## 7. 本周可执行清单

1. 确定底物池：ChEMBL 类药下载方式 + 是否叠加 ZINC in-stock  
2. 写清胺 SMARTS + 丙烯酰胺枚举规则（含原子映射）  
3. 定合成性门槛与双轨 Tc 窗口  
4. 定 Glide→AF3 缩库比例（建议先 20k→1–2k）  
5. 商业 ~4k 作为并行快车道，先跑通一次全漏斗试点
