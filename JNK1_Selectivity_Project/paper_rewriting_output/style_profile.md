# Style Profile

## Target voice

- Formal scientific English; contribution-first; reviewer-aware.
- Dense but not promotional; numbers over adjectives.
- Chinese OK for planning/UI; manuscript `en`.

## Section proportions (recommended)

| Section | Role | Approx. weight |
|---------|------|----------------|
| Introduction | Biology + homology challenge + dual RQ | 15% |
| Methods | Pipeline gates + thresholds + purchase design | 25% |
| Results | ML / dock / **selectivity failure** / MD / shortlist | 35% |
| Discussion | Claim boundary + kinome caveat + future work | 15% |
| Conclusion | Restate contribution only | 5% |

## Figure budget (aligned with prior selection advice)

| Keep in main text | Role |
|-------------------|------|
| Funnel (ML→157→25→16→purchase) | Pipeline overview |
| Model comparison R² / decoy FPR | ML credibility |
| Redock + Δsel direction accuracy | Docking validity + selectivity failure |
| ADMET F7 five-panel (A–E) | Drug-likeness gate |
| Hinge occupancy + RMSD–hinge QC | MD pose QC (not selectivity proof) |
| Optional: 690/2157 dock poses | Candidate illustration |

Drop redundant RMSD bar chart if heatmap kept.

## Claim lexicon

| Prefer | Avoid |
|--------|-------|
| JNK-family binder | JNK1-selective hit (unless IC50 proves) |
| pose-credible shortlist | MD-confirmed selective |
| computational selectivity predictors failed | we achieved selectivity computationally |
| kinome selectivity not assessed | kinase-selective (ambiguous) |
