# JNK2 选择性抑制剂项目 — 五阶段决策脉络

本文档记录从文献整理到最终方法学选型的完整推理链，供方案、主表与计算流程对照使用。

**最终决策：** JNK2 选择性**共价**抑制剂 + **DFG-in（8ELC）** 主筛 + 可选 AF3；**DFG-out（3NPC）仅作认知补充，不作共价主筛受体。**

---

## 阶段 1：文献整理

### 做什么

系统整理 JNK2 **共价抑制剂**与**可逆抑制剂**，逐条核对：

- 生化/细胞活性（IC50、kinact/KI 等）
- 共晶结构编号（PDB）
- 选择性机制（是否有 JNK1/2/3 对比及结构解释）

### 怎么判断质量

不以「活性表行数多」为准，而以两条标准筛锚点：

1. **是否有实验共晶结构**
2. **是否有明确的亚型选择性结构解释**（而非仅 kinome 或单一 IC50）

### 得到的锚点

| 化合物 | PDB | 构象 | 路线 |
|--------|-----|------|------|
| YL2056 | **8ELC** | DFG-in | 共价 Cys116 |
| 26k | **4WHZ** | DFG-in | 可逆，Leu106 后口袋 |
| BIRB796 | **3NPC** | **DFG-out** | 可逆 Type II |

### 本阶段结论

JNK 亚型选择性**有结构生物学依据**，是「共晶 + 机制」支撑的结论，不是把活性数字堆在一起。

同时初步看出：**共价 hit 的共晶都在 DFG-in（如 8ELC）；BIRB796 在 DFG-out（3NPC）且为可逆**，两条线在结构类型上已分叉——为阶段 2、4 的「构象不可混用」埋下线索。

---

## 阶段 2：拓展构象认知（DFG-out）

### 做什么

补充 **3NPC（JNK2 DFG-out 构象）** 与 **BIRB796**，理解 Type II 可逆抑制剂为何更偏 JNK2。

### 中文概念对照

| 术语 | 含义 |
|------|------|
| **DFG-in（DFG 内收）** | DFG 基序收在活性口袋内，配体主要占据标准 ATP 口袋（8ELC、4WHZ 属此类） |
| **DFG-out（DFG 外摆）** | 苯丙氨酸翻出，铰链后方腾出**扩展口袋**，配体更长，占 ATP 区 + 后部（3NPC / BIRB796 属此类） |

### 与 DFG-in + Leu106 轴的对照

| | DFG-in 路线 | DFG-out 路线 |
|--|-------------|--------------|
| 代表结构 | 8ELC、4WHZ | 3NPC |
| 代表化合物 | YL2056、26k、YL5084、56d | BIRB796 |
| 结合逻辑 | 标准 ATP 口袋 + **Leu106 后口袋 fit** | **外摆构象 + 扩展后口袋** |
| 抑制剂类型 | 共价（Cys116）或可逆 DFG-in | **可逆 Type II** |

### 本阶段结论

这是**两条正交路线**：

- **Leu106 / Ile106** 后口袋差异在两条线上都可能贡献选择性；
- 但**受体构象、配体长度、设计逻辑不同**，不能混用——尤其不能把 3NPC 当作共价 Cys116 筛选的模板。

---

## 阶段 3：机制归纳（三大原因）

JNK1 与 JNK2 ATP 口袋序列约 **98% 相同**，亚型选择性主要来自以下三类结构因素（可单独或叠加）：

### 原因一：Leu106 / Ile106 后口袋匹配（共价 + 可逆通用主轴）

- JNK2、JNK3：**Leu106**，后口袋较大，深芳环 / 特定 scaffold 可 fit  
- JNK1：**Ile106**，侧链更小，同一 scaffold 易发生**位阻冲突** → JNK2/3 优先  

**证据：** 4WHZ（26k）、8ELC（YL2056）、Wydra 可逆系列 21b/51d（148×～>340× vs JNK1）

### 原因二：DFG-out 扩展口袋（ mainly 可逆 Type II）

- DFG **外摆**后形成额外疏水腔；BIRB796 用长配体填满  
- JNK2 有实验 DFG-out 共晶；JNK1/JNK3 同源模型中该口袋更小 → BIRB796 偏 JNK2  

**证据：** 3NPC + MedChemComm 2016 对接与活性  

**注意：** 此机制解释的是 **BIRB796 类可逆抑制剂**，不是 Cys116 丙烯酰胺共价结合。

### 原因三：P-loop 及主链动态（ mainly 共价 kinact/KI 放大）

- 共价效率 = **非共价预定位（KI）× 成键速率（kinact）**  
- JNK2 的 P-loop（如 Val54 主链）相对 JNK1 **更易移动**，有利于 warhead 接近 Cys116  
- JNK1 中 Arg50–Glu109 盐桥等限制 P-loop → **kinact/KI(JNK2)/kinact/KI(JNK1) 可差约 20 倍**（YL5084）  

**证据：** Lu 2023 共晶 + 分子动力学；与原因一叠加，共价选择性往往强于单纯可逆 IC50 差异。

### 本阶段结论

三条机制**不互相替代**：

- 做 **DFG-in 共价**：主轴是 **原因一 + 原因三**  
- 理解 **BIRB796**：主轴是 **原因二**  
- 共价筛选若换用 DFG-out 受体，**原因二的几何前提与原因三所需的 Cys116–warhead 关系均对不上**（见阶段 4）

## 阶段 4：路线比较（可逆 vs 共价）与为何不用 DFG-out 主筛共价

### 4.1 可逆 vs 共价（DFG-in 框架内）

| 维度 | 可逆（DFG-in） | 共价（DFG-in + Cys116） |
|------|----------------|-------------------------|
| 结构锚点 | 4WHZ（26k）、51d 叠合逻辑 | **8ELC**（YL2056/YL5084） |
| 选择性倍数 | 21b **148×**、51d **>340×** vs JNK1 | YL5084 kinact/KI **~21×**；56d JNK2/3 >> JNK1 |
| 结构解释 | 直接（后口袋 fit） | 共晶 + Leu106 + P-loop |
| 实验负担 | 相对轻（三亚型 IC50） | 较重（kinact/KI、C116S、洗脱、IPMS 等） |
| 探针成熟度 | 可逆系列数据较完整 | **严格 JNK2-biased 共价 probe 仍稀缺** |

**结论：** 若目标仅为**高倍数 JNK2/3 vs JNK1 可逆先导**，DFG-in 可逆 + 4WHZ 逻辑更轻；若目标为**不可逆占用 Cys116 的 JNK2 探针**，共价 + 8ELC 仍是主路径，但验证链更长。

### 4.2 为何不能在 DFG-out（3NPC）上主筛共价抑制剂

以下六点构成「禁用 3NPC 作共价主受体」的完整理由（`config/targets.yaml` 与筛选方案已采纳）。

#### （1）共价证据链都在 DFG-in，不在 DFG-out

| 化合物 | 验证方式 | 构象 |
|--------|----------|------|
| YL2056 / YL5084 | **8ELC 共晶**，Cys116 共价键 | DFG-in |
| 56d | 叠合 16a + 3V6S + 4WHZ | DFG-in |
| JNK-IN-7/8 | 3V6S 等共晶 | DFG-in |
| BIRB796 | **3NPC**，可逆结合 | **DFG-out**，**无** Cys116 共价 |

用 3NPC 筛丙烯酰胺库，等于用**可逆、外摆构象**预测**共价、内收构象**的结合——**模板与产物类型不匹配**。

#### （2）口袋形状不同，Cys116 与丙烯酰胺的相对几何会变

共价 Michael 加成不只看「能否进口袋」，还看：

- Cys116 巯基是否接近丙烯酰胺 **β 碳**
- 加成角度是否合理  
- P-loop 等是否允许 warhead 到位  

DFG-out 时苯丙氨酸外摆，激活环与后部口袋通路改变 → **同一配体在 8ELC 与 3NPC 下 Cys116–warhead 相对位置不同**。  
在 3NPC 上的 pose **不能**作为 8ELC 式共价 pose 用于排序、AF3 约束或 RMSD 对照。

项目内 **56b vs 56d** 已说明：scaffold 相近，仅 linker/丙烯酰胺矢量不同，共价效率可差 **>10 μM vs 25 nM**；换整条构象（DFG-out），几何偏差通常更大。

#### （3）DFG-out 是可逆 Type II 逻辑，不是共价设计逻辑

- **BIRB796**：靠 DFG-out **扩展口袋 + 长配体可逆占据** → 高亲和力、JNK2 偏好  
- **YL5084 / 56d**：先在 **DFG-in** 下 fit Leu106 后口袋 → 再让丙烯酰胺够到 Cys116 → **预定位 + 共价**

设计起点、readout（IC50 vs kinact/KI）、受体结构**均正交**，不能互相替代。

#### （4）混用构象导致计算与实验假结果

| 风险 | 说明 |
|------|------|
| **假阳性** | DFG-out 对接看着能结合，DFG-in/细胞内构象下够不到 Cys116 或 kinact 极低 |
| **假阴性** | 8ELC 几何下优秀的 YL5084 类分子，在 3NPC 上打分差，被错误淘汰 |
| **AF3 / Glide 共价** | `bondedAtomPairs` 按 **DFG-in + Cys113/116** 设定；换 DFG-out 结构则约束与受体不一致 |

#### （5）BIRB796 仍是有价值的「对照」，但不是共价主筛模板

| 用途 | 是否合适 |
|------|----------|
| 理解 JNK2 为何能结合 Type II 长配体 | ✅ |
| 可逆 DFG-out 先导设计（另开可逆课题） | ✅ |
| **Cys116 丙烯酰胺共价库主筛** | ❌ |
| YL5084 pose 与 8ELC RMSD / Phase 0 gate | ❌（应只用 8ELC） |

#### （6）项目配置与阶段 1–3 结论一致

- 主受体：**8ELC（DFG-in）**  
- **禁用 3NPC（DFG-out）** 作共价对接排名  
- DFG-out 选择性归入阶段 2–3 的**机制认知**，不进入共价 hit 发现流程  

### 4.3 本阶段总结论

| 路线 | 决策 |
|------|------|
| **共价主筛** | **DFG-in + 8ELC** |
| **可逆高倍数** | **DFG-in + 4WHZ 逻辑**（21b/51d） |
| **DFG-out 认知** | **3NPC / BIRB796**，理解 Type II，**不作共价主筛** |
| **DFG-out 共价** | **不可行或不值得作主线**（证据缺失 + 几何不一致 + 假结果风险） |

## 阶段 5：方法学锚定（AF3 共价共折叠）

### 依据

Shamir 等（COValid 思路）：在 BTK 等激酶上，**AF3 共价共折叠 + mPAE 排序**在前瞻性筛库中有效，并与共晶高度一致（亚埃级回证）。

### JNK2 是否具备类似条件

| 条件 | JNK2 情况 |
|------|-----------|
| 单一位点共价半胱氨酸 | **Cys116**（JNK1/2 保守） |
| 较深 ATP 口袋 | 有（8ELC 共晶） |
| 统一 warhead | **丙烯酰胺**（与文献共价系列一致） |
| 校准用阳性对照 | **YL5084**（kinact/KI JNK2/JNK1 ~21×） |
| 校准用 decoy | 性质匹配丙烯酰胺，Tc < 0.4 |

### 与阶段 4 的衔接（为何 AF3 也绑定 DFG-in）

AF3 Phase 0 gate 要求：

- 蛋白输入：激酶域 FASTA（Cys116 → 构建内 **113 位**）  
- 共价约束：Cys–SG ↔ 丙烯酰胺 β-C  
- 阳性对照 pose 对照：**8ELC**（DFG-in），**非 3NPC**  

若改用 DFG-out 结构作 AF3 输入，**与 YL5084/8ELC 校准体系不一致**，gate 结果无法指导 DFG-in 共价库筛选。

### 本阶段最终决策

```
文献锚点（阶段 1）
    → 构象分叉：DFG-in vs DFG-out（阶段 2）
    → 三大机制，共价主轴 = Leu106 + P-loop（阶段 3）
    → 共价主筛仅 DFG-in/8ELC；DFG-out 不主筛共价（阶段 4）
    → 可选 AF3，但必须过 Phase 0 gate（阶段 5）

最终路线：JNK2 选择性共价抑制剂
         + DFG-in（8ELC）主筛
         + 可选 AF3（mPAE + decoy 富集）
         + DFG-out（3NPC）仅作 Type II 可逆认知补充
```
