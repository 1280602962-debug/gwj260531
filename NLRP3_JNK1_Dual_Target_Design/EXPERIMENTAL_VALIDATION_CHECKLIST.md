# NLRP3 / JNK1 双靶点药物：实验验证清单

> 本清单与 [`NLRP3_JNK1_Dual_Target_Design_Considerations.md`](./NLRP3_JNK1_Dual_Target_Design_Considerations.md) 配套使用。  
> 实验设计原则基于靶点占据理论 [34,35]、组合药效学 [39,40] 及双靶点药物发现一般规范 [13,14,26]。

---

## 使用说明

- **阶段编号** 对应药物发现典型流程：Hit → Lead → PCC → In vivo
- **优先级**：P0 = 必做；P1 = 强烈建议；P2 = 条件允许时做
- **通过判据** 为研究规划用参考阈值，需结合具体化合物系列调整
- 引用编号见 [`REFERENCES.md`](./REFERENCES.md)

## 阶段 0：计算与合成前（先导物设计）

| ID | 实验/分析 | 目的 | 优先级 | 通过/关注判据 |
|----|-----------|------|--------|---------------|
| 0.1 | 双靶点结构对接（NLRP3 NACHT + JNK1） | 评估药效团可达性及连接子长度 | P1 | 两端对接 score 可接受；无严重立体冲突 |
| 0.2 | 药效团叠合/杂交建模 | 指导第一梯队化合物设计 | P1 | 参考 URAT1-NLRP3 双药效团流程 [17] |
| 0.3 | 类药性过滤（Lipinski、PAINS、Brenk） | 排除明显非类药结构 | P0 | 无 PAINS 警报；MW ≤ 550 优先 [30,32] |
| 0.4 | 合成可及性（SAscore/SCScore） | 确保可制备足够 SAR 系列 | P0 | SAscore 不宜过高 [33] |
| 0.5 | 代谢产物预测 + 连接子稳定性评估 | 排除易裂解连接子 | P1 | 无高风险代谢软点 [36] |

**工具参考**：分子对接可用 AutoDock Vina / Glide；NLRP3 结构 PDB: 7PZB, 7VTP [20,21]；JNK1 结构 PDB: 3ELJ [25]。

## 阶段 1：体外生化/生物物理（Hit 确认）

### 1.1 JNK1 靶点验证

| ID | 实验 | 模型/方法 | 优先级 | 通过判据（Hit） | 通过判据（Lead） |
|----|------|-----------|--------|----------------|-----------------|
| 1.1.1 | JNK1 酶活性抑制 | ADP-Glo 或 HTRF；重组 JNK1 | P0 | IC₅₀ < 1 μM | IC₅₀ < 100 nM [7,12] |
| 1.1.2 | JNK 亚型选择性 | JNK1 vs JNK2 vs JNK3 平行测定 | P0 | JNK1 活性最优 | JNK1/JNK2 ≥ 5–10 倍 [7,12] |
| 1.1.3 | 激酶组选择性 | KINOMEscan 468 kinases 或等价 panel | P1 | — | S(35) ≤ 0.1 或明确脱靶清单 [45] |
| 1.1.4 | 作用机制 | ATP 竞争性验证（Km 变化） | P2 | — | 符合 ATP 竞争预期 [41] |

### 1.2 NLRP3 靶点验证

| ID | 实验 | 模型/方法 | 优先级 | 通过判据（Hit） | 通过判据（Lead） |
|----|------|-----------|--------|----------------|-----------------|
| 1.2.1 | NLRP3 靶点占据/结合 | NanoBRET NLRP3 target engagement [4,42] | P0 | 有效结合信号 | EC₅₀ < 500 nM |
| 1.2.2 | 备用结合验证 | CETSA 或 SPR（如有重组蛋白） | P1 | 热稳定性位移 | Kd 与功能一致 [42] |
| 1.2.3 | 炎症小体特异性 | NLRP1/NLRC4/AIM2 平行刺激 | P1 | 不显著抑制其他炎症小体 | 与 MCC950 选择性相当 [1,44] |

> **说明**：NLRP3 无成熟纯酶活性测定体系，**靶点占据实验应优先于单纯细胞 IL-1β 读数** [4,22]。

### 1.3 双靶平衡（生化层）

| ID | 实验 | 计算 | 优先级 | 通过判据 |
|----|------|------|--------|----------|
| 1.3.1 | 生化双靶平衡指数 | BDI = min(IC₅₀_JNK1, EC₅₀_NLRP3) / max(...) | P0 | Hit: BDI ≥ 0.3；Lead: BDI ≥ 0.5 |
| 1.3.2 | 双轴 SAR 散点图 | 每轮修饰后绘制 pIC₅₀(JNK1) vs pIC₅₀(NLRP3) | P0 | 优先选择近对角线化合物 [26] |

## 阶段 2：细胞水平功能验证

### 2.1 细胞模型与刺激

| 细胞系 | 适用实验 | 刺激方案 | 参考文献 |
|--------|----------|----------|----------|
| THP-1（分化后） | IL-1β、ASC speck | LPS 4 h + ATP/nigericin 45 min | [1,8,10] |
| 小鼠 BMDM | IL-1β、ASC speck | 同上 | [8,10] |
| 人原代单核细胞 | IL-1β（转化验证） | 同上 | [4] |

**必须记录并固定的参数**：细胞密度、LPS 剂量、ATP 浓度、药物预处理/共处理时间 [8,10]。

### 2.2 正交 readout（同一细胞批次平行）

| ID | Readout | 靶点指向性 | 优先级 | 通过判据（Lead） |
|----|---------|------------|--------|-----------------|
| 2.2.1 | p-c-Jun（WB/流式） | JNK1 直接底物 | P0 | IC₅₀ < 500 nM |
| 2.2.2 | p-JNK | JNK 激活状态 | P1 | 与 p-c-Jun 一致 |
| 2.2.3 | ASC speck（免疫荧光） | NLRP3 炎症小体组装 | P0 | EC₅₀ < 1 μM [10] |
| 2.2.4 | IL-1β（ELISA） | 下游效应 | P0 | IC₅₀ < 1 μM |
| 2.2.5 | IL-18、LDH（焦亡） | 下游/细胞毒性 | P2 | 选择性抑制 NLRP3 通路 |
| 2.2.6 | 细胞活力（CCK-8） | 毒性对照 | P0 | CC₅₀ >> 功能 IC₅₀ |

### 2.3 单靶点对照与协同分析

| ID | 实验设计 | 目的 | 优先级 | 通过判据 |
|----|----------|------|--------|----------|
| 2.3.1 | 双靶药 vs JNK1 单药（CC-90001 或工具化合物） | 排除"仅 JNK1 起效" | P0 | 见判读逻辑 §A |
| 2.3.2 | 双靶药 vs NLRP3 单药（MCC950 或工具化合物） | 排除"仅 NLRP3 起效" | P0 | 见判读逻辑 §A |
| 2.3.3 | 双靶药 vs 单药等摩尔联合 | 验证单分子优势 | P0 | 疗效 ≥ 联合；PK 优势体内验证 |
| 2.3.4 | 等效线图 / CI 分析 | 协同判定 | P0 | CI < 1 为协同 [39,40] |

#### §A 判读逻辑（IL-1β 为例）

| 结果 | 解释 | 下一步 |
|------|------|--------|
| 双靶药显著优于 JNK1 单药 **且** NLRP3 单药 | 双靶协同可能成立 | 做遗传学验证 |
| 双靶药 ≈ JNK1 单药 >> NLRP3 单药 | 可能主要为 JNK1 起效 | 优化 NLRP3 端 |
| 双靶药 ≈ NLRP3 单药 | JNK1 端可能较弱 | 优化 JNK1 端或讨论不对称策略 |
| 双靶药 ≈ 联合用药 | 单分子无明显优势 | 重新评估设计策略 [13,15] |

### 2.4 遗传学/药理学靶点确认

| ID | 实验 | 优先级 | 预期结果 |
|----|------|--------|----------|
| 2.4.1 | NLRP3 siRNA/shRNA 或 NLRP3⁻/⁻ 细胞 | P1 | 双靶药抑制 IL-1β 效应显著减弱 [8] |
| 2.4.2 | JNK1 siRNA/shRNA 或 JNK1⁻/⁻ 细胞 | P1 | p-c-Jun 抑制消失；IL-1β 抑制部分减弱 [8,10] |
| 2.4.3 | NLRP3 S198A/S194A 突变体（如有条件） | P2 | JNK1 许可环节受损；验证上游机制 [8] |

### 2.5 细胞层双靶平衡

| ID | 指标 | 注意 | 通过判据 |
|----|------|------|----------|
| 2.5.1 | BDI_cell（p-c-Jun vs ASC speck） | **不用 IL-1β 代替 ASC speck** [8,10] | BDI ≥ 0.5 |
| 2.5.2 | 生化 BDI vs 细胞 BDI 比较 | 若生化平衡但细胞不平衡，检查通透性/时间轴 | 趋势一致 |

## 阶段 3：ADME 与初步安全性（Lead 优化）

| ID | 实验 | 物种/模型 | 优先级 | 关注阈值 |
|----|------|-----------|--------|----------|
| 3.1 | 溶解度 | PBS / 模拟肠液 | P0 | > 10 μM（口服方向） |
| 3.2 | 肝微粒体/肝细胞稳定性 | 人/小鼠/大鼠 | P0 | t₁/₂ 满足给药间隔 |
| 3.3 | CYP 抑制/诱导 | 主要 CYP（1A2, 2C9, 2D6, 3A4） | P1 | 弱抑制为佳 [12,37] |
| 3.4 | 血浆蛋白结合 | 人血浆 | P0 | 记录 fu；用于占据估算 [34,35] |
| 3.5 | P-gp 底物/抑制 | Caco-2 或 MDCK-MDR1 | P1 | 评估脑/肠渗透 |
| 3.6 | hERG 抑制 | 膜片钳或荧光 | P0 | IC₅₀ > 10 μM |
| 3.7 | 肝细胞毒性 | HepG2 或原代肝细胞 | P0 | CC₅₀ >> 有效浓度 |
| 3.8 | 体外代谢产物鉴定 | 肝微粒体 + 肝细胞 | P1 | 鉴定主要代谢物并测双靶活性 [36] |
| 3.9 | 反应性代谢物 | GSH 捕获 | P2 | 无异常反应性 |

## 阶段 4：体内 PK 与靶点占据（PCC 前）

| ID | 实验 | 设计要点 | 优先级 | 输出 |
|----|------|----------|--------|------|
| 4.1 | 小鼠 PK（IV + PO） | 至少 3 个剂量；测定 Cmax, AUC, t₁/₂ | P0 | 计算 fu 与 Cu [34,35] |
| 4.2 | 大鼠 PK（如进入临床前） | 重复给药 7 天 | P1 | 暴露线性/蓄积 |
| 4.3 | 组织分布 | 炎症组织 vs 血浆 | P1 | 滑膜/脂肪/肝/脑（视适应症） |
| 4.4 | 体内 PD 生物标志物 | p-c-Jun；血浆 IL-1β | P0 | PK/PD 时间曲线 |
| 4.5 | 暴露—占据关联 | Cu/IC₅₀,JNK1 与 Cu/IC₅₀,NLRP3 | P0 | 两者均 ≥ 1（建议 ≥ 3）[34,35] |

## 阶段 5：疾病动物模型疗效

|----|------|----------|------|--------|----------|

### 5.2 代谢炎症模型

| ID | 模型 | 给药方案 | 终点 | 参考文献 |
|----|------|----------|------|----------|
| 5.2.1 | db/db 或 HFD 小鼠 | 慢性给药 4–8 周 | 胰岛素敏感性、血糖、血浆 IL-1β | [16,47] |
| 5.2.2 | LPS 低剂量慢性模型 | 慢性给药 | 系统性炎症指标 | [16] |

### 5.3 体内疗效判据

| 判据 | 说明 |
|------|------|
| 疗效优于 vehicle | 基本有效 |
| 疗效优于 JNK1 单药 **或** NLRP3 单药 | 支持双靶贡献 |
| 疗效优于等摩尔联合 | 支持单分子设计价值 [13,15] |
| 等效剂量下毒性不高于单药 | 安全性可接受 |

## 阶段 7：论文/开题必须呈现的数据最低集

### 7.1 开题/初步数据（Minimum Viable Package）

- [ ] JNK1 酶学 IC₅₀ + 亚型选择性（1.1.1, 1.1.2）
- [ ] NLRP3 靶点占据或 ASC speck（1.2.1, 2.2.3）
- [ ] 同细胞 p-c-Jun + IL-1β 浓度曲线（2.2.1, 2.2.4）
- [ ] 单靶点抑制剂对照（2.3.1, 2.3.2）
- [ ] 生化 BDI 计算（1.3.1）
- [ ] 1 个概念验证动物实验（5.1.1 或 5.2.1）

### 7.2 博士论文发表级（Recommended Package）

- [ ] 完整 SAR（≥ 20 化合物）与双轴散点图
- [ ] CI/等效线图协同分析（2.3.4）
- [ ] 遗传学验证（2.4.1, 2.4.2）
- [ ] 激酶组选择性（1.1.3）
- [ ] 完整 ADME + hERG + 肝毒性（阶段 3）
- [ ] 小鼠 PK + PK/PD（阶段 4）
- [ ] ≥ 2 个疾病模型 + 单药/联合对照（阶段 5）
- [ ] 代谢产物表征（3.8）
