## 1. 综述结论（先行）

### 1.1 领域现状

近五年高水平双靶点研究呈现三条主线：

| 主线 | 代表工作 | 与 NLRP3/JNK1 课题关系 |
|------|----------|------------------------|
| **炎症/痛风多机制双靶** | URAT1+NLRP3 [L1]、mesalamine-NSAID+NLRP3 [L4]、NLRP3+AHAS [L2] | **高度相关**：疾病-机制-适应症逻辑可直接借鉴 |
| **炎症小体家族内双靶** | NLRP1+NLRP3 (ADS032) [L3] | 相关：验证策略可参考，但靶点组合不同 |
| **AIDD 从头双靶设计** | POLYGON [L5]、CLM [L6]、AIxFuse [L7]、DualTransORGAN [L8] | **方法学高度相关**：可指导计算设计流程 |

**重要事实（有据可查）**：截至本综述撰写时，**尚未检索到公开发表的 NLRP3 与 JNK1 理性双靶点小分子设计论文**。JNK1 与 NLRP3 的上下游耦合由 Song 等（2017）[见主文档 REF 8] 及 Gaul 等（2023）[见主文档 REF 10] 确立，但尚未被转化为双靶点药物化学论文。

### 1.2 近五年文献提炼的"五步法"

```
Step 1  靶点组合选择  →  疾病机制耦合 + 结构/口袋可设计性
Step 2  双药效团/骨架  →  药效团模型、杂交或 AI 生成
Step 3  体外双靶验证  →  生化 + 正交细胞 readout + 单靶对照
Step 4  SAR 平衡优化  →  双轴散点图，追求活性平衡而非单端极强
Step 5  适应症-模型匹配  →  动物模型终点与双靶机制一致
```

## 3. 靶点如何选择：文献中的共性原则

综合 [L11][L12] 及实证论文，近五年双靶点靶点组合选择遵循以下**可重复的规则**：

### 3.1 规则一：疾病机制上的"同一病理链条"

| 文献 | 靶点组合逻辑 |
|------|-------------|
| [L1] | 痛风 = 高尿酸（URAT1）+ MSU 晶体激活 NLRP3 → IL-1β；单靶无法同时解决"成因+炎症" |
| [L4] | UC = COX-2 前列腺素通路 + NLRP3 细胞因子通路；传统 mesalamine 或 NSAID 单药不足 |
| [L2] | 真菌感染 = 病原体（AHAS）+ 宿主过度炎症（NLRP3）；抗真菌+抗炎联合需求 |
| [L3] | 广泛炎症 = NLRP1 与 NLRP3 在不同细胞/刺激下分别激活，双抑制扩大治疗窗 |
| [L5] | 肿瘤 = 合成致死（synthetic lethality）蛋白对；遗传学/组学定义的双依赖 |

**对 NLRP3/JNK1 的映射**：JNK1 磷酸化 NLRP3-S198 是 priming 许可步骤（Song 2017；见主文档），属于**同一病理链条的上下游**，符合 [L1][L4] 类研究的选题逻辑。

### 3.2 规则二：结构/化学上的"可设计性"

[L11] 明确提出，连接策略取决于口袋特征：

```
口袋大、溶剂暴露  →  药效团直接融合（fusion）
口袋深埋、小而疏水  →  柔性连接（linker）—— NLRP3 NACHT 深口袋 + JNK1 ATP 口袋属此类
底物/配体相似      →  两先导物合并（merging）
```

[L2] 则利用 **NLRP3 抑制剂（MCC950/磺酰脲）与 AHAS 抑制剂（磺酰脲类除草剂）的结构相似性** 启动虚拟筛选——这是"化学相似性驱动靶点配对"的典型案例。

[L12] 数据挖掘发现：已发表 DTDL 中 **86.7% 保留了单靶点母核的保守修饰**，仅 7% 为真正全新骨架；提示**从已知先导出发扩展第二靶点**是主流且可行路径。

### 3.3 规则三：临床/未满足需求驱动

| 文献 | 未满足需求 |
|------|-----------|
| [L1] | 现有降尿酸药（非布司他、苯溴马隆）肝毒性/肾毒性；抗炎药（秋水仙碱）靶点相关性弱 |
| [L4] | NSAID 全身毒性；mesalamine 抗炎机制单一 |
| [L8] | 哮喘需 A2A 受体 + PDE4 双通路协同 |

## 4. 为何选择这些靶点：机制与疾病逻辑

### 4.1 痛风/代谢炎症轴（最贴近 NLRP3/JNK1 适应症）

**[L1] Zhan et al., *Nat Commun* 2025** 的论证链（原文逻辑）：

1. 痛风 = HUA + MSU 晶体沉积；
2. MSU → NLRP3 → IL-1β 是急性发作核心；
3. 仅降尿酸不解决急性炎症；仅抗炎不解决高尿酸；
4. 因此需要 **单分子双功能**：降尿酸 + 抗 NLRP3 炎症；
5. 天然产物 β-carboline 有降尿酸活性 → 药效团引导优化 → 引入 NLRP3 药效团。

**可借鉴点**：NLRP3/JNK1 双靶可同样论证——JNK1 阻断 priming，NLRP3 阻断执行；对于**急性痛风发作预防**或**慢性低度炎症**，双靶优于单靶。

### 4.2 结构相似性跨物种/跨靶点（计算筛选逻辑）

**[L2] Lowes et al., *ACS Infect Dis* 2021**：

- **观察**：NLRP3 抑制剂（glyburide、MCC950）与靶向真菌 AHAS 的磺酰脲类除草剂具有结构相似性；
- **推论**：同一化学骨架可能同时结合两个口袋；
- **验证**：BCAA（支链氨基酸）救援实验——若抗真菌活性被 BCAA 逆转，则支持 AHAS 靶向（机制验证的典范）。

### 4.3 同家族蛋白双靶（扩展治疗谱）

**[L3] ADS032**：NLRP1 与 NLRP3 在呼吸道上皮和巨噬细胞中均可被不同刺激激活；双抑制可覆盖更广泛的 DAMP 响应。

### 4.4 炎症多通路（杂合药物）

**[L4]**：UC 病理涉及 NF-κB、COX-2、NLRP3 等多节点；mesalamine（局部抗炎）+ diclofenac（COX-2）杂合，旨在**结肠靶向 + 双通路**。

## 5. 双靶效应如何验证：实验与计算证据链

### 5.1 文献中的验证层级（由弱到强）

```
Level 1  计算预测     对接、药效团匹配、AI 生成评分
Level 2  生化结合     酶学 IC₅₀、SPR、NanoBRET、CETSA
Level 3  细胞功能     正交 readout（见下表）
Level 4  机制特异性   救援实验、KO/siRNA、选择性刺激
Level 5  单靶对照     单药 vs 双靶药 vs 联合用药
Level 6  体内疗效     疾病模型 + 生物标志物
```

### 5.2 各文献具体验证方案对照

| 文献 | 靶点 1 验证 | 靶点 2 验证 | 双靶特异性证据 | 体内 |
|------|------------|------------|----------------|------|
| [L1] | URAT1 细胞摄取 IC₅₀；SPR Kd=27.8 μM | BMDM IL-1β IC₅₀=2.61 μM；SPR 结合 NLRP3 | 多转运体面板；非 TNF-α/IL-6 抑制 | 高尿酸小鼠 + MSU 痛风关节炎大鼠 |
| [L2] | IL-1β IC₅₀（THP-1 LPS+ATP） | 真菌 MIC；BCAA 救援 | SAR 必需骨架 | 未报道体内（待验证） |
| [L3] | NLRP1 刺激下 IL-1β | NLRP3 刺激下 IL-1β；ASC speck | 直接结合 NLRP1/NLRP3 | LPS、硅肺、流感 A 模型 |
| [L4] | COX-2（设计意图） | NLRP3/IL1B/CASP1 qRT-PCR | 对接 NLRP3、caspase-1 | 未报道（待做） |
| [L5] | MEK1 酶学活性 | mTOR 酶学活性 | 32 个化合物双抑制 >50% | 肺癌细胞活力 |
| [L6] | 各靶点酶学/结合 | 各靶点酶学/结合 | 12 个合成，7 个确认双靶 | 无体内 |
| [L8] | ADORA2A 结合 | PDE4D 结合 | 39 蛋白面板测选择性 | 无体内 |

### 5.3 共同验证要点（你的课题应采纳）

1. **正交 readout**：[L1] 用 URAT1 细胞实验 + IL-1β，而非仅用 IL-1β 代表两个靶点；[L3] 用 ASC speck 代表 NLRP3 组装。
2. **单靶点抑制剂对照**：[L1] 以 febuxostat、lesinurad、MCC950 等为阳性对照；你的课题需 CC-90001 类 + NLRP3 抑制剂对照。
3. **机制救援**：[L2] 的 BCAA 救援是典范；NLRP3/JNK1 可用 **NLRP3-S198A** 或 **JNK1 siRNA** 验证。
4. **联合用药对比**：[L1] 隐含单药联用毒性/PK 问题；需显式比较双靶单分子 vs 等摩尔联合（见主文档）。
5. **协同统计**：Chou-Talalay CI 分析在双靶文献中仍较少见，但是博士论文的加分项 [见主文档 REF 39-40]。

## 6. 双靶分子如何优化：SAR 与计算迭代

### 6.1 药效团引导的多轮 SAR（[L1] 典范流程）

```
轮次 1：保留天然产物核心（β-carboline）+ 引入 lesinurad 药效团疏水区 → 8 个化合物
轮次 2：骨架跃迁（carboline → indole 酰胺）→ 8 个化合物
轮次 3：构建 URAT1-NLRP3 双药效团 → 48 个 indole acylsulfonamide → 选 32
```

**SAR 规律（[L1] 原文）**：
- 萘环（S2）优于苯环；
- 环丙基取代优于溴取代（系列依赖）；
- 磺酰胺基团为必需阴离子中心；
- NLRP3 活性与 URAT1 活性需同步优化（双轴筛选）。

### 6.2 虚拟筛选 → 苗头 → SAR（[L2]）

- 25 万库对接 → top 1%（~70 个）→ 体外双活性 → 12 个命中 → SAR → 10/10a 低 μM。

### 6.3 AI 生成 → 过滤 → 合成（[L5][L6][L8]）

| 步骤 | POLYGON [L5] | CLM [L6] | DualTransORGAN [L8] |
|------|-------------|----------|---------------------|
| 生成 | VAE 潜在空间 + RL 奖励双靶预测 | SMILES CLM pooled fine-tuning | GAN-Transformer + 策略梯度 RL |
| 过滤 | 类药性、合成可及性、双靶对接 | 指纹相似度、靶点预测 | 双靶 bioactivity 评分求和 |
| 输出 | 32 个 MEK1/mTOR 化合物 | 12 个合成 | 10 个合成 |
| 成功率 | 大多数 >50% 双酶抑制 | 7/12 确认双靶 | 3/10 双靶结合 |

### 6.4 双靶平衡优化（[L11] 原则）

> "The inhibitory activities of the two targets need to be adjusted to achieve an optimal ratio." [L11]

实践做法：
- 绘制 **pIC₅₀(靶点A) vs pIC₅₀(靶点B)** 双轴散点图；
- 优先选择近对角线化合物；
- 避免"一端极强、一端无效"的伪双靶分子 [L12]。

## 8. CADD/AIDD 方法学专题

### 8.1 计算方法分类总览

| 方法类别 | 代表工具/算法 | 文献 | 适用场景 |
|----------|--------------|------|----------|
| **药效团建模** | MOE Pharmacophore、Schrödinger Phase | [L1] | 已知先导物，双口袋特征明确 |
| **分子对接虚拟筛选** | Glide、AutoDock Vina、内部对接管线 | [L1][L2][L4] | 大库筛选、苗头发现 |
| **分子动力学 + MM-GBSA** | GROMACS/AMBER，100 ns+ | [L1][L13] | 结合稳定性、双靶亲和力比较 |
| **SPR/ITC 辅助** | 生物物理验证 | [L1] | 直接证明靶点结合 |
| **VAE + 强化学习** | POLYGON | [L5] | 从头生成，需大量活性数据训练 |
| **化学语言模型 fine-tuning** | CLM (SMILES GPT) | [L6][L10] | 配体结构相似的双靶对 |
| **RL + 对接反馈** | AIxFuse（MCTS + AttentiveFP） | [L7] | 药效团融合，激酶等对 |
| **GAN-Transformer + RL** | DualTransORGAN | [L8] | 任意双靶，需活性数据 |
| **GAIL + Transformer** | MTMol-GPT | [L9] | 多靶分子生成 |
| **QSAR + MD + DCCM** | 机器学习 + 动态相关矩阵 | [L13] | 骨架系列优化 |
| **片段 GA 组装** | DualFASMIFRA | [L8] | 保守、基于已知活性片段 |

### 8.2 各 AIDD 平台的技术细节（供课题方法学参考）

#### POLYGON [L5]

```
输入：两个靶点的蛋白序列/结构 + 已知活性数据
架构：VAE 嵌入化学空间 → 强化学习采样新结构
奖励函数：R = w1·P(抑制靶点A) + w2·P(抑制靶点B) + w3·类药性 + w4·合成可及性
输出：SMILES → 对接验证 → 合成
验证：82.5% 识别已知多靶活性；MEK1/mTOR 32 个化合物大多数双抑制 >50%
```

#### CLM 多靶 [L6]

```
输入：两个靶点的已知配体 SMILES 集合
方法：预训练 CLM（365k 分子）→ 合并两个靶点配体池 fine-tuning
生成：偏向同时含有两个靶点药效团元素的 SMILES
验证：6 个靶点对训练，12 个分子合成，7 个确认双靶（58% 双靶率）
局限：配体结构需有一定相似性才效果好
```

#### AIxFuse [L7]（含 JNK 家族案例）

```
输入：GSK3β 与 JNK3 的晶体结构 + 活性分子药效团
方法：
  1. 从活性分子提取药效团
  2. 两个 RL agent（MCTS）学习药效团选择与融合
  3. 对接分数作为奖励；AttentiveFP 学习对接评分函数（主动学习）
输出：同时满足双靶对接约束的分子
验证：对 GSK3β/JNK3 优于 PGMG 等；RORγt/DHODH 成功率提高 5 倍
与课题关联：JNK3 案例证明 AI 平台可处理 JNK 家族口袋
```

#### DualTransORGAN + DualFASMIFRA [L8]

```
DualFASMIFRA：GA 组装已知活性片段 → 保守、可解释
DualTransORGAN：SMILES 为输入的 GAN-Transformer
  - 随机策略梯度 RL 优化双靶 bioactivity 评分
生成后用 39 蛋白结合面板验证选择性
```

#### Zhan et al. 双药效团流程 [L1]（**最接近传统药物化学+CADD 混合，推荐优先模仿**）

```
1. Schrödinger 构建 β-carboline 与 lesinurad 药效团
2. MOE 分别构建 URAT1、NLRP3 单靶药效团
3. 叠合构建双靶药效团（3 疏水 + 1 阴离子中心；距离 3.94/6.20/3.58 Å）
4. 分子杂交设计 64 个化合物
5. 表型筛选（小鼠降尿酸）→ 活性化合物 → 靶点鉴定
6. URAT1 细胞实验 + BMDM IL-1β + SPR 结合 NLRP3
7. 分子对接（PyMOL）+ 100 ns MD（RMSD 稳定性）
```

### 8.3 CADD 方法选择决策树（针对 NLRP3/JNK1）

```
是否有 JNK1 与 NLRP3 共晶/可靠同源模型？
├── 是 → 分子对接 + 药效团杂交（参考 [L1] 流程）
│         + 100 ns MD 验证双靶结合稳定性
├── 活性数据 > 50 化合物？
│   ├── 是 → QSAR 双模型 + 骨架优化（参考 [L13]）
│   └── 否 → 虚拟筛选（参考 [L2]）或 AI 生成（参考 [L7][L8]）
└── 是否需要从头设计？
    ├── 是 → AIxFuse / POLYGON / CLM（需充分计算验证后合成）
    └── 否 → 从 MCC950 类 + CC-90001 类药效团杂交（[L11] linker 策略）
```
