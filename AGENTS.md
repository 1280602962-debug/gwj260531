# AGENTS.md

## Cursor Cloud specific instructions

### What this project is
A single Python scientific CLI product: `JNK1_Selectivity_Project/`, a CADD/AIDD
pipeline for JNK1-selective kinase inhibitor screening (RDKit + XGBoost +
Chemprop + SHAP). There are **no servers, databases, ports, or env vars/secrets** —
everything is local CLI scripts reading/writing flat files (CSV/JSON/PNG).

### Working directory
All commands run from `JNK1_Selectivity_Project/` (scripts resolve paths relative
to that directory). The repo root is a thin wrapper; `cd JNK1_Selectivity_Project`
first.

### Dependencies
Installed by the update script (`pip install -r JNK1_Selectivity_Project/requirements.txt`).
Heavy native/ML wheels (RDKit, XGBoost, LightGBM, and Chemprop which pulls in
PyTorch/CUDA wheels). They install into the user site (`~/.local`); `python3 ...`
picks them up automatically — no virtualenv activation needed. GPU is not
required (torch runs CPU-only; `torch.cuda.is_available()` is `False`).

### Run / hello-world
End-to-end pipeline (data prep → train XGBoost selectivity models → SHAP →
virtual screening on a demo library):
```bash
cd JNK1_Selectivity_Project
python3 scripts/run_selectivity_pipeline.py            # full run, ~50s
python3 scripts/run_selectivity_pipeline.py --skip-data-prep   # reuse curated data
```
Individual steps (`scripts/00_*`–`07_*`) and the model-comparison entrypoint
(`scripts/07_compare_models.py --skip-prepare --skip-similarity --skip-chemprop`)
are documented in `JNK1_Selectivity_Project/README.md`.

### Tests / lint
There is **no test suite and no linter/formatter configured** (no pytest, ruff,
flake8, pyproject, etc.). Use `python3 -m py_compile scripts/*.py` as a basic
syntax check.

### Gotchas
- RDKit prints many `DEPRECATION WARNING: please use MorganGenerator` lines on
  every run — these are harmless noise; filter with `grep -v "DEPRECATION WARNING"`.
- Some training metrics legitimately report `NaN` (e.g. MTL `pAct_JNK1` R²,
  selectivity classifier AUC) because of tiny/constant test splits in the bundled
  curated data; this is expected and not an error.
- Generated `models/` and large libraries under `data/libraries/*.smi|*.csv` are
  gitignored; `models/` is regenerated by step 04 / the orchestrator on first run.
- Internet (ChEMBL API via `scripts/01_download_chembl_data.py`) is only needed to
  re-download raw data; curated inputs are already committed under `docs/` and
  `data/processed/`, so it can be skipped.
