# 路线 C3：实验结构模板上的双节点结构指纹筛选（候选优先）

> **用语更正（2026-09-04）**：「cryo-EM 锚定」不是一种新方法，只是口语缩写，意思是**对接口袋、IFP 参考姿态和关键残基全部取自已沉积的实验坐标，而不是 AlphaFold2 模型或对接出来的药物姿态**。URAT1 侧是 cryo-EM（9DK9/9DKA/9DKB/9DKC）；NLRP3 侧 7ALV 是 **X-ray 晶体结构（2.83 Å）**，不能写成「cryo-EM 锚定的双节点」。更准确的说法是**实验结构模板（experimental-structure template）**。
> 「没人做过」只表示：截至检索日，未见以 9DK 系列共结构为受体、并以已发表突变体校准 IFP 的 URAT1 虚筛论文。这是**时间窗口上的缺口**（结构 2025-06 才公开），不是方法学发明。

> **目标**：产出候选分子 + 一篇正面论文。不以负结果为产品。
> 机器可读锁：[`config/campaign_c3.yaml`](../config/campaign_c3.yaml)
> C2 的"转运循环不相容"降级为本路线内的 **S4 底物排除过滤器**（仍有用，但不再是论文主张）。

## 1. 为什么这条路能出正面结果（三个新发现）

### 发现一：存在一套现成的匹配交叉对接基准，你只用了其中四分之一

Suo, Fedor & Lee, *Nat. Commun.* 2025, **16:5178** 一次沉积了**同一构建体、同一实验室、同一批条件**的四个结构：

| PDB | 内容 | 分辨率 | 配体 ID |
|---|---|---|---|
| **9DK9** | URAT1 apo（未加外源配体） | **2.68 Å** | — |
| **9DKA** | 苯溴马隆 | **3.00 Å** | R75 |
| **9DKB** | lesinurad（你的生产结构） | **2.74 Å** | LES |
| **9DKC** | **TD-3**（新化合物） | **2.55 Å** | A1A45 |

意义有三：
1. **同构建体 = 无跨构建体伪影**，是理想的 4×4 交叉对接矩阵；
2. **有 apo（9DK9）**，因此可以做"前瞻性场景"的对接（把配体投进未见过配体的口袋），这是审稿人最认的姿态验证；
3. **TD-3 是一个新化合物**，其结构告诉你哪种药效团真的работает：**4-溴萘基 + 咪唑并吡啶硫醚 + α,α-二甲基羧酸**（`2-({1-[(4-bromonaphthalen-1-yl)methyl]-1H-imidazo[4,5-b]pyridin-2-yl}sulfanyl)-2-methylpropanoic acid`）。萘环与 verinurad 一致，gem-二甲基酸臂是 lesinurad 酸臂的代谢稳定化版本——**这是现成的新颖化学型模板**。

之前 lesinurad 自由自对接 4.30/4.31/4.88 Å 被当成项目判决。实际上它只是 4×4 矩阵里的一格：lesinurad 有柔性硫醚-乙酸臂（最难的那一个），而**苯溴马隆约 2 个可旋转键、TD-3 中等柔性**，且分辨率 2.55–3.00 Å。姿态预测的成败必须在矩阵上报告，不能由最难的配体单独定罪。

### 发现二：你项目里已经有一个跑通的判别器，只是在 NLRP3 侧

`data/campaigns/c1/05_metrics/nlrp3_structural_panel/` 的实测：

| 指标 | 数值 |
|---|---|
| 正例通过率 | **10/10 = 100%** |
| 背景通过率 | 11/20 = 55% |
| Fisher 精确检验 | **p = 0.0134** |
| IFP Jaccard：NP3-146 / MCC950 | 0.842 / 0.895 |
| IFP Jaccard：ChEMBL 砜脲活性（pChEMBL 8.1–8.3） | 均 0.895 |
| IFP Jaccard：临床背景分子 | 0.62–0.80 |

门定义：`loose = COM≤6 Å 且 CNNscore≥0.5`；`structural = loose + overlap≥0.50 + IFP Jaccard≥0.50 + key contacts≥5/7 + 无冲突`。

**结论：在本项目内，能判别的方法是 IFP 模式匹配与关键接触回收，不是打分幅值。** 这解释了全部历史：
- CNNaffinity 是**幅值**，与分子大小/疏水体积共变 → TrueDecoy 上 EF 2.59、包络随机集上 0.215；
- IFP Jaccard 是**模式匹配**，与分子大小无关 → NLRP3 侧 p = 0.0134。

URAT1 侧从未做过等价的 IFP 门。这是最大的一块未开采资产，而且工具已有（`extract_nlrp3_key_residues.py`、`rescore_nlrp3_structural.py`、`c1_nlrp3_pose_metrics.py`），移植成本很低。

需要改进的一点要说清楚：NLRP3 面板背景通过率 55%，**特异性偏弱**。URAT1 侧必须在诱饵集上调门限并报告真实 EF/AUC，而不是照抄 0.50 阈值。

### 发现三：URAT1 有大量**定量**突变体数据，可做无需湿实验的验证

| 来源 | 数据 |
|---|---|
| Tan 等 *Sci. Rep.* 2017, 7:665 | verinurad：F241Y 5×↓、F449Y 无变化、R477K 9×↓；苯溴马隆：F241Y 2×↑、**F449Y 9×↓**、R477K 4×↓；磺吡酮：F241Y 7×↓、F449Y 3×↓、R477K 2×↑；丙磺舒：仅 R477K 3×↓ |
| Guo/Chen *Nat. Commun.* 2025 | S35Q、R477N 显著降低 lesinurad 与 verinurad 结合；M214Q、F360Y、F365Y 不同程度降低；F241Y/F364Y/F449Y 不显著；**D389A** 显著降低 verinurad（与氰基静电）；**F360T** 对苯溴马隆效价影响最大 |
| Dai & Lee *Cell Res.* 2024 | 五 Phe 笼 **F241/F360/F364/F365/F449**，任一→Ala 显著降低尿酸摄取；F365 在啮齿类为 Tyr |
| Guo/Chen 结构 | verinurad：萘环与 F241 堆积、与 F360/F364/F449 疏水；氰基–K393；吡啶与 F365 T 型 π-π、与 S35 极性、与 M214 疏水；**羧基–Q437 + R477** |

**每个药物有一份不同的突变体响应指纹。** 这直接给出 URAT1 的 IFP 关键残基集：
`S35, M214, F241, F360, F364, F365, D389, K393, Q437, F449, R477`（+ Q473）
——**全部有已发表的突变体或结构证据支持**。

## 2. 可行性排序：哪些真的能过

这是你问的核心。按成功概率排，**不把项目押在低概率环节上**。

| 环节 | 成功概率 | 依据 | 失败退路 |
|---|---|---|---|
| **S1 突变体一致性** | **近确定** | 对已沉积坐标做一致性核对，是核对不是预测 | 无需退路 |
| **S2 匹配交叉对接矩阵** | **高**（BBR/TD-3） | 刚性配体 + 2.55–3.00 Å 同构建体 + 有 apo | 用晶体姿直接建 IFP 参考 + 局域/受限对接 |
| **S3 URAT1 IFP 富集** | **中高** | NLRP3 同法 p=0.0134、正例 10/10；活性集骨架窄（127/469） | 调门限；退到 `key_contacts≥N` 单指标 |
| **S3b 外部药物回收** | **中** | 5–7 个上市/临床药作**外部**正例（它们不在 469 里，反而更干净） | 判据放宽至 top 10% |
| **S4 底物排除** | 高 | 参考 IFP 来自尿酸/吡嗪酸晶体位点 | 降为提示性注释 |
| **S5 MD 稳定性** | **高** | 有对照、有已发表力场配方 | 只报相对接触占据 |
| **S6 候选产出** | **高** | 双池 + 双节点门；NLRP3 臂已跑通 | 扩池到 taosu 库 |

**为什么之前失败的两件事这次不会重演**
1. 排序读出从 **CNNaffinity 幅值** 换成 **IFP 模式匹配 + 关键接触回收**——与分子尺寸解耦，这正是 RandomDecoy 崩塌的机理所在；
2. lesinurad 自由自对接失败从"项目判决"降级为"4×4 矩阵中最难的一格"，且主验证配体换成更刚性的苯溴马隆与 TD-3。

**S1 与 S2 必须先做**：它们成本最低、成功率最高，且产出的是论文的地基图（突变体一致性图 + 交叉对接矩阵）。

## 3. 新颖性：缺口是干净的

| 已发表 | 用了什么 | 缺口 |
|---|---|---|
| Yang 等 *RSC Adv.* 2023, 13:3474 | **AlphaFold2 模型** + watvina，ROC 0.813（21 活性 + 1050 DUD-E 诱饵）→ IFD/MM-GBSA → HEK | 非 cryo-EM |
| Du 等 *J. Biomol. Struct. Dyn.* 2024 | **AlphaFold2 模型**，四个 e-药效团来自**对接的**药物复合物 → 25 黄酮 → HEK（fisetin 12.77 µM） | 药物姿态是算出来的，不是实验解析的 |
| 荷叶碱衍生物 *Med. Chem. Res.* 2026, 35:203 | 衍生物合成 + 对接 + MD | 非筛选、非双靶 |
| *Eurycoma longifolia* 多靶抗痛风（PMC12340016） | **配体基**双靶 URAT1/NLRP3 药效团（3 疏水 + 阴离子中心，间距 3.94/6.20/3.58 Å，角 86.6°/90.9°）+ 表型筛选 + 64 个合成物 → 化合物 32 | 配体基 + 表型，**非结构基** |

**双结论**：
1. URAT1 + NLRP3 双靶概念**已被证明可以发在顶刊**（上表最后一行），所以方向不需要辩护；
2. 迄今能检索到的 URAT1 虚筛论文，受体都是 **AlphaFold2/同源模型**，药效团来自**对接出来的**药物姿态。2024–2025 才有实验共结构。到检索日为止，**未见**以 9DK 系列为受体、并以已发表突变体校准接触指纹的虚筛论文——这是时间窗口，不是新方法。NLRP3 侧 7ALV 是 X-ray，双节点应写成「实验结构模板」，不能两边都叫 cryo-EM。

可写进论文的主张必须降到这一级，不能写成「发明了 cryo-EM 锚定」：
> 在 URAT1 实验共结构（含同构建体 apo/多药复合物）上建立突变体校准的相互作用指纹，并与 NLRP3 的实验共结构（7ALV，X-ray）做双节点筛选，给出机制表征的候选分子。先前 URAT1 虚筛论文使用的是结构未解出时的 AlphaFold2 模型。

## 4. 实施阶段

### S1 — 突变体一致性（先做，近确定成功）
1. 从 9DKA / 9DKB / 9DKC（+ 9IRY verinurad、9JE1 dotinurad）提取晶体配体的**逐残基接触图**；
2. 与 §1 发现三的定量突变体响应比对：苯溴马隆应重现 F449 依赖（F449Y 9×↓）与 F360 依赖；verinurad 应重现 R477（9×↓）、F241（5×↓）、D389、S35，且 **F449 不敏感**；
3. 产出：药物特异接触指纹表 + 一致性图；据此**冻结** URAT1 IFP 关键残基集与权重。
- 产物：`data/campaigns/c3/01_ifp_reference/`

### S2 — 匹配交叉对接矩阵（高概率）
- 4 受体（9DK9 apo / 9DKA / 9DKB / 9DKC）× 4 配体（BBR / LES / TD-3 / verinurad）；三种子；报 RMSD 矩阵与 IFP 恢复率；
- **主判据用苯溴马隆与 TD-3**，lesinurad 作为已知困难例单列；
- **apo 9DK9 上的对接是前瞻性场景的代表**，须单独报告；
- 门：BBR 或 TD-3 在自身结构上 CNNscore 选姿 RMSD ≤ 2.0 Å 即通过；两者皆失败 → 转用晶体姿建参考 + 局域受限对接（不终止课题）。
- 产物：`data/campaigns/c3/02_crossdock/`

### S3 — URAT1 IFP 门标定与富集（中高概率）
1. 在 **469 活性 + 80 实验弱活 + TrueDecoy + RandomDecoy** 上计算 IFP Jaccard、overlap、key-contact 回收；
2. 在诱饵集上**标定门限**（不照抄 NLRP3 的 0.50），报 EF@1%/EF@5%/AUC 与 **Bemis–Murcko 骨架分层**统计（Top-1 骨架 127/469 = 27%，必须分层）；
3. 与历史同表并列：CNNaffinity EF@1% True 2.587 / Random 0.215；酸门 OR 0.970。
4. **S3b 外部药物回收**：苯溴马隆、dotinurad、verinurad、lesinurad、丙磺舒、磺吡酮不在 469 活性集内，作为**外部保留正例**，要求进入临床库排序前列。
- 产物：`data/campaigns/c3/03_ifp_enrichment/`

### S4 — 底物/反向阴离子排除（C2 保留下来的有用部分）
- 以尿酸（9B1K/9B1L 位点）与吡嗪酸（Dai & Lee 三位点）建**被转运配体参考 IFP**；
- 与被转运参考更相似而与抑制剂参考不相似者，标记为 **substrate-like / 抗尿酸排泄风险**，从候选中移出并单列。
- 理由：URAT1 是尿酸/单羧酸反向转运体，阴离子识别为底物与抑制剂共享；吡嗪酸是**抗尿酸排泄剂**。这一过滤没有任何同类工作做过，是低成本的差异化点。

### S5 — 双池筛选与候选提名
- **主池**：临床/再定位池（`docking_pool_p05.csv`，1588）+ 全 ~8319，给出可立即验证的双节点候选；
- **副池**：taosu 库，按 TD-3 / verinurad 药效团（溴萘基 + 杂芳硫醚 + 酸性头）取新颖化学型；
- 双节点门：URAT1 IFP 门（S3 标定）**且** NLRP3 结构门（沿用 `structural` 定义，正例 10/10、p=0.0134）；
- 附 ADMET / 新颖性 / 骨架多样性。

### S6 — MD 确证（对照先行）
对照顺序：apo 9DK9 → 苯溴马隆@9DKA（晶体姿）→ TD-3@9DKC → lesinurad@9DKB → NP3-146@7ALV。
对照过关后跑候选，每体系 3 × 150 ns。力场：Amber14SB / GAFF2 / POPC / TIP3P、PME、vdW 9 Å、2 fs、Parrinello–Rahman（*Nat. Commun.* 2025, 16:61226-x 配方）。
- 读出：配体位移 RMSD、关键残基接触占据（vs 晶体接触）、门距离。
- **不做** MM-GBSA 重排，不报绝对结合自由能。

## 5. 论文产品与投稿定位

**产品**：5–15 个双节点候选，每个含 cryo-EM 锚定姿态、突变体一致的相互作用指纹、MD 稳定性、双靶依据、ADMET、新颖性评估；外加 substrate-like 风险名单。

**图表骨架**
1. 四联 cryo-EM 结构与口袋（9DK9/9DKA/9DKB/9DKC）
2. 突变体一致性图（S1）— 论文地基
3. 4×4 交叉对接 RMSD 矩阵（S2）
4. URAT1 IFP 富集曲线 + 骨架分层（S3）；与 CNNaffinity 幅值排序对照
5. 外部药物回收（S3b）
6. 双节点筛选漏斗 + 候选表
7. 候选姿态与相互作用图
8. MD 稳定性（候选 vs 晶体对照）
9. substrate-like 排除（差异化点）

**定位说明（须写进 Limitations，一次讲清）**：无湿实验时，本文的主张是"经结构与回顾性验证优先排序的候选假说"，不是"已验证的抑制剂"。这一层级的论文在 *Molecular Diversity* / *JCIM* / *IJMS* / *J. Biomol. Struct. Dyn.* / *Eur. J. Med. Chem.*（计算栏目）是常规可发表的；要进 *Nat. Commun.* 级别则必须补 HEK 摄取与 IL-1β 实验。用验证深度（突变体一致性 + 匹配交叉对接 + 外部药物回收 + MD）来补偿没有细胞数据，是本路线的取胜方式。

## 7. 禁止事项

- 不覆盖 `data/repurposing/p2/` 与 `data/campaigns/c1/`；
