# 近半年 *Mol. Divers.* / *JCAMD* 无湿虚筛对照：MD 做完之后这篇还剩什么

检索日：2026-09-05。窗口约 2025-12 至 2026-09（近半年 + 上一轮已核过的 2025 年末篇）。  
只对照**无湿实验、或湿实验明确写 underway / putative**的虚筛/对接/MD 文。有酶活、细胞、LC-MS 的篇目单独标注，不当无湿对照。

本文回答两件事：**做完 MD 之后这篇有没有自己的亮点；缺陷在哪里、MD 修不修得掉。**

| | *Molecular Diversity*（目标刊） | *J. Comput. Aided Mol. Des.* |
|---|---|---|
| 近半年主体 | 应用虚筛：药效团/对接分 → ADMET → 100–200 ns MD → MM-GBSA → 点 2–5 个名字 | 方法、可复现、超大库、对接失效模式；应用文也要 ROC/诱饵/层次打分 |

## 1 *Molecular Diversity* 近半年无湿虚筛长什么样

核过的无湿/putative 篇（有湿的刻意排除）：

| 论文 | DOI / 时间 | 库与漏斗 | 排序字段 | MD | 湿实验 |
|---|---|---|---|---|---|
| Klebsiella PBP3 + KPC-2 萜类双靶（Gyebi & Sabiu） | 10.1007/s11030-025-11429-7（2025-12） | 147,953 萜类；药效团 → AutoDock/Vina | 对接分 + MD 后 MM-PBSA（写 −24.40 ± 5.20 kcal/mol 优于对照） | 有；PCA / 结合自由能 | 无（写 in vitro underway） |
| PCOS 3β-HSD1（Ranjan & Krishnasamy） | 10.1007/s11030-025-11437-7（2026-01） | 结构 + 配体 HTVS | 对接分 ≤ −8.0 + ADME | 200 ns | 无 |
| M3 抗毒蕈碱（Gill 等） | 10.1007/s11030-025-11208-4（2025-05 / 2026-02 卷） | 3D-QSAR 药效团 | 对接 → MM-GBSA | 有 | 无 |
| µ 阿片偏倚激动剂（Rajkumar / Garg） | 10.1007/s11030-026-11511-8（2026-03） | 超大化学空间；QuickShape → Glide → BBB | Glide + MM-GBSA | 有 | 无（标题 putative） |
| Online First 2026-09：AChE/MAGL 双抑制、CDK4/6 双抑制、PBP2b/PBP2x 肽 | 2026-09-03 起连续上线 | 对接 / ML / 生成肽 | 对接分 + MD 动态画像 | 有 | 从标题看无湿 |

**不要当无湿对照**（摘要里有湿实验）：CERS2（10.1007/s11030-025-11436-8，酶活 + LC-MS/MS）；PI3Kα（Vol. 30-4，体外活性）；RIPK3（2026-08-20，bioactivity evaluation）；CXCR4（2026-08-20，micromolar antagonist）。

标准漏斗几乎是复印的：

```
大库 / 天然产物 / 临床库
  → 药效团或形状
  → 对接分截断（Vina / Glide / AutoDock，单位 kcal/mol）
  → “作用看起来像共晶”
  → SwissADME / pkCSM
  → 100–200 ns MD，RMSD“稳”
  → MM-GBSA/PBSA 再给一个 kcal/mol
  → 点 2–5 个名字，写 promising / putative / underway
```

他们几乎从不做、也从不写的事：

- 已知药自对接 Top-1 失败 → **关掉排序轨**；
- 回顾集合上报 OR / Fisher / **LR+**，并承认某一扇门 LR+ = 1；
- 预登记阈值、只评一次、禁止网格搜索最大化 OR；
- 机械集合交产生名单（不用手写 primary/backup）；
- 膜转运蛋白用膜体系 MD；晶体对照失败则该靶侧不解释。

**和本项目产品形态最像的是 Klebsiella 那篇**（双靶、无湿、点名、MD+自由能）。方法完全不像。近半年这本刊里**没有**“对接分无排序能力 → 改几何门”的同类。

## 2 *JCAMD* 近半年在审什么

| 论文 | DOI / 时间 | 类型 | 和本项目的关系 |
|---|---|---|---|
| TRα 心脏再生激动剂虚筛 | 10.1007/s10822-026-00787-5（2026-03） | **无湿应用文**。ZINC15 4.12 亿 → 物化 → ROCS 药效团（ROC 定截断）→ FRED 对接 → 目视 8 个 → MD/MM-PBSA + PM7 + QM/MM + Fukui → **2 个候选** | 这本刊近半年最接近的“无湿点名”文。卖点是层次打分和 ROC 标定，不是“MD 稳” |
| 对接可复现 / 失效模式综述 | 10.1007/s10822-026-00849-8（2026-06） | 方法综述。对接是**条件模型**；自对接必要但不充分；必须交叉对接、诱饵、apo/预测结构；**禁止跨靶比分、把分当亲和力** | 本项目关掉 Rank 轨、改几何门，与这篇的主张同向 |
| *Stable simulations do not guarantee functional engagement*（Seladelpar / Zanamivir 脱靶案例） | JCAMD 40:227（2026-09-03） | 案例：MD 稳 ≠ 功能占据 | 直接打掉 *Mol. Divers.* 把 RMSD 当验证的写法 |
| VEGFR2 药效团+QSAR+对接+MD | 2026-08-22 | **有体外**，不当无湿对照 | — |
| WEE1 超大库 ML 虚筛 | 2026-08-14 | 方法+发现框架 | 库规模比本项目大几个数量级 |

*JCAMD* 近半年的编辑口味：要的是**部署条件下的可靠性**（姿态是否合理、筛选是否富集、受体不确定时是否稳健），不是工具新鲜或 kcal/mol。无湿应用文能上，但必须看起来像 TRα 那篇——层次、ROC、诱饵、多尺度——而不是 *Mol. Divers.* 模板。

## 3 做完 MD 之后，这篇有没有自己的亮点

先把 MD 能给的东西说死。预登记（`w5_md`）是：lesinurad 晶体酸根姿 @9DKB **膜体系**、NP3-146 共晶姿 @7ALV、discovery 2–3 个（单槽已预登记 PF-03882845）、3×200 ns、读出是盐桥/关键接触占据与 RMSD、**对照失败则该靶侧不解释**、MM-GBSA 只许池内相对比较、**不许当亲和力**。

### 3.1 MD 本身不是亮点

在 *Mol. Divers.*，100–200 ns MD + RMSD 稳 + MM-GBSA 是近半年无湿文的**标配**，做完只是“齐了手续”。在 *JCAMD*，2026-09 已经有人写“稳 ≠ 功能占据”。所以：

- 若 MD 之后用 MM-GBSA 给 URAT1 排名次 → 和 Klebsiella / µ 阿片同质，且违反本项目自己的锁；
- 若 MD 之后只报“RMSD 稳、看起来结合” → *Mol. Divers.* 能过模板，*JCAMD* 会认为没贡献；
- 若 MD 按预登记做（膜、晶体对照、停规则、接触占据、不重排）→ 这是**比同行更干净的 MD**，但仍是支撑层，不是主贡献。

### 3.2 真正还站得住的亮点（MD 做不做都在；MD 只是把它托住）

按“近半年两本刊有没有同类”排序，而不是按自我感觉：

| # | 亮点 | *Mol. Divers.* 近半年有没有 | *JCAMD* 近半年有没有 | MD 之后变强吗 |
|---|---|---|---|---|
| 1 | **对接分在 URAT1 上无排序能力，被量化后主动关掉**（lesinurad Top-1 4.3–4.9 Å；苯溴马隆 3.59 Å；best-of-9 ≈ 1.11 Å = 搜得到选不中） | **没有。** 他们自对接过了就排序，不过就换引擎或假装过了 | 综述主张如此，但**没有一篇应用文真的关掉排序轨** | 否。这是对接层的负结果，MD 不能补分 |
| 2 | **几何/IFP 门带回顾 OR、Fisher、LR+**，并公开 A2 的 LR+ = 1.00 | 没有人报这个 | TRα 文报了 ROC，但不是几何门 | 否 |
| 3 | **预登记 + 机械名单**（废掉硬编码 PF-04620110；β-内酰胺用 SMARTS） | 没有 | 有 FAIR/可复现主张，少见做到名单层 | 否 |
| 4 | 临床酸 + 疾病轴（尿酸重吸收 ∪ MSU–NLRP3）的**双节点假说**，且不叫 dual inhibitors | 产品像 Klebsiella，但他们叫 leads / modulators | 不像；JCAMD 不靠疾病故事 | 略强：MD 让“姿态活得过 200 ns”可写，故事本身不靠 MD |
| 5 | 晶体坐标锚定 IFP，不用失败的 CNNscore 重对接姿 | 没有 | 和“对接是条件模型”同向 | 否 |
| 6 | **膜转运蛋白用膜 MD + 晶体对照停规则**（若真按预登记做） | 几乎全是可溶蛋白水盒子，无对照停规则 | 少见应用 | **这是 MD 能新增的唯一方法亮点** |

**一句话**：亮点是“承认对接分失败、改用可审计的几何门、并量化门的真实增益（LR+ 2.2，且挡掉了已知药）”。MD 做对了，只多一条“膜体系 + 对照停规则”。MD 做错了（水盒子、无对照、MM-GBSA 排名），亮点会被自己冲掉。

### 3.3 不要再当亮点卖的东西

- “双靶”——2026-09 *Mol. Divers.* Online First 一周内就能数出三篇双靶计算文。
- “临床重定位”——µ 阿片、TRα（Cetraxate）都在做。
- “三种子 / exh=32”——是严谨，不是新方法。
- “MD 200 ns 稳”——商品。
- “PF-03882845 结合两个口袋”——MD 稳也不能这么写。

## 4 缺陷在哪里（按 MD 修不修得掉）

### 4.1 MD **修不掉**的硬缺陷（审稿人一定会问）

1. **主判别门挡掉同池已知 URAT1 药。** lesinurad 14.11 Å、verinurad 12.30 Å、puliginurad 14.55 Å，A1 与 W2 IFP 全不过。12 个主名单的正确读法是“Top-1 姿恰好酸根锚定的临床酸”，不是“比已知药更可能抑制 URAT1”。给 PF-03882845 跑 200 ns **不能**让这条消失。必须写进 Results/Limitations，不能藏在 SI。

2. **A1 门真实增益弱（LR+ = 2.20），A2 门为零（LR+ = 1.00）。** 备份 21 个在 URAT1 侧基本未筛。MD 只跑主名单里的 1 个，改变不了漏斗统计。

3. **NLRP3 节点不是结合证据。** \(q_N\) 来自细胞 IL-1 分类器，池子已按 \(q_N\ge0.5\) 条件化；7ALV 结构门只说明口袋相容。MD 里 NP3-146 对照稳、候选不漂，仍然只是“这个起始姿在 200 ns 内没散”，不是 NACHT 结合。

4. **PF-03882845 的 MR 通路混杂。** 醛固酮–MR–ROS–NF-κB 本身就能压 NLRP3 输出。这是比 PF-04620110 更干净但仍同类的替代解释。MD 在 7ALV 上“稳”会被审稿人读成“一个酸性分子待在一个疏水口袋里 200 ns”，不能区分直接结合与通路效应。

5. **零前瞻验证。** 门在 URAT1 羧酸 active/decoy 上标定，应用到基本不是 URAT1 药的临床库。可迁移性是假设。*Mol. Divers.* 接受这个（他们也没有）；*JCAMD* 会拿 TRα 文的 ROC/诱饵来比，本项目的回顾集合活性占比 78%，诱饵太弱。

6. **单构象 / 单口袋。** URAT1 只用 9DKB 内向开口态；NLRP3 只用 7ALV NACHT。Nat. Commun. 2025 已写 URAT1 抑制剂结合内向态——这一条有文献支持，但仍不是构象集合对接。W1 其余 29 格没跑，交叉对接矩阵不完整。

### 4.2 MD **可能减轻、但做不好会加重**的缺陷

| 缺陷 | 按预登记做 | 按 *Mol. Divers.* 模板做 |
|---|---|---|
| 对接姿可能是错的 | 晶体对照 + 盐桥占据；对照丢 Arg477 则 URAT1 侧不解释 | 只报候选 RMSD 稳 → 错姿被“验证” |
| 膜蛋白用水盒子 | 9DKB 用 POPC | 和水盒子萜类文同质，还多一个科学错误 |
| 单轨迹噪声 | 3 replica × 200 ns | 1×100 ns 在这本刊也能发，但比不过 TRα / Klebsiella 的多体系 |
| 能量分诱惑 | 禁止 MM-GBSA 当亲和力 | 一写 −XX kcal/mol 优于 lesinurad，就和已知药召回失败打架 |

### 4.3 对两本刊分别会露出的短板

**投 *Mol. Divers.*（更匹配）**

- 他们习惯看对接分和 MM-GBSA。本项目没有这两列，审稿人可能觉得“没排出来”。对策：把 Rank 关闭写成**正结果**（与 2026-06 *JCAMD* 综述同向），用 LR+ 表代替 kcal/mol 表。
- 库只有 156 个临床酸，不像 14 万萜类或超大空间。对策：这是重定位假说，不是 hit-finding；标题和摘要不要写 discovery of inhibitors。
- 双靶不再新。对策：卖“节点可分证伪”（URAT1 摄取 vs 无细胞 NACHT vs MR 敲低），不卖“双靶”。

**投 *JCAMD*（更难，但方法故事更对口）**

- 应用贡献弱：2 个候选（TRα）来自 4 亿库 + ROC；本项目 12 个名字来自 156 酸 + 弱门。
- 方法贡献必须写成：**一个对接分失效的转运蛋白案例，以及几何门替代方案的限度（LR+ 2.2、已知药漏检）。** 短名单是例，不是发现。
- 若正文主叙事是“MD 后 PF-03882845 是双靶候选”，和 2026-09 的 *stable ≠ engagement* 直接冲突。

## 5 做完 MD 之后的诚实总评

**有亮点，但不在 MD，也不是“筛出了双靶药”。**

亮点是近半年两本刊都少见的方法学选择：

1. 自对接失败被当作**停规则**而不是换引擎的理由；
2. 门的判别力用 LR+/OR 说清楚，包括失败的 A2；
3. 名单可审计，人工名单被废掉；
4. （仅当 MD 按预登记做）膜体系 + 晶体对照停规则，不把 RMSD 当结合。

缺陷是科学上的，不是手续上的：

- 主门漏掉已知药；
- NLRP3 不是结合；
- 无前瞻；
- 单槽分子有更简约的 MR 解释；
- 双靶/MD/kcal/mol 在目标刊已商品化。

**MD 的正确用法**：给已经冻住的假说加一条“起始姿在对照可解释的前提下是否保持关键接触”。MD 的错误用法：用轨迹数字把 12 个分子说成比 lesinurad 更好的双靶抑制剂。后者会让这篇在 *Mol. Divers.* 变得和其他无湿文无法区分，在 *JCAMD* 变得和该刊自己的 2026 年主张对着干。

**投稿策略（不改变科学锁）**

- 主投 *Mol. Divers.*：标题用 putative dual-node hypotheses / geometric-gate prioritization，不用 dual inhibitors；MD 一节写接触占据和对照停规则，不写优于对照的 kcal/mol。
- 若改投 *JCAMD*：把“对接分失效 + 几何门限度”提成主结果，12 个名字降为案例表；MD 作为姿态存活的补充，篇幅要短。
- 无论哪本：已知药召回失败、A2 无判别力、MR 混杂、细胞 IL-1 ≠ NACHT，四条必须出现在正文，不能只在 SI。
