## 1. 标题（暂定）

痛风 URAT1–NLRP3 双节点临床药物重定位：基于 TrueDecoy/RandomDecoy 的 URAT1 对接协议筛选与不对称机器学习漏斗

英文见 V2 §3.3。避免 “discovery / Glide XP lead” 气质。

---

## 2. 摘要（五句 · 先验框架语气）

1. 痛风涉及 URAT1 与 NLRP3 双节点；临床库重定位需同时处理两靶数据不对称，并避免默认某一对接读出。
2. 我们预先规定：在 URAT1（9DKB）上用 TrueDecoy（主判）与 RandomDecoy（否决对照）比较开源协议（Vina、gnina、RTMScore），按锁定规则选定 Π\*，并报告自对接三类 RMSD。【⏳ 数字待填】
3. 再以 NLRP3 分类模型（骨架 CV **AUROC 0.893 / AUPRC 0.914**）将 8,319 临床化合物缩至 1,588，按 Π\* 双靶对接并以 Pareto 整合。
4. 漏斗用于检验对照药行为，并将结构警报阳性的盲筛命中降级，在清洁子集上提名可检验假说。
5. 输出为可证伪的计算假说与方法学对照，非双靶抑制剂发现或临床推荐。
