# 对外部投稿评估的逐条裁定（2026-09-05）

对方把匹配度从“8/10 比较稳”降到“边缘到中等、值得尝试”，**这个方向是对的**。  
下面按“成立 / 部分成立 / 过度”裁定，并给出本项目该做与不该做的清单。

---

## 总判断

核心诊断成立：**能不能投 *Mol. Divers.*，取决于“临床库重定位 + 不靠对接分的结构约束框架”这一条贡献，而不是又发现了一个双靶治疗概念。** HNW005（*Eur. J. Med. Chem.* 2025, 10.1016/j.ejmech.2025.117644）和 *Nat. Commun.* 的 compound 32（10.1038/s41467-025-62645-6）已经把“首次双靶/多靶治痛风”堵死。我们原先锁的产品语言（putative dual-node hypotheses，不写 dual inhibitors）正好对上；若写成“发现双靶抑制剂”，desk reject 风险会明显高于方法本身。

工作量足够、scope 不越界，也成立。  
“方法学明显高于该刊同类因此比较稳”——不成立。SERT 文（10.1007/s11030-026-11705-0，2026-08-28）证明该刊**仍收**无湿完整虚筛，但它卖的是 1150 万库 + 新骨架 + MM-GBSA 语言；不是“无实验虚筛很容易”。酪氨酸酶 FEP 文（10.1007/s11030-026-11601-7）有实验 IC50 锚定（FEP \(R^2=0.91\)），不能当纯 prospective VS 先例。

修正后的分数我同意这个量级：方法 8、化学新颖 5–6、靶点证据 5–6、刊匹配 6–7。没有实验就不是 8/10。

## 逐条

| 对方主张 | 裁定 | 说明 |
|---|---|---|
| 刊 scope 没问题 | **成立** | 临床酸库 + 微状态 + 结构门是 chemistry-driven screening |
| 近半年高度可比的无湿 prospective VS **并不多** | **成立** | 必须把 SERT 当强先例，不能当“很常见所以稳” |
| SERT：3660 训练 / 1150 万筛 / 无新湿实验 | **成立** | 摘要核过。MD 最终点名是 **3** 个 lead（不是 5）；对方表里“5 个 × 3×100 ns”略不准 |
| 酪氨酸酶文有实验锚定，不是纯虚筛 | **成立** | |
| 不能写“首次双靶策略 / 首次发现双靶候选” | **成立，且最重要** | HNW005：NLRP3 激活 IC50 1.7 µM、\(K_D\) 204.6 nM、URAT1 转运 IC50 6.4 µM + 动物；compound 32：URAT1/GLUT9/OAT4/NLRP3 + 表型。我们的创新只能是**临床化学空间 + 几何门框架** |
| 相对 SERT：方法更严、发现证据更弱 | **成立** | 规模和 chemotype novelty 输；对接 QC、诱饵、膜 MD、关排序轨赢。不能抄 “novel inhibitors” |
| \(q_N\) 是表型富集不是 NACHT 结合 | **成立，但我们已锁** | 正文已禁止 binding prediction。对方当作新缺口，其实是必须守住的旧锁 |
| A1 是中等富集（LR+ 2.20）不是活性分类器 | **成立，已锁** | |
| NLRP3 结构门 n=9 阳性，CI 很宽 | **成立** | 9/9 的 Wilson 95% 下限约 0.70。必须报区间。是否“只认 MCC950 骨架”要查，但**不要为了好看去扩面板再调阈值** |
| 9DKB 单构象不够；应做 receptor-sensitivity | **部分成立** | 9B1I（verinurad）、9B1G（dotinurad）是真结构。值得做**有限几何检查**，不值得重开分数排序或把 W1 其余 29 格当解锁 |
| 单槽 MD 像 case study | **部分成立** | 虚筛文叙事上 2–3 个不同骨架更好。单槽不是不能投，但标题/摘要必须像框架文，不能像 PF 专论 |
| 泄漏 / 最近邻 / 已知活性审计 | **成立，且便宜，投稿前必做** | `acid_a2_eligible_audited.csv` 已有 `max_tanimoto_nlrp3_train`，缺：与 513 训练 exact match、与已知 URAT1/直接 NLRP3 抑制剂 Tc、文献/专利是否已报 PF 的新靶关系 |
| 规则太细会被疑事后调参 | **部分成立** | 要写清预登记 vs 校准。阈值敏感性（+0.5/+1.0/+1.5 Å）便宜该做。把 9/40 再切 held-out 报性能 = 样本不够，**过度** |
| 无实验是最大不确定因素；审稿人会问为何不测 PF | **成立** | 比 SERT 更难答：SERT 是新商业骨架，PF 是现成临床期分子 |
| 五件补强里 1、2、4 最重要 | **部分成立** | 我把优先级改成：**1（泄漏审计）> 3 的廉价部分（CI + 阈值敏感性）> 4 的有限构象检查**。第 2 条（重做 assay-group split / Brier）对已冻短名单不是阻断项 |

## 值得做（投稿前，零或极少新对接）

1. **Novelty / leakage 表（必做）**  
   12 个主名单 + PF：对 NLRP3 训练 513、已知直接 NLRP3 抑制剂、已知 URAT1 抑制剂做 exact SMILES / InChIKey 与 ECFP4 max Tc；文献/专利检索“是否已有 URAT1 或 NLRP3 活性”。目的是 **new target annotation，不是新骨架**。

2. **把已有统计写完整（必做）**  
   A1 / IFP / W4 补 OR 与 LR+ 的区间；W4 9/9 报 Wilson CI；点明 A2 LR+ = 1。不调阈值。

3. **阈值敏感性（该做，很便宜）**  
   Arg 门 +0.5 / +1.0 / +1.5 Å 时 12 个名字是否大体稳定。证明 +1.0 Å 不是为假阳性最小搜出来的。

4. **有限 receptor-sensitivity（该做，但要收口）**  
   只对已冻的 12 个（至少 PF + 1–2 个不同骨架）在 **另一个 inward 实验构象**（优先 9DKA 或 9B1I）上查酸根–Arg477 与 Phe 笼是否还在，**不按 CNNscore 重排**。NLRP3 可加一个非 NP3-146 共晶（如 GDC-2394 口袋）做同样的几何检查。不要把这变成第二套虚筛。

5. **MD 若还能加预算：2–3 个 tier1，3×100–150 ns**  
   比把全部算力堆在 PF 的 3×200 ns 更像筛选文。资源锁死就保持单槽，正文改成“框架 + 一个预登记案例”，不要装成 12 选 1 的全面动力学筛选。

## 过度 / 不要做

| 建议 | 为何过度 |
|---|---|
| 为了像 SERT 去筛千万级商业库 | 换科学问题。本文是临床重定位，不是 hit-finding |
| 重训 NLRP3、改 assay-group split 后**重挑短名单** | \(q_N\) 只是池先验。诊断性 split 可以进 SI；用新 split 改 12 个名字是事后改规则 |
| Brier / 概率校准作为投稿阻断项 | 有则加一句“model score 不是 calibrated probability”；没有不挡投稿 |
| 扩 W4 阳性到 GDC-2394/NP3-562 再调结构门 | 阈值已冻。最多 SI 注释，禁止重标定 |
| 9/40 再切 calibration / held-out | n 不够，数字会更吵 |
| 完成 W1 其余 29 格当推进条件 | 已锁 optional SI |
| 用 MM-GBSA/FEP 给 URAT1 补名次以“更像该刊” | 违反本项目锁，也和已知药漏检打架 |
| 无实验室条件下把 HEK293 摄取 + IL-1β 写成必须 | 有条件做，风险会掉一大截；**没有就不能投计算稿**。那是另一篇论文，不是这篇的计算过度，但也不该当成计算清单的第 6 项 |

湿实验是**另一条产品线**：能做两条最便宜的（PF ± 1–2 个备份的 URAT1 摄取 + NLRP3 依赖 IL-1β），匹配度会过 7。做不到，就按框架文投，接受 6–7 和 major revision 风险。
