# 结论初稿（中文）

> 与 [`PROJECT_CLAIM_REFRAME.md`](PROJECT_CLAIM_REFRAME.md)、[`MANUSCRIPT.md`](MANUSCRIPT.md) 同步。  
> 主结论：URAT1 对接读出不够用，**不从 P2 百分位鉴定双节点 hit。**  
> 7 个名字不是正文产品。未完成的 MD 不得写成结合或 lead 验证。

## 5 结论

在与临床库无关的 URAT1 TrueDecoy / RandomDecoy 基准上比较六种对接与重打分读出。规则幸存者是 gnina CNNaffinity（P2），但其绝对性能达不到多样化库虚拟筛选的可用门槛：TrueDecoy AUC 0.58、EF@1% 2.59；RandomDecoy AUC 0.54、EF@1% 0.22（95% 区间含 0，与随机无法区分）。临床重定位库的化学型更接近 RandomDecoy。因此 **P2 不能当作筛选活性读出**，也不能用双靶百分位门控去鉴定痛风双节点候选。P1/P3/P4 在 TrueDecoy 上与随机无法区分；P5 在 RandomDecoy 前 1% 命中为零；P0 虽两侧较均衡，但是预注册的姿态置信度负对照，且自对接 Top-1 同样失败。六个读出中没有一个同时满足“性质匹配诱饵上可用、随机诱饵上可用、第一构象近原生”。更干净的结论是停用对接排名，而不是把淘汰赛冠军写成生产协议。

将该弱读出迁到 8,319 个临床小分子上，结果与基准一致而不是相反：已知促尿酸药或因 NLRP3 分类器 \(q_N=0\) 未进对接池，或在池内百分位不高（lesinurad \(S_U=45.9\)，verinurad \(S_U=3.4\)）；裸 Pareto 被大环骨架占据。这些不是“库里没有双节点分子”，而是 **对接分在本设定下不携带可用的活性信息**。lesinurad 的 P2 第一构象质心仍在口袋内，但羧酸–Arg477 约 14 Å，进一步说明该读出不是结合模式证据。

NLRP3 分类器（AUROC 0.893）只用于缩库，标签是细胞 IL-1 相关抑制，分数在临床库上高度饱和，不得解释为 NACHT 结合。若仍对 P2 双分前 10% 施加化学过滤，会得到 7 个命名分子（含 GSK-3008348、Vecabrutinib）。该表保留在 SI，作为与排名挂钩的启发式湿实验面板，**正文不称为优选候选、lead 或双节点计算候选**。湿实验若开展，纳入标准应与 P2 百分位脱钩：例如按羧酸选择 URAT1 摄取面板、按炎症文献或 IL-1 模型选择 NLRP3 面板，两端各自证伪，不把对接排序当作已经成立的双节点证据。

分子动力学按晶体对照 + P2 选出姿势的六体系做口袋压力测试，回答的是姿稳不稳，不回答活不活性。本稿不报告轨迹数值。痛风双节点在指南里仍是两个药覆盖两个节点；本计算漏斗不能提供“同一临床分子同时覆盖两端”的筛选证据。后续工作应是新的 URAT1 评价方法（实验摄取为主），或明确与对接排名脱钩的湿实验设计，而不是继续降低百分位门槛或更换读出。

## 摘要末句

预先锁定的诱饵基准表明，gnina CNNaffinity 等 URAT1 对接读出不足以在多样化临床库上筛选活性；据此不能从对接百分位鉴定 URAT1–NLRP3 双节点候选。
