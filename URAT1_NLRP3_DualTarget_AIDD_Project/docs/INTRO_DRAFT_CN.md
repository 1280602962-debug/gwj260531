# 引言初稿（中文）

> 作者备忘（勿进投稿正文）：先验三阶段叙事；不写换方法日记；Methods 见 [`METHODS_DRAFT_CN.md`](METHODS_DRAFT_CN.md)。正文引用用“作者，年份”，DOI 见文末清单。

痛风是成人最常见的晶体性关节炎之一。当血尿酸长期升高，单钠尿酸盐可在关节及其周围沉积；巨噬细胞识别晶体后激活 NLRP3 炎症小体，经 caspase-1 将前体白细胞介素-1β 加工为活性形式，从而触发急性炎症发作（Dalbeth 等，2021；Leask 等，2024；Martinon 等，2006）。尿酸主要来自肝脏嘌呤代谢。多数患者的高尿酸血症并非生成过多，而是肾脏或肠道排泄不足；近端小管尿酸盐转运体 URAT1（由 *SLC22A12* 编码）承担约九成尿酸重吸收，因而是降尿酸治疗的关键靶点（Dai 与 Lee，2024；Lin 等，2024）。由此可见，临床管理往往需要同时应对两个相互关联却机制不同的节点：一是降低血尿酸，二是抑制晶体驱动的炎症反应（Zhao 等，2023）。

现有药物大体沿这两条轴线展开。降尿酸方面，黄嘌呤氧化酶抑制剂（如别嘌醇、非布司他）减少尿酸生成；促排泄药物中的 URAT1 抑制剂（如苯溴马隆、lesinurad、dotinurad，以及处于临床研究中的 verinurad）可占据底物结合区并稳定转运体内向构象，阻断重吸收（Suo 等，2025；Wu 等，2025）。抗炎方面，急性期常用秋水仙碱、非甾体抗炎药与糖皮质激素，必要时使用白细胞介素-1 相关生物制剂。然而上述方案仍有明显局限。别嘌醇在 HLA-B*5801 阳性人群中存在严重超敏风险；非布司他的心血管安全性在不同试验间结论并不完全一致，高危患者仍需权衡（Borghi 等，2023）；苯溴马隆受肝毒性制约，lesinurad 亦因肾脏安全性影响使用。长期治疗中，血尿酸达标率并不理想，依从性下降会进一步削弱效果。抗炎药物起效较快，但多偏对症；以 MCC950 为代表的 NLRP3 直接抑制剂虽机制清楚，却因安全性问题未能进入常规治疗。若将降尿酸与抗炎简单联合，还可能增加药物相互作用与不良反应负担。

痛风还常与心血管疾病、代谢综合征、脂肪肝、慢性肾脏病及糖尿病等并存。在这种合并症背景下，从全新化学实体推进到临床可用往往周期长、淘汰率高；相比之下，已进入临床阶段的化合物通常具备一定的人体安全性与药代信息，更适合作为重定位筛选的起点。基于此，我们以临床阶段小分子库为化学空间，系统评估其中是否存在同时关联 URAT1 与 NLRP3、并值得实验跟进的候选，而不是事先指定某一分子作为研究终点。

要实现上述目标，计算流程必须正视两个靶点在数据与机制标签上的不对称。URAT1 属于多构象膜转运体，公开活性数据噪声较大；若回归模型对已知尿酸药的基准回收不足，则不宜再用其分数主排临床库，而应以结构对接提供 URAT1 一侧的排序证据（Dai 与 Lee，2024）。即便采用对接，也不能默认某一引擎或某一诱饵设定：随机负样本往往夸大表观富集，性质匹配的负样本更能检验排序协议是否稳健。因此，本研究将 Gu 等提出的 TrueDecoy 与 RandomDecoy 双诱饵评估框架（Gu 等，2025）纳入设计的第一阶段：在 URAT1 的 inward-open 结构（PDB 9DKB）上，按事先固定的富集与对照回收规则，于开源对接与重打分方案中选定生产用排序协议，再进入后续筛选。NLRP3 一侧则以分类模型负责缩小化学空间；结构分析采用分辨率约 2.8 Å 的 NACHT 结构（PDB 7ALV，共晶配体为 MCC950 类类似物 NP3-146），对接与分子动力学主要用于检验结构是否合理，而不替代机器学习作为该侧的主证据（Dekker 等，2021）。

综合以上考虑，本文报告一条事先规定、可逐步复核的 URAT1–NLRP3 双节点计算流程。流程依次完成对接协议筛选、NLRP3 机器学习缩库、双靶对接百分位与 Pareto 整合，以及成药性与结构警报审计后的假说提名。其输出是可证伪的计算假说与方法学对照结果，并不等同于已经证实的双靶抑制剂，也不构成临床用药建议。
