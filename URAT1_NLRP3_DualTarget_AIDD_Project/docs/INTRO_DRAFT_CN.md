# 引言初稿（中文；保留版）

> 按作者确认保留此版本（范文风格润色版），不再使用后续更口语的去 AI 腔改写。

痛风是一种慢性炎症性关节炎，其特征在于单钠尿酸盐（MSU）晶体在关节或周围组织中沉积，并经由 NOD 样受体蛋白 3（NLRP3）炎症小体介导的 IL-1β 反应触发炎症（Dalbeth et al., *Lancet* 2021, https://doi.org/10.1016/S0140-6736(21)00569-9；Leask et al., *Nat Rev Rheumatol* 2024, https://doi.org/10.1038/s41584-024-01137-1）。高尿酸血症是痛风的基本病理基础，主要源于嘌呤代谢紊乱或血清尿酸排泄不足。尿酸为肝脏嘌呤代谢终产物，多数患者的高尿酸血症以排泄障碍为主。肾近端小管中，尿酸盐转运体 1（URAT1，*SLC22A12*）介导约 90% 的尿酸重吸收，是调控血尿酸稳态的关键靶点（Dai & Lee, *Cell Res* 2024, https://doi.org/10.1038/s41422-024-01023-1；Lin et al., *Signal Transduct Target Ther* 2024, https://doi.org/10.1038/s41392-024-01916-y）。沉积的 MSU 晶体可被巨噬细胞识别，经预激与激活两步过程启动 NLRP3 炎症小体，再由 caspase-1 将 pro-IL-1β 剪切为活性 IL-1β，推动急性发作（Martinon et al., *Nature* 2006, https://doi.org/10.1038/nature04516；Zhao et al., *Front Immunol* 2023, https://doi.org/10.3389/fimmu.2023.1137822）。因此，痛风治疗通常需要同时考虑降低血尿酸与控制晶体诱导的炎症反应。

目前抗痛风治疗仍以药物干预为主，长期降尿酸有助于促进 MSU 晶体溶解，减少急性发作与痛风石形成，并改善生活质量。现有小分子降尿酸药主要包括黄嘌呤氧化酶抑制剂（如别嘌醇、非布司他）与促尿酸排泄药。后者中，URAT1 抑制剂可通过阻断肾小管尿酸重吸收升高尿酸排泄，代表性药物包括苯溴马隆、雷西那德（lesinurad）、多替诺雷（dotinurad）以及仍处临床研究阶段的 verinurad。结构药理学研究表明，这类抑制剂可在 URAT1 底物结合区域竞争尿酸并稳定内向构象，从而抑制转运功能（Fedor/Suo et al., *Nat Commun* 2025, https://doi.org/10.1038/s41467-025-60480-3；Wu et al., *Cell Discov* 2025, https://doi.org/10.1038/s41421-025-00779-z）。炎症控制则主要依赖秋水仙碱、非甾体抗炎药、糖皮质激素及 IL-1 相关生物制剂。然而，现有药物仍有明显不足。别嘌醇在 HLA-B\*5801 携带者中可诱发严重超敏反应，东亚人群尤为关注。非布司他自 CARES 试验后长期伴随心血管安全性讨论，后续 FAST 试验虽未显示明确风险升高，相关结论仍不完全一致，高心血管风险患者需谨慎评估（Borghi et al., *Cardiol J* 2023, https://journals.viamedica.pl/cardiology_journal/article/view/98254）。苯溴马隆存在肝毒性并在部分地区受限使用，雷西那德也因肾脏安全性问题影响临床应用。即使规范治疗，仍有相当比例患者难以长期达到目标血尿酸水平，依从性不足进一步削弱疗效。与此同时，传统抗炎药起效较快，但多为对症处理，难以从上游持续阻断晶体诱导的炎症级联。MCC950 等 NLRP3 抑制剂虽机制清晰，却因安全性问题未能顺利转化为成熟疗法。由此可见，单纯降尿酸或单纯抗炎都难以充分覆盖痛风的代谢—炎症双重病理，联合用药又常增加相互作用与不良反应风险，开发更安全、更适合合并症人群的治疗策略仍有现实需求。

大量研究表明，痛风与高尿酸血症常伴随心血管疾病、代谢综合征、脂肪肝、慢性肾脏病和糖尿病等共病状态（Cleveland Clinic J Med 2024, https://www.ccjm.org/content/91/7/392；Front Cardiovasc Med 2023, https://doi.org/10.3389/fcvm.2023.1190069）。这意味着治疗方案往往需要在降尿酸与抗炎之外兼顾整体代谢与器官保护背景。全新分子从发现到临床应用周期长、不确定性高，而已经进入临床阶段的药物通常具备较完整的安全性、药代动力学与人体暴露信息，一旦出现新的计算或药理信号，转化路径相对更短，也更贴近真实患者的合并用药场景。基于这一考虑，我们选择以临床阶段药物库作为计算筛选对象，系统评估其中是否存在可同时关联 URAT1 与 NLRP3 双节点、并具备可检验结构假说的候选，而不是事先指定某一化合物。

本工作的目标是建立一条可复现、可核查的临床库双节点（URAT1–NLRP3）重定位流程，并在两靶数据条件不同的前提下提出可被实验检验的候选假说，而不是直接宣称获得已验证的双靶抑制剂。URAT1 属于膜转运体，存在内向开放、闭塞与外向等多种构象（Dai & Lee, *Cell Res* 2024, https://doi.org/10.1038/s41422-024-01023-1）。其公开活性数据噪声较大，机器学习回归对已知尿酸药的回收不够稳定，因此后续排序更依赖对接证据，同时也需要回答哪一种搜索与打分组合更适合该靶点。NLRP3 的抑制位点位于 NACHT 结构域。全长蛋白常形成大型寡聚组装，整体分辨率往往难以直接支撑精细的小分子对接网格，因此我们采用分辨率约 2.8 Å 的 NACHT 结构 7ALV 作为对接与后续分子动力学模板。该结构结合的是 MCC950 类抑制剂类似物 NP3-146，可用于表征磺酰脲类相关结合口袋（Dekker et al., *J Mol Biol* 2021, https://doi.org/10.1016/j.jmb.2021.167189）。在这一安排下，NLRP3 一侧以分类机器学习承担临床库缩库的主要任务，对接与分子动力学用于提供同一口袋假设下的结构支持。为使 URAT1 对接排序建立在可比较的基准上，我们参考 Gu 等提出的 TrueDecoy 与 RandomDecoy 评估思路（Gu et al., *Nat Mach Intell* 2025, https://doi.org/10.1038/s42256-025-00993-0），构建面向本靶点的性质匹配诱饵集与随机诱饵集，分别考察不同开源对接与重打分协议，并将较优协议进一步用于后续临床库筛选，而不是停留在方法对照本身。

据此，本研究拟建立一条覆盖 URAT1 对接协议选择、NLRP3 机器学习缩库、双靶对接整合与成药性审查的端到端流程，为痛风相关双节点重定位提供可重复的计算框架。其预期输出是经过审查的候选假说与相应方法学结论，后续仍需实验验证，不能等同于双靶抑制剂发现或临床用药推荐。
