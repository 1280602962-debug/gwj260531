# C5 虚筛全过程（一段话，含预登记 MD / MM-GBSA）

> 对接至短名单冻结为已完成事实。MD / MM-GBSA 为预登记协议（`w5_md`，`md_authorized` 仍为 false），正文不得提前填写轨迹数值。MM-GBSA 只许池内相对比较，不得当作亲和力或用来给 URAT1 重排名次。

临床重定位库先用 ChEMBL 清洗的人源 NLRP3 细胞 IL-1 相关抑制记录（513 个分子 / 39 个测定，不是 NACHT 结合测定）训练 XGBoost 分类器，按 \(q_N\ge0.5\) 将库缩至 1,588 个分子；再以羧酸 / 四氮唑 / 酰基磺酰胺 SMARTS 留下酸等效物 303 个，并以 Veber、氢键 RO5 与分子量 200–550 的软药化门得到 156 个临床期酸性分子作为对接池。全部配体按 Dimorphite-DL 在 pH 7.4 枚举微状态（羧酸脱质子；苯溴马隆用已冻结的酚负离子），经 Meeko 嵌入（种子 `0xC0FFEE`）后，用 GNINA 1.3.1（本机二进制若为 1.3.2 则参数不变）在 URAT1 内向开口态 9DKB 与 NLRP3 NACHT 共晶 7ALV 上各做三种子（42/43/44）对接：exhaustiveness = 32、num_modes = 9、`cnn_scoring=rescore`，盒子分别锁定为 9DKB `[99.966, 102.967, 105.699]` 22³ 与 7ALV `[16.756, 35.449, 125.714]` 20³。因 lesinurad@9DKB 与苯溴马隆@9DKA 的 CNNscore Top-1 `pose_rmsd` 分别为 4.30–4.88 Å 与 3.59 Å（best-of-9 约 1.11 Å，属搜得到但选不中），对接分排序轨关闭，不以 CNNscore / CNNaffinity / MM-GBSA 给 URAT1 排名次。URAT1 主门改为晶体相对几何：CNNscore Top-1 姿的酸根氧–Arg477 氮最短距离 ≤ 7.7027 Å（沉积 A1AIL 最短 6.7027 Å + 1.0 Å），该 A1 门在 228 个羧酸活性物对 64 个羧酸真诱饵上 OR = 3.18、LR+ = 2.20；九姿中“存在可解释姿”的 A2 门 OR ≈ 0.97、LR+ = 1.00，故不作判别器。NLRP3 臂要求口袋重叠、相对 NP3-146 的 IFP Jaccard、关键残基接触与无冲突的结构门，并在 9 个阳性对 40 个性质匹配诱饵上复测（seed42 结构门 9/9 vs 11/40，比宽松门少 4 个假阳性）。随后用沉积晶体坐标（R75 / A1AIL / A1A45，Kabsch 到 9DKB）锚定 URAT1 IFP 作更严注释而不改名单；化学审计以 PAINS / Brenk / NIH / 聚集启发式及 β-内酰胺 SMARTS 代替药名黑名单。短名单由纯集合交冻结：tier1 = A1（seed42 双臂）∩ A2 结构门 ≥2/3 种子 ∩ 化学合格，去掉结构对照 GSK-3008348 后得 12 个可报告主名单；tier2 为其余 A2≥2/3 且化学合格者，去掉 3 个头孢后得 21 个备份（备份在 URAT1 侧基本等于未筛，不得称次优候选）。单槽 MD 分子按已锁优先顺序预登记为 PF-03882845。动力学阶段（尚未授权开跑）固定两套晶体对照——lesinurad 晶体羧酸根姿于 9DKB/POPC 膜体系、NP3-146 共晶姿于 7ALV 水盒子——与候选在两靶各跑 3×200 ns；URAT1 读出为酸根–Arg477 盐桥占据、关键接触持久性与配体 RMSD，NLRP3 读出为关键残基 IFP 持久性、口袋重叠时间序列与配体 RMSD。对照丢失 Arg477/Phe 笼则 URAT1 侧全部不解释，NP3-146 漂出则 NLRP3 侧全部不解释。轨迹平衡段上的 MM-GBSA 只在同一池、同一靶、同一力场设置内作相对比较，用来看候选相对晶体对照的接触能是否同号、是否同量级，明确不解释为 \(\Delta G\)、\(K_\mathrm{i}\) 或活性名次，也不允许据此把名单重排；MD 合格仅表示起始姿在对照可运行的前提下未立刻离开口袋，不等于双靶成立，更不替代 HEK293-URAT1 摄取或无细胞 NACHT / IL-1 测定。
