## 1 闸门失败是什么意思

对接分两步：搜索（摆出 9 个姿态）和选择（CNNscore 把第一名当生产姿）。

苯溴马隆自对接 @ 9DKA × seeds 42/43/44：

| 看什么 | 结果 | 含义 |
|---|---|---|
| 9 姿里最好的（mode 3）`pose_rmsd` | 1.110 / 1.087 / 1.109 Å | **搜得到**晶体盆 |
| CNNscore 第一名 `pose_rmsd` | 3.585 / 3.603 / 3.595 Å | **选不中** |
| 预登记门槛 | Top-1 ≤ 2.0 Å | **闸门仍失败** |

准备 QC 通过（盒子、无残留 R75、酚负离子）。`GetBestRMS`（先叠合再比，≈1.65 / 0.48 Å）是构象相似度，**不得**用来改判闸门。lesinurad@9DKB 更早就是同一类（Top-1 4.30 / 4.31 / 4.88 Å）。

**一句话**：口袋和准备没有坏。GNINA 找得到晶体盆。用来当第一姿的神经网络分，在 URAT1 上选不对。

原规则只写了“苯溴马隆失败→停，不准进 W2”，没区分原因。分岔（准备出错 / 搜得到选不中 / 口袋装不下）是在只看到 Top-1 数字时登记的。数值门槛未改、仍失败。W4 与本闸门无科学依赖。W2 改为锚定**晶体沉积坐标**，不用 CNNscore 失败姿。

## 2 这样筛有效吗 / 对接能不能给 URAT1 排序

**按对接分数给 URAT1 排序：没有这个能力。** `rank_track` 已关闭。正文禁止把 CNNscore / CNNaffinity 当亲和力或 Ki。

分层说：

| 层 | 有效？ | 证据 |
|---|---|---|
| CNNscore / CNNaffinity 名次 | **无效（已关）** | 两个已知药 Top-1 都偏 3.6–4.9 Å |
| 搜索（9 姿里有没有晶体盆） | 还有 | 苯溴马隆 best-of-9 ≈ 1.11 Å |
| 几何门 A1（第一姿酸根近 Arg477） | 有回顾富集，不是发现 | 228 vs 64：OR = 3.18，p ≈ 4.5×10⁻⁴；灵敏度 0.45 |
| 几何门 A2（9 姿里有一个说得通） | **无判别力** | OR ≈ 0.97，p = 1.0 |
| NLRP3 自对接选姿 | 有效 | NP3-146 Top-1 0.67–0.82 Å |
| NLRP3 结构门（W4 vs 诱饵） | 对性质匹配诱饵有效 | seed42 结构 9/9 vs 11/40，比宽松少 4 个假阳性；临床酸背景上仍等于宽松门 |

因此：对接在 URAT1 上**不是排序器**。它只剩下“生成姿态 → 几何/IFP 做二元过滤”。名单没有可靠的 URAT1 对接分名次。短名单里很大一块走的是 A2，不是那个有统计信号的 A1。

## 3 近半年 *Molecular Diversity* 同行怎么排

检索日 2026-09-05。对照的是路线文档点过的几篇，外加能核到方法的 2026 年虚筛文。

| 论文 | DOI / 刊出 | 湿实验 | 排序字段 |
|---|---|---|---|
| Klebsiella PBP3 + KPC-2 萜类双靶（Gyebi & Sabiu） | 10.1007/s11030-025-11429-7（2025-12） | 无（写 in vitro underway） | 药效团 → AutoDock/Vina 分 → MD 后 MM-PBSA/GBSA |
| CERS2（Yu 等） | 10.1007/s11030-025-11436-8（2026-01） | **有**酶活 + LC-MS/MS | Glide HTVS/SP/XP 分（−6.5/−7.0/−7.5）→ MM-GBSA |
| PCOS 3β-HSD1（Ranjan & Krishnasamy） | 10.1007/s11030-025-11437-7（2026-01） | 无 | 对接分 ≤ −8.0 + ADME → 200 ns MD |
| M3 抗毒蕈碱（Gill 等） | 10.1007/s11030-025-11208-4（2025-05 / 2026-02 卷） | 无 | 3D-QSAR 药效团 → 对接 → MM-GBSA → MD |
| µ 阿片偏倚激动剂（Rajkumar 等） | 10.1007/s11030-026-11511-8（2026-03） | 无（标题 putative） | QuickShape → Glide → BBB → MD + MM-GBSA |

标准漏斗：药效团/形状缩小库 → **对接分截断** → 作用看起来像共晶 → ADMET → MM-GBSA → MD RMSD“稳”→ 点 2–5 个名字。

他们几乎从不报回顾 OR/Fisher，也几乎从不因自对接选姿失败而关掉排序轨。

**CERS2 订正**：路线文档曾把它和那几篇无湿文并列；摘要写了重组酶和脂质组学，**不是无湿文**。无湿对照是 Klebsiella、3β-HSD1、M3、µ 阿片。

**和本项目像不像**：产品形态（双靶、无湿、点名）最像 Klebsiella 那篇；方法不像。近半年这本刊里**没有**“已知药自对接 Top-1 失败 → 宣布对接分无排序能力 → 改几何门”的同类。不要学他们用 CNNscore/MM-GBSA 给 URAT1 补名次。

## 4 对接不能排之后，还要不要另开排序轨

**不要。** 该试的已经试过或写进禁令。

| 方法 | 决定 |
|---|---|
| 换对接引擎 / MM-GBSA / FEP 当亲和力 | **禁止**（错姿上的能量分更没有意义） |
| 重训 URAT1 ML（XGBoost / Chemprop / kNN） | **禁止**。已试 7 种，OOF R²≈0.53，lesinurad/dotinurad 回收不了 |
| 与已知药 Tanimoto/形状 | 只许当**化学注释**（近=已知型，远=更新但更无把握），不当活性名次 |
| 晶体 IFP / 关键接触完整度 | **唯一还该做的 URAT1 量化** = W2（0 个新对接） |
| 多种子 3/3 vs 2/3 | 已在 W3 分层里用，是优先顺序不是活性名次 |
| NLRP3 结构门 / \(q_N\) | 双靶名单的**第二关键字**（该臂自对接过了） |
| MD 盐桥占据 | W5，短名单已冻；仍须显式授权后才开 2–3 个主名单分子 |

论文顺序只能写成：几何/IFP 门 → 多种子分层 → 化学审计。不能写成对接分或 ML 分排出的 dual inhibitors。
