# 对照 *Molecular Diversity* 近三年对接筛选文：回顾与修改计划

> 目的：在**不重锁 Π\*** 的前提下，把现有漏斗改写成该刊能接受的“命名候选 + 化学审计”稿，并规定哪些门槛可以放宽、哪些不能动。  
> 生产排名读出仍是 **P2（gnina CNNaffinity）**。本文件不是重新选协议。

## 1. 近三年该刊对接筛选文实际在做什么

Aims **没有**要求 MD，也没有要求双诱饵。近三年（约 2023–2025）以“库筛选 → 对接 → 命名 hit”为主的原研，社区模板高度同质：

| 环节 | 典型 Mol Divers / 同类筛选文 | 本课题现状 |
|------|------------------------------|------------|
| 库 | DrugBank / FDA 约 1,000–2,500，或 ZINC 子集 | ChEMBL 临床+ATC **8,319**（更贴重定位，规模更大） |
| 靶点数 | **单靶**，按对接分取 Top N | **双靶 AND 门控**，τ=90 |
| 引擎 | AutoDock Vina / Glide，少做协议比较 | 先比较 P0–P5 再锁 P2（更严，也更不像该刊模板） |
| 类药 | Lipinski ± ADMET 口算 | Veber + Ro5 氢键/logP + MW 200–550 + 降级大环（更严） |
| 阳性对照 | 共晶配体或已知抑制剂常排在前面，或根本不报回收 | lesinurad / verinurad **未进门控** |
| 正文分子 | **2–5 个命名药** + 相互作用图 | 表 2 有 7 个，跟进 2 个，但叙事像方法文 |
| MD | 几乎都有 **~100 ns**，对照 1 个参考配体，常加 MM-GBSA | 仅有体系搭建，**无轨迹** |
| 主张 | 常写成 potential inhibitor | 已正确降为假说生成；标题/摘要仍偏方法 |

差距不在“库里没有分子”，而在 **产品形态**：该刊要看见可点名的 2–3 个临床分子、一张类药/ADMET 表、（最好）对照校准的短 MD。我们把门槛加到 τ=90 双 AND + 构象金标准 + 多协议共识后，看起来像“筛不出来”。

## 2. 回顾：候选已经存在，卡住的是门槛而不是库

在已归档的 1,580 完整案例上复算（不重对接）：

| 规则 | 门控 n | 无 PAINS/Brenk 且 Veber + Ro5 属性 | 再加 MW 200–550（优选口径） |
|------|------:|------:|------:|
| 双对接 τ=95 | 21 | 4 | 3 |
| **τ=90（现行正文）** | **51** | 14 | **7** |
| τ=85（已有 `candidates_tau85/`） | 85 | 18 | **8**（多 Bafrekalant） |
| τ=80 + 全 Module F | 131 | 29 | **19** |
| τ=80 + 仅警示/Veber/MW（先前说的 27） | 131 | — | **27** |
| τ=75 / τ=70 全 Module F | 180 / 234 | 45 / 68 | 30 / 49 |

羧酸且类药、双轴 ≥90 的只有 **GSK-3008348**。Vecabrutinib 不是酸，但是 NLRP3 分类器与对接双高。

已知痛风药：benzbromarone / probenecid / dotinurad 等 \(q_N=0\)，**没进对接池**；lesinurad、verinurad 进了池但 P2 百分位低。这是漏斗顺序 + 读出问题，不是 8319 选错库。

**结论：** 想要的“候选分子”用现有 P2 分数就能给。需要改的是**提名呈现和对照实验**，不是换临床库，也不是把 Π\* 改成 P4/P5。

## 3. 可以放宽什么，不能放宽什么

### 可以放宽（提名启发式，须写成敏感性，不能假装本来就是）

1. **双百分位 τ：90 → 85 或 80。** 90 没有生物学唯一性。85 优选 8；80 全化学规则优选 19。正文主表仍用 90 的 7 个，80/85 进 SI 或“扩展短名单”。  
2. **跟进分子数：2 → 3。** 该刊习惯 3 个命名药。建议固定：**GSK-3008348（URAT1/羧酸）+ Vecabrutinib（NLRP3 双证据）+ 第三者仅作化学多样性对照（Zelenirstat 或 Bafrekalant），不升格为第二故事药。**  
3. **27 人名单作为 SI 探索性集合**（80/80 + 无警示 + Veber + MW，不加满 Ro5 属性、不要求 oral_absorption）。正文不把 27 都写成优选。  
4. **MD 有无：** 该刊模板想要，但不是 Aims 硬门槛。没有合格起始姿就不要编 100 ns。

### 不能放宽（一放就变成事后换协议或越界主张）

1. **不把 Π\* 从 P2 改成 P0/P4/P5** 来让 lesinurad 变高分。协议锁在看临床库之前；事后换读出等于 p-hacking。P4/P5 只可用于**对照姿 / 敏感性打分**，不能重排 1580 的主表。  
2. **不取消 NLRP3 缩库再对 8319 全库做双靶对接**（除非另开一篇“URAT1 单靶重定位”）。那是换科学问题。  
3. **不把大环 Pareto、EGCG、Spiroglumide、Tegoprazan 写成 hit。** 后两者双轴未过门控。  
4. **不用 Glide 分数混进主表。**  
5. **不把对接分、MM-GBSA、MD RMSD 写成 \(K_i\) 或双靶抑制剂鉴定。**  
6. **不把 known uricosurics 改标成新命中**；它们只做回收对照。

### 不是“放宽”，是应做的方法修正

- 羧酸 **pH 7.4 羧酸根** 枚举后，对 lesinurad / verinurad / GSK-3008348 重对接或重打分：这是配体准备漏洞，不是改 τ。  
- 已知 URAT1 药 **强制对接**（不受 \(q_N\ge0.5\) 限制），单独做回收表。  
- MD 用晶体 lesinurad（羧酸根）作对照，而不是用失败的 P2-lesinurad 姿去“验证”候选。

## 4. 目标产品形态（按 Mol Divers 改故事，不改科学主张）

**标题方向（示例，勿写 dual inhibitors discovered）：**  
*Protocol-first dual-node repurposing of a clinical library against URAT1 and NLRP3: chemistry-aware nomination of computational hypotheses*

**正文三层名单（必须同时出现，避免“一个都没有”）：**

| 层 | 内容 | 主张 |
|----|------|------|
| A. 优选（主表） | τ=90，7 个 | 锁定规则下的短名单 |
| B. 跟进案例 | GSK-3008348、Vecabrutinib | 可证伪假说，不是 hit |
| C. 对照 / 负例 | lesinurad、verinurad、大环 Pareto | 回收失败与审计降级，当结果写 |

SI：τ=85 的 8 个、τ=80 的 19/27、强制对接回收表。

## 5. 分阶段修改计划

### 阶段 0 — 只改写作（无新计算，可立即投方法+筛选稿）

- 结果把表 2 的 7 个当 Mol Divers 式短名单，不要写成协议论文附录。  
- 补一张 **ADMET / 骨架 / 临床分期** 表（数据已在 `admet_pool.csv`、`filters_pool.csv`）。  
- 讨论里用一段对照该刊模板：本文多了协议锁定和化学降级，少了生产 MD。  
- 封面信写 hypothesis-generating clinical-library screen。  
- **不**把“选不出 MD 分子”写进摘要。

### 阶段 1 — 敏感性短名单（不重对接）

用现有 `pareto_merged_scores.csv` 归档 τ=80 / 85，**不覆盖**生产 `data/repurposing/p2/nominated_*.csv`。

```bash
python3 scripts/14_candidate_nomination.py --tau 85 --output-dir data/repurposing/p2/sensitivity_tau85
python3 scripts/14_candidate_nomination.py --tau 80 --output-dir data/repurposing/p2/sensitivity_tau80
```

方法里预先写明：主分析 τ=90；80/85 只回答“门槛移动时名单是否崩溃”。**禁止**看完 80 的名单再回头改主 τ。

### 阶段 2 — 阳性对照可见（少量新对接，强烈建议）

对未进 1588 的命名 URAT1 / 痛风药按**生产 P2 设置**强制对接 9DKB（可选 7ALV），分子包括但不限于：benzbromarone、dotinurad、probenecid、sulfinpyrazone；lesinurad/verinurad 已有生产分，只入回收表。

产出：SI「已知药回收」，结论预期为 **P2 不能回收经典促尿酸药**。这对 Mol Divers 是加分的诚实对照，不是删候选的理由。

同时：lesinurad、GSK-3008348 做羧酸根微状态后对接，报告 Arg477 距离是否改善。若改善，MD 用新姿；若无改善，正文保持“P2 排序≠晶体模式”。

### 阶段 3 — 该刊模板要的 MD（对照优先，候选其次）

仅在阶段 2 的晶体/羧酸根姿可用之后进行。每体系建议 **3×100 ns**（对齐近三年常见档，不追 *J. Mol. Model.* 的 500 ns）。

1. lesinurad @ 9DKB，**晶体坐标 + 羧酸根**，膜+脂双层（阳性对照）  
2. lesinurad @ 9DKB，生产 P2 姿（协议诊断，允许失败）  
3. GSK-3008348 @ 9DKB，羧酸根姿（假说压力测试）  
4. NP3-146 或 MCC950 类似物 @ 7ALV（NLRP3 对照）  
5. Vecabrutinib @ 7ALV（NLRP3 假说）

只报告：配体 RMSD、Arg477–羧酸距离、Phe 笼占据。 **不做 MM-GBSA 重排 7 个候选。** 对照体系不合格则不解释候选轨迹。

### 阶段 4 — 不要做

- 为让某个喜欢的分子进门控而改 τ、改 MW、改 PAINS。  
- 用 P0 重排后发现 GSK 的 URAT1 分下降，再改回 P2 只保留高的分子。  
- 把 27 人名单写进摘要当“发现了 27 个双靶抑制剂”。

## 6. 推荐执行顺序与投稿策略

**若两周内要投稿、MD 跑不完：** 阶段 0 + 阶段 1。科学上已经有 7 个命名候选；用写作对齐该刊，MD 放 Discussion 预定设计。风险是碰到 hit 鉴定口味审稿人仍要 MD。

**若接受再等一轮计算：** 阶段 0–3。这是最接近近三年 Mol Divers 筛选文外形、同时不破坏协议锁定的路径。

**主 τ 建议维持 90。** 放宽到 80 会多出 UCB-1184197、Taranabant、Afimetoran 等，化学更杂、痛风相关性并不增加，只适合 SI。跟进案例仍从现行 7 个里取，不必靠放宽协议“再筛出一个”。

## 7. 一句话

库和 P2 已经给出候选；要的不是换协议，而是 **按该刊习惯把 7 个写成短名单、把对照失败写成结果、用羧酸根+强制对照补洞，MD 只做校准不是发现。**
