# 若仍要“排出活性再提名候选”：哪些还能做、哪些不能做

> 冻结的 P0–P5 表不能事后做高。下面是**新实验**，必须先在诱饵集过关，再碰临床库。  
> 成功标准预先写死，失败则回到方法学阴性文，不把旧 7 个名字救回来。

## 不能做（那是改已经失败的考试分数）

- 改 EF 切片、只报 TrueDecoy、看过 7 个名字后把 Π\* 换成 P0/P4/P5  
- 只给 GSK / lesinurad 补羧酸根，不去重对接整个诱饵集  
- 把 lesinurad 加进阳性后，用**旧**对接分重算 EF  
- 用 MM-GBSA 或 MD RMSD 重排已发表的 1580 行主表  

P0（CNNscore）在 RandomDecoy 上点估计确实比 P2 好（EF@1% 1.94 vs 0.22）。它当时是**预注册负对照**，现在拿来当生产读出等于事后改规则。新一轮里可以把它改成正式候选读出，但不能用来给旧漏斗翻案。

## 值得做、且可能真的改变“能不能排出活性”

按预期收益和对“候选”是否仍诚实排序。

### 1. 羧酸根 / 质子化（最该做，属于修漏洞）

lesinurad 生产姿 Arg477 ≈ 14 Å，说明当前配体准备很可能把酸做成中性。URAT1 已知药多数靠酸根–Arg477。  
**做法：** pH 7.4 枚举羧酸根，**整份** TrueDecoy+RandomDecoy+自对接重跑，再比 P0–P5（可加上面的 CNN_VS）。  
**过关：** RandomDecoy EF@1% 显著 >1，且 lesinurad / verinurad / benzbromarone 至少有一个在强制回收表的前 10%。  
修对了，姿态和排序都可能变；修完 Random 仍随机，就说明不是准备错误这么简单。

### 2. Arg477 约束对接（改的是问题，不是同一套自由对接）

强制盐桥/氢键。预期：羧酸系列早期富集会升，非酸抑制剂会掉。  
这是在问“谁能做出晶体那种酸根姿”，不是“谁是任意 URAT1 活性物”。对痛风双节点其实更合理（URAT1 药本来就是酸），但文章必须改口，不能再说“对接排出了活性”。

### 3. 重做阳性集（改考试题，不是改打分器）

现在 p≥6 + 冲突剔除，把 lesinurad、benzbromarone、dotinurad 踢出阳性。  
**新基准可预注册：** 教科书药强制当阳性（文献/中位 IC50），专利类似物降权或按骨架去冗余后再算 EF。  
EF 升高只说明“更能认出已知药”，不自动等于临床库里能发现新双靶分子。

### 4. 未测过的读出：CNN_VS = CNNscore × CNNaffinity

Gnina 的 VS 推荐常用这个乘积。本轮 P0 是 CNNscore、P2 是 CNNaffinity，**没有把乘积当正式协议**。可进入新一轮预注册比较。不保证 RandomDecoy 能过。

### 5. 受体集合 / 外向构象

只用了 9DKB inward-open。转运体有循环。有结构或 MD 帧就做 ensemble，仍先在诱饵集比，不要先看临床名单。算力大，对 RandomDecoy 的提升不确定。

## 不该指望的

| 做法 | 原因 |
|------|------|
| 加大 exhaustiveness / 多出几个构象 | 已经 32 / 9，AUC 从 0.54 拉到能用的可能性很小 |
| 全库 MM-GBSA 重排 | 贵，且常不提高 VS 早期富集；已写死不做 MM-GBSA 重排 |
| 用 MD 证明对接能排序 | MD 只测姿稳不稳，不测库内排序 |

## 若“候选”可以不靠对接排序（更可能走到名单）

URAT1 臂改成**化学门控**，对接只负责出姿：

1. 临床库里留下羧酸（或等价酸根）；  
2. NLRP3 分类器仍只缩库；  
3. 羧酸根对接 9DKB，**Arg477 距离过关**才留下，不用 CNN 百分位排名；  
4. 已知促尿酸药做回收表（不受 \(q_N\) 挡住的强制对接）。  

这样 GSK 这类酸可以成为“姿态上说得通的假说”，Vecabrutinib 这类非酸不应再当 URAT1 候选。这不是提高了对接排出活性的能力，是**不再要求对接承担活性检索**。没有湿实验，名单仍是假说，但比失败的百分位 AND 诚实。

## 仍走排序路线时的停损

新一轮诱饵集若 **RandomDecoy 仍不显著优于随机**，或教科书药仍回收失败：停止再调参，不要再筛临床库当候选。那时方法学阴性文是唯一诚实产品。
