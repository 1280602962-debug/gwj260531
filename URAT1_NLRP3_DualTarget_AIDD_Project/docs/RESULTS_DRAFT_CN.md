## 3 结果

### 3.1 诱饵集合的相似性泄漏审计

TrueDecoy 的性质匹配诱饵在构建时已要求相对活性物的最大 Tanimoto 相似度 \(\le 0.5\)，但 80 个实验弱活分子与全部 4,690 个 RandomDecoy 诱饵均未经过该过滤，存在“诱饵实际上是活性物近邻”的潜在风险（`data/si/decoy_leakage_audit/`）。核查结果：80 个实验弱活分子中 6 个（其骨架种类的 15.8%）与某活性物共享 Murcko 骨架，14 个（17.5%）的最大相似度超过 0.5，但无一超过 0.85——这一定程度的重叠符合设计意图，弱活分子正是因为与活性物同属可比较化学空间才被选作难负例。4,690 个 RandomDecoy 诱饵与活性物的骨架重叠为 **0**，最大相似度中位数 0.20、第 90 百分位 0.25，无一超过 0.5：本次抽样中 RandomDecoy 天然疏远于活性物，不存在近邻泄漏。按“排除相似度 >0.5 的诱饵”重新计算六个读出在 RandomDecoy 上的 EF@1%/EF@5%/AUC，因无诱饵被排除，数值与未过滤结果逐位相同。因此表 1 的 RandomDecoy 否决判据不依赖这一潜在漏洞。

### 3.2 URAT1 活性物–诱饵基准上的协议比较与 Π\* 锁定

协议比较在查看临床库排名之前完成。六种读出（P0–P5）均在 9DKB 上对接同一结构并集（归档主表 9,839 个独特结构），再分别汇总 TrueDecoy 与 RandomDecoy。锁定时的点估计与随后在分子级分数上的排名 bootstrap 一并列于表 1。前 1% 切片在锁定表中按约 52 个分子计（P2 TrueDecoy 为 12/52，EF@1% = 2.54）；归档重算采用 \(n_f=\lfloor 0.01N\rfloor\)，故同一 12 个命中记为 12/51，EF@1% = 2.59。两种切片不改变读出排序，**不重新选择** Π\*。

P5 在 TrueDecoy 上早期富集最强，但 RandomDecoy 前 1% 命中为 0；该零命中在纯随机排序下出现的概率约 0.76%，不宜归因于小样本噪声。P0 两侧最均衡，但预先指定为负对照，不提为生产读出。P1、P3、P4 的 TrueDecoy 前 1% 与随机无法区分，或覆盖不全。P2 覆盖完整，TrueDecoy EF@1% 显著高于随机，且 RandomDecoy 非零。因此生产排序读出锁定为 **Π\* = P2（gnina CNNaffinity）**。绝对富集仍为中等（AUC ≈ 0.58），只支持库内相对排序，不支持把分数解释为结合亲和力。

lesinurad 在 9DKB 上的自对接（exhaustiveness = 32，最多 9 个构象）表明：全部读出的集合最低 RMSD ≤ 1.0 Å，搜索盒与配体准备能够采样到近原生姿；但 P2 的第一构象 RMSD 为 4.16 Å，未通过 2.0 Å 的 Top-1 门控（P1/P4/P5 的 Top-1 RMSD 为 0.86–0.99 Å，可通过该门控）。P2 因此用作**排序读出**，不用作构象金标准。MCC950 按生产 P2 设置对接至 7ALV，CNNaffinity = 7.018，仅作药理学类似物对照：7ALV 共晶配体是 NP3-146，该作业不是自对接，也不进入临床库百分位表。NLRP3 侧未做对应的 NP3-146 自对接，是本文结构验证力度上的一处不对称，已在方法 2.5 节列为局限。

**配对 bootstrap：P2 与其余读出的差异是否显著。** 上表的区间估计对每个读出独立重采样，不能回答“P2 是否显著优于/劣于某读出”。配对 bootstrap（同一组重采样索引同时应用到六个读出，2,000 次；`data/si/protocol_paired_bootstrap/`）显示：在 TrueDecoy 上，P2 的 EF@1% 显著高于 P1、P3、P4（\(p\le 0.006\)），但与 P0、P5 的差异均不显著（\(p=0.61\)、\(0.72\)）。换言之，**P2 相对 P5 的优势不是“TrueDecoy 上统计显著更强”，而是 P5 在 RandomDecoy 上前 1% 命中为零这一独立的否决理由**。在 RandomDecoy 上，P2 与 P4、P5 的 EF@1% 差异同样不显著（三者点估计均接近零，命中数过少导致方差偏大）；因此 P4、P5 被排除生产协议，依据是各自绝对命中数的超几何检验，而不是与 P2 的两两差值检验。

### 3.3 NLRP3 缩库、双靶完整案例漏斗与库内对照

NLRP3 相关细胞活性分类器在 5 折骨架分组交叉验证中 AUROC = 0.893、AUPRC = 0.914、前 10% 富集因子 = 1.57，用于临床库缩库而不作结合证明。分子级活性率 60.4%（310/513），不构成需要类别重加权的严重不平衡；测定层面的不平衡通过样本平方根倒数加权处理（方法 2.4 节）。URAT1 回归对照的 OOF RMSE = 0.663、\(R^2\) = 0.508、Spearman = 0.726；命名药物回顾中 lesinurad 与 dotinurad 未按预定阈值回收，故 URAT1 主排序不依赖该模型。

临床库 8,319 个分子中，1,588 个满足 \(q_N\ge 0.5\)。配体三维准备得到 1,583 个 PDBQT；5 个脂质或核苷酸前药未能嵌入（磷脂酰胆碱、feneritrol、fosfluridine tidoxil、fozivudine tidoxil、磷脂酰丝氨酸）。两靶对接文件各含 1,583 行，其中有效构象 1,582、空姿态 1（`REP_05842` tauroselcholic acid）。与临床库规范 SMILES 内连接后，归档合并表为 **1,580** 行（`pareto_merged_scores.csv`）。其中 1 行即上述空姿态分子，两靶 `dock_score` 均为缺失、百分位记为 0；**具有有效双靶 P2 分数的分子为 1,579**。另有 3 条在合并时落下（fostriecin 与其钠盐、plocabulin）。缺失集分子量中位 721 Da，对接池中位 480 Da，偏向准备失败的大体积脂质/核苷酸类结构，而不是随机丢失高分分子。百分位沿用归档 1,580 分母，与冻结提名表一致。将该空姿态行剔除后按 1,579 重算百分位，7 个优选候选的 \(S_U\) 与 \(S_{N,\mathrm{dock}}\) 变化均 < 0.1 个百分点，双结构门控集合仍为 51。本文没有对失败分子赋予人为低分后参与跟进提名。

\* 该 1,377 为重训练模型在相同 6.0 阈值下的池规模，用于与 5.5/6.5 阈值比较；因 XGBoost 多线程训练非逐位可重现，与冻结生产池（1,588）的 Jaccard 为 0.87。生产池仍以冻结文件为准。

测定上下文取频率最高的 1、3 或 5 个时，\(q_N\ge 0.5\) 集合彼此完全重合；与冻结的 1,588 生产池仅差 1 个分子（CT-1578），归因于模型反序列化而非测定个数。生产对接池不予替换。

### 3.4 弱读出迁到临床库：Pareto 偏置与化学过滤表（非 hit）

### 3.5 对接姿态质控

对表 4 七个分子的生产第一构象做口袋几何质控，不参与协议选择。以 9DKB 共晶 lesinurad 和 7ALV 共晶 NP3-146 为参考。七者两靶均 `both_in_pocket=True`，冲突为 0。该检验只说明几何上落在晶体腔内，不证明结合，也不把它们升格为 hit。

lesinurad 与 verinurad 作为 URAT1 对照另做姿态检查。lesinurad 生产第一构象质心位移 1.59 Å、口袋内，但羧酸氧与 Arg477 最短距离约 **14.2 Å**，未保持晶体盐桥几何——这与自对接中 P2 Top-1 RMSD = 4.16 Å 一致，并直接决定后续 MD 必须使用**晶体羧酸根姿**作 URAT1 阳性对照，而不是用这条生产第一构象当“已验证的结合模式”。verinurad 质心位移 5.06 Å，仍按关键残基规则记为口袋内，但芳香笼接触明显减少（仅 Phe449）。二者均不进入任何 hit 名单。

### 3.6 分子动力学：体系已指定，轨迹数值不在本文报告

生产 MD 的必须清单为 6 个体系（方法 2.11；`docs/MD_RUN_PLAN.md`）：lesinurad 晶体羧酸根姿 @ 9DKB（膜+脂双层）；GSK-3008348 与 Vecabrutinib 各 @ 9DKB；NP3-146/RM5 共晶坐标 @ 7ALV（水盒子）；Vecabrutinib 与 GSK-3008348 各 @ 7ALV。可选第 7 条为 lesinurad 的生产 P2 第一构象，仅作协议诊断。本归档包含部分体系的起始坐标准备记录。开跑前的羧酸根枚举与对照晶体姿提取属于配体/体系准备，不是第二套生产排名。

**截至本稿不报告任何依赖轨迹的数值。** 对照失败则该靶不解释。MD 合格不等于活性，更不等于双靶。六体系是 P2 姿态诊断，不是 lead 验证。

## 主张边界（本节禁止升格）

- 表 4 是弱读出尾部的化学过滤记录，不是 hit。
- P2 在 RandomDecoy 上与随机无法区分，百分位不是活性。
- P2 第一构象不是近原生结合模式的证明。
- 裸 Pareto 四分子不是命中。
- 未完成的 MD 不得补写数值，也不能回升为 lead。
- 不得把 Tegoprazan、Levotofisopam、Verinurad 写成生产跟进分子。
