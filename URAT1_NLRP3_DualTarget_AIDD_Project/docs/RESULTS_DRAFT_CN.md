## 3 结果

### 3.1 URAT1 活性物–诱饵基准上的协议比较与 Π\* 锁定

协议比较在查看临床库排名之前完成。六种读出（P0–P5）均在 9DKB 上对接同一结构并集（归档主表 9,839 个独特结构），再分别汇总 TrueDecoy 与 RandomDecoy。锁定时的点估计与随后在分子级分数上的排名 bootstrap 一并列于表 1。前 1% 切片在锁定表中按约 52 个分子计（P2 TrueDecoy 为 12/52，EF@1% = 2.54）；归档重算采用 \(n_f=\lfloor 0.01N\rfloor\)，故同一 12 个命中记为 12/51，EF@1% = 2.59。两种切片不改变读出排序，**不重新选择** Π\*。

P5 在 TrueDecoy 上早期富集最强，但 RandomDecoy 前 1% 命中为 0；该失败在纯随机排序下出现的概率约 0.76%，不宜归因于小样本噪声。P0 两侧最均衡，但预先指定为负对照，不提为生产读出。P1、P3、P4 的 TrueDecoy 前 1% 与随机无法区分，或覆盖不全。P2 覆盖完整，TrueDecoy EF@1% 显著高于随机，且 RandomDecoy 非零。因此生产排序读出锁定为 **Π\* = P2（gnina CNNaffinity）**。绝对富集仍为中等（AUC ≈ 0.58），只支持库内相对排序，不支持把分数解释为结合亲和力。

lesinurad 在 9DKB 上的自对接（exhaustiveness = 32，最多 9 个构象）表明：全部读出的集合最低 RMSD ≤ 1.0 Å，搜索盒与配体准备能够采样到近原生姿；但 P2 的第一构象 RMSD 为 4.16 Å，未通过 2.0 Å 的 Top-1 门控。P2 因此用作**排序读出**，不用作构象金标准。MCC950 按生产 P2 设置对接至 7ALV，CNNaffinity = 7.018，仅作药理学类似物对照：7ALV 共晶配体是 NP3-146，该作业不是自对接，也不进入临床库百分位表。

### 3.2 NLRP3 缩库与 P2 双靶完整案例漏斗

NLRP3 相关细胞活性分类器在 5 折骨架分组交叉验证中 AUROC = 0.893、AUPRC = 0.914、前 10% 富集因子 = 1.57，用于临床库缩库而不作结合证明。URAT1 回归对照的 OOF RMSE = 0.663、\(R^2\) = 0.508、Spearman = 0.726；命名药物回顾中 lesinurad 与 dotinurad 未按预定阈值回收，故 URAT1 主排序不依赖该模型。

临床库 8,319 个分子中，1,588 个满足 \(q_N\ge0.5\)。配体三维准备得到 1,583 个 PDBQT；5 个脂质或核苷酸前药未能嵌入（磷脂酰胆碱、feneritrol、fosfluridine tidoxil、fozivudine tidoxil、磷脂酰丝氨酸）。两靶各有 1,582 个有效 P2 分数（`REP_05842` tauroselcholic acid 的 PDBQT 为空，姿态文件为空）。百分位只在双靶分数均可与临床库规范 SMILES 内连接的 **1,580** 个完整案例上计算。另有 3 条在合并时落下（fostriecin 与其钠盐、plocabulin）。缺失集分子量中位约 721 Da，对接池中位约 480 Da，偏向准备失败的大体积脂质/核苷酸类结构，而不是随机丢失高分分子。

完整案例中，方向统一后的 P2 `dock_score`（即 −CNNaffinity）范围为 URAT1 −9.276 至 −4.572、NLRP3 −8.547 至 −4.153。这些数值只在本池内转换为百分位。库内对照药均未进入后文双结构门控，也不在裸 Pareto 前沿：lesinurad \(S_U=45.9\)、\(S_{N,\mathrm{dock}}=43.9\)；verinurad \(3.4\)、\(80.7\)；秋水仙碱 \(63.2\)、\(6.4\)。对照药出现在池中，说明漏斗没有把已知痛风相关分子从审计表中物理删除，只是它们未同时位于两靶对接分布的上端。

测定上下文取频率最高的 1、3 或 5 个时，\(q_N\ge0.5\) 集合彼此完全重合；与冻结的 1,588 生产池仅差 1 个分子（CT-1578），归因于模型反序列化而非测定个数。生产对接池不予替换。

### 3.3 裸 Pareto 审计与双结构提名

在 1,580 个完整案例上，以 \(S_U\) 与 \(S_N=\max\{S_{N,\mathrm{ML}},S_{N,\mathrm{dock}}\}\) 做非支配分析，得到 4 个分子：Idremcinal、Alemcinal、Cethromycin 和 Zamzetoclax。四者分子量 698–766 Da，均为红霉素/大环相关骨架，相对 URAT1 / NLRP3 已知活性物的最近邻 Tanimoto 约 0.11–0.19。有放回重采样（500 次）中，四者出现在前沿的频率为 0.59–0.65。该集合用于展示对接优势被高分子量骨架占据，**不是**跟进名单。两轴前 1%、2%、5%、10% 的交集分别为 5、8、21、77 个分子；审计轴双阈值 85 / 90 / 95 的集合为 119 / 77 / 21 个分子。

跟进提名与 Pareto 成员身份分开，改用双对接门控 \(S_U\ge90\) 且 \(S_{N,\mathrm{dock}}\ge90\)，得到 51 个分子；机器学习分数不把分子抬进该门控。其中无 PAINS、无 Brenk，且通过 Veber 与 Ro5 氢键/\(\log P\) 条件者 14 个。再要求分子量 200–550 Da、经验口服吸收标记通过、且非大环骨架后，优选候选为 **7** 个（表 2）。完整 Lipinski 分子量 \(\le500\) 仅作注释：除 GSK-3008348 外，其余六者因分子量略高于 500 Da 未通过该注释规则，但仍落在预定的 200–550 Da 窗口内。门控内因分子量超出窗口而降级的分子包括 Atumelnant、Mioflazine、Depulfavirine、BMS-986142、XP-102、BN-104 和 JTK-853 等，不进入优选表。1,580 个完整案例中，PAINS 命中 78 个，Brenk 命中 626 个；Lipinski 通过 752 个，Veber 通过 1,254 个，分子量 200–550 Da 者 1,199 个。

七者相对 URAT1 训练集最近邻均低于适用域第 5 百分位阈值 0.578，标记为域外临床库化学型，不因此剔除。GSK-3008348 带羧酸，两靶对接百分位均衡，但 NLRP3 模型百分位仅 3.5，其 NLRP3 侧证据几乎完全来自对接而非分类器。Vecabrutinib 则同时具有高对接百分位和高模型分。其余五者保留在优选表中供审计，不作为当前故事分子：Zelenirstat、Deucrictibant 与 BI 653048 的 NLRP3 模型分接近池中位，Praliciguat 与 MLN-0415 的模型分较高，但均无痛风双节点的既有人体证据可把对接排序升格为活性结论。

### 3.4 对接姿态质控；分子动力学数值不报告

对 7 个优选候选的生产第一构象做口袋几何质控，不参与协议选择或百分位排序。以 9DKB 共晶 lesinurad 和 7ALV 共晶 NP3-146 为参考：质心位移 ≤ 6 Å 或至少 3 个预定关键残基接触（4.5 Å）即记为口袋内。七者在两靶上均 `both_in_pocket=True`，重原子冲突（2.2 Å）均为 0。URAT1 质心相对 lesinurad 为 0.64–1.62 Å，均接触苯丙氨酸笼（Phe241/360/364/365/449）。GSK-3008348 羧酸氧与 Arg477 最短距离 3.19 Å。NLRP3 质心相对 RM5 为 0.34–3.12 Å；Vecabrutinib 为 2.14 Å，大于 GSK-3008348 在 URAT1 上的位移。该检验只说明生产构象落在晶体配体腔的几何范围内，不证明结合模式，也不给出亲和力。

lesinurad 与 verinurad 作为 URAT1 对照另做姿态检查。lesinurad 质心位移 1.59 Å、口袋内；verinurad 质心位移 5.06 Å，仍按关键残基规则记为口袋内，但芳香笼接触明显减少。二者均不进入提名。

本归档包含 GSK-3008348、Vecabrutinib 和 Zelenirstat 各一对 URAT1 / NLRP3 体系搭建记录。**生产轨迹与数值未纳入本文**，故不报告 RMSD、氢键占据或 MM-GBSA。当前计算跟进仍为 GSK-3008348（URAT1 侧案例）和 Vecabrutinib（NLRP3 侧案例），二者都需要后续实验验证，不能表述为已发现的双靶抑制剂。
