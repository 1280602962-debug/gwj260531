## 3 结果

### 3.0 诱饵集合的相似性泄漏审计

TrueDecoy 的性质匹配诱饵在构建时已要求相对活性物的最大 Tanimoto 相似度 \(\le0.5\)，但 80 个实验弱活分子与全部 4,690 个 RandomDecoy 诱饵均未经过该过滤，存在"诱饵实际上是活性物的近邻"的潜在风险（复现：`scripts/si_decoy_leakage_audit.py`，`data/si/decoy_leakage_audit/`）。核查结果：80 个实验弱活分子中 6 个（其骨架种类的 15.8%）与某活性物共享 Murcko 骨架，14 个（17.5%）的最大相似度超过 0.5，但无一超过 0.85——这一定程度的重叠符合设计意图，弱活分子正是因为与活性物同属可比较化学空间才被选作"难负例"。4,690 个 RandomDecoy 诱饵与活性物的骨架重叠为 **0**，最大相似度中位数 0.20、第 90 百分位 0.25，无一超过 0.5：本次抽样中 RandomDecoy 天然疏远于活性物，不存在近邻泄漏。按"排除相似度 >0.5 的诱饵"重新计算六个读出在 RandomDecoy 上的 EF@1%/EF@5%/AUC，因无诱饵被排除，数值与未过滤结果逐位相同（`data/si/decoy_leakage_audit/random_decoy_ef_before_after_tc_filter.csv`），说明表 1 的 RandomDecoy 结果不依赖这一潜在漏洞。

### 3.1 URAT1 活性物–诱饵基准上的协议比较与 Π\* 锁定

协议比较在查看临床库排名之前完成。六种读出（P0–P5）均在 9DKB 上对接同一结构并集（归档主表 9,839 个独特结构），再分别汇总 TrueDecoy 与 RandomDecoy。锁定时的点估计与随后在分子级分数上的排名 bootstrap 一并列于表 1。前 1% 切片在锁定表中按约 52 个分子计（P2 TrueDecoy 为 12/52，EF@1% = 2.54）；归档重算采用 \(n_f=\lfloor 0.01N\rfloor\)，故同一 12 个命中记为 12/51，EF@1% = 2.59。两种切片不改变读出排序，**不重新选择** Π\*。

P5 在 TrueDecoy 上早期富集最强，但 RandomDecoy 前 1% 命中为 0；该失败在纯随机排序下出现的概率约 0.76%，不宜归因于小样本噪声。P0 两侧最均衡，但预先指定为负对照，不提为生产读出。P1、P3、P4 的 TrueDecoy 前 1% 与随机无法区分，或覆盖不全。P2 覆盖完整，TrueDecoy EF@1% 显著高于随机，且 RandomDecoy 非零。因此生产排序读出锁定为 **Π\* = P2（gnina CNNaffinity）**。绝对富集仍为中等（AUC ≈ 0.58），只支持库内相对排序，不支持把分数解释为结合亲和力。

lesinurad 在 9DKB 上的自对接（exhaustiveness = 32，最多 9 个构象）表明：全部读出的集合最低 RMSD ≤ 1.0 Å，搜索盒与配体准备能够采样到近原生姿；但 P2 的第一构象 RMSD 为 4.16 Å，未通过 2.0 Å 的 Top-1 门控。P2 因此用作**排序读出**，不用作构象金标准。MCC950 按生产 P2 设置对接至 7ALV，CNNaffinity = 7.018，仅作药理学类似物对照：7ALV 共晶配体是 NP3-146，该作业不是自对接，也不进入临床库百分位表。NLRP3 侧未做对应的 NP3-146 自对接（受限于本次可用的计算环境），是本文结构验证力度上的一处不对称，已在方法 2.5 节列为局限。

**配对 bootstrap：P2 与其余读出的差异是否显著。** 上表的区间估计对每个读出独立重采样，不能回答"P2 是否显著优于/劣于某读出"。配对 bootstrap（同一组重采样索引同时应用到六个读出，2,000 次；`data/si/protocol_paired_bootstrap/`）显示：在 TrueDecoy 上，P2 的 EF@1% 显著高于 P1、P3、P4（\(p\le0.006\)），但与 P0、P5 的差异均不显著（\(p=0.61\)、\(0.72\)）。换言之，**P2 相对 P5 的优势不是"TrueDecoy 上统计显著更强"，而是 P5 在 RandomDecoy 上前 1% 命中为零这一独立的否决理由**（超几何 \(p\approx0.0005\)）。在 RandomDecoy 上，P2 与 P4、P5 的 EF@1% 差异同样不显著（三者点估计均接近零，命中数过少导致方差偏大）；因此 P4、P5 被排除生产协议，依据是各自绝对命中数的超几何检验，而不是与 P2 的两两差值检验——本文对每一条结论都标注了具体使用了哪一种检验。

### 3.2 NLRP3 缩库与 P2 双靶完整案例漏斗

NLRP3 相关细胞活性分类器在 5 折骨架分组交叉验证中 AUROC = 0.893、AUPRC = 0.914、前 10% 富集因子 = 1.57，用于临床库缩库而不作结合证明。分子级活性率 60.4%（310/513），不构成需要类别重加权的严重不平衡；测定层面的不平衡通过样本平方根倒数加权处理（方法 2.4 节）。URAT1 回归对照的 OOF RMSE = 0.663、\(R^2\) = 0.508、Spearman = 0.726；命名药物回顾中 lesinurad 与 dotinurad 未按预定阈值回收，故 URAT1 主排序不依赖该模型。

临床库 8,319 个分子中，1,588 个满足 \(q_N\ge0.5\)。配体三维准备得到 1,583 个 PDBQT；5 个脂质或核苷酸前药未能嵌入（磷脂酰胆碱、feneritrol、fosfluridine tidoxil、fozivudine tidoxil、磷脂酰丝氨酸）。两靶各有 1,582 个有效 P2 分数（`REP_05842` tauroselcholic acid 的 PDBQT 为空，姿态文件为空）。百分位只在双靶分数均可与临床库规范 SMILES 内连接的 **1,580** 个完整案例上计算。另有 3 条在合并时落下（fostriecin 与其钠盐、plocabulin）。缺失集分子量中位约 721 Da，对接池中位约 480 Da，偏向准备失败的大体积脂质/核苷酸类结构，而不是随机丢失高分分子。表 1a 汇总了对接失败漏斗；本文没有对失败分子赋予人为低分，而是把它们整体排除在完整案例集合之外。

**表 1a. 从缩库池到完整案例的对接失败漏斗**

| 环节 | 通过 / 输入 | 失败原因 |
|------|:---:|------|
| 配体三维准备 | 1,583 / 1,588 | 5 个脂质/核苷酸前药未能嵌入 |
| URAT1 对接 | 1,582 / 1,583 | `REP_05842` 姿态为空 |

完整案例中，方向统一后的 P2 `dock_score`（即 −CNNaffinity）范围为 URAT1 −9.276 至 −4.572、NLRP3 −8.547 至 −4.153。这些数值只在本池内转换为百分位。库内对照药均未进入后文双结构门控，也不在裸 Pareto 前沿：lesinurad \(S_U=45.9\)、\(S_{N,\mathrm{dock}}=43.9\)；verinurad \(3.4\)、\(80.7\)；秋水仙碱 \(63.2\)、\(6.4\)。对照药出现在池中，说明漏斗没有把已知痛风相关分子从审计表中物理删除，只是它们未同时位于两靶对接分布的上端。

**标签阈值与测定聚合方式的敏感性。** \(\mathrm{pActivity}\ge6\) 之外，另在 5.5、6.5 两个阈值下重训练模型（`data/si/nlrp3_threshold_sensitivity/`）：三个阈值的分类判别力相近（AUROC 0.88–0.90），但缩库池规模随阈值明显变化（5,208 / 1,377\* / 707；三者两两 Jaccard 仅 0.13–0.36），这是阈值筛选的固有属性。更重要的是两个正文分子的表现：Vecabrutinib 在三个阈值下 \(q_N\) 均为 0.82–0.96，稳定通过；GSK-3008348 在重训练的 6.0 阈值下已接近边界（\(q_N=0.46\)），6.5 阈值下跌破 0.5——这与其 \(S_{N,\mathrm{ML}}\) 百分位仅 3.5 的观察一致，进一步说明 GSK-3008348 的 NLRP3 侧证据应理解为主要来自结构对接而非分类器。另检验了取最大值、均值、中位数、前二均值四种测定聚合方式：临床库分子从未出现在训练测定中，四种聚合方式给出完全相同的缩库池（n = 1,377，Jaccard = 1.0），因为同一分子在五个测定上下文下的预测值几乎不变（标准差 < 1×10⁻⁶）；聚合方式的选择在本文的具体应用中不影响结果。

\* 该 1,377 为重训练模型在相同 6.0 阈值下的池规模，用于与 5.5/6.5 阈值比较；因 XGBoost 多线程训练非逐位可重现，与冻结生产池（1,588）的 Jaccard 为 0.87。生产池仍以冻结文件为准。

测定上下文取频率最高的 1、3 或 5 个时，\(q_N\ge0.5\) 集合彼此完全重合；与冻结的 1,588 生产池仅差 1 个分子（CT-1578），归因于模型反序列化而非测定个数。生产对接池不予替换。

### 3.3 裸 Pareto 审计与双结构提名

在 1,580 个完整案例上，以 \(S_U\) 与 \(S_N=\max\{S_{N,\mathrm{ML}},S_{N,\mathrm{dock}}\}\) 做非支配分析，得到 4 个分子：Idremcinal、Alemcinal、Cethromycin 和 Zamzetoclax。四者分子量 698–766 Da，均为红霉素/大环相关骨架，相对 URAT1 / NLRP3 已知活性物的最近邻 Tanimoto 约 0.11–0.19。有放回重采样（500 次）中，四者出现在前沿的频率为 0.59–0.65。该集合用于展示对接优势被高分子量骨架占据，**不是**跟进名单。两轴前 1%、2%、5%、10% 的交集分别为 5、8、21、77 个分子；审计轴双阈值 85 / 90 / 95 的集合为 119 / 77 / 21 个分子。

跟进提名与 Pareto 成员身份分开，改用双对接门控 \(S_U\ge90\) 且 \(S_{N,\mathrm{dock}}\ge90\)，得到 51 个分子；机器学习分数不把分子抬进该门控。其中无 PAINS、无 Brenk，且通过 Veber 与 Ro5 氢键/\(\log P\) 条件者 14 个。再要求分子量 200–550 Da、经验口服吸收标记通过、且非大环骨架后，优选候选为 **7** 个（表 2）。完整 Lipinski 分子量 \(\le500\) 仅作注释：除 GSK-3008348 外，其余六者因分子量略高于 500 Da 未通过该注释规则，但仍落在预定的 200–550 Da 窗口内。门控内因分子量超出窗口而降级的分子包括 Atumelnant、Mioflazine、Depulfavirine、BMS-986142、XP-102、BN-104 和 JTK-853 等，不进入优选表。1,580 个完整案例中，PAINS 命中 78 个，Brenk 命中 626 个；Lipinski 通过 752 个，Veber 通过 1,254 个，分子量 200–550 Da 者 1,199 个。

### 3.4 对接姿态质控；分子动力学数值不报告

对 7 个优选候选的生产第一构象做口袋几何质控，不参与协议选择或百分位排序。以 9DKB 共晶 lesinurad 和 7ALV 共晶 NP3-146 为参考：质心位移 ≤ 6 Å 或至少 3 个预定关键残基接触（4.5 Å）即记为口袋内。七者在两靶上均 `both_in_pocket=True`，重原子冲突（2.2 Å）均为 0。URAT1 质心相对 lesinurad 为 0.64–1.62 Å，均接触苯丙氨酸笼（Phe241/360/364/365/449）。GSK-3008348 羧酸氧与 Arg477 最短距离 3.19 Å。NLRP3 质心相对 RM5 为 0.34–3.12 Å；Vecabrutinib 为 2.14 Å，大于 GSK-3008348 在 URAT1 上的位移。该检验只说明生产构象落在晶体配体腔的几何范围内，不证明结合模式，也不给出亲和力。

lesinurad 与 verinurad 作为 URAT1 对照另做姿态检查。lesinurad 质心位移 1.59 Å、口袋内；verinurad 质心位移 5.06 Å，仍按关键残基规则记为口袋内，但芳香笼接触明显减少。二者均不进入提名。

本归档包含 GSK-3008348、Vecabrutinib 和 Zelenirstat 各一对 URAT1 / NLRP3 体系搭建记录。**生产轨迹与数值未纳入本文**，故不报告 RMSD、氢键占据或 MM-GBSA。当前计算跟进为 GSK-3008348 与 Vecabrutinib，作为待双通路验证的双节点计算候选，不能表述为已发现的双靶抑制剂，也不应写成只需验证单靶。
