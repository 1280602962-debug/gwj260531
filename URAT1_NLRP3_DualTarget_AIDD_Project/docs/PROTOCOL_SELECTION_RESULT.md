# URAT1 对接协议筛选结果与 Π* 锁定

在 TrueDecoy（主判）+ RandomDecoy（否决对照）上比较 P0–P5（9DKB，exhaustiveness=32，num_modes=9）。
True 集约 5150 个分子、469 活性；前 1% 约 51–52 个分子。

## 显著性（超几何检验，TrueDecoy 前 1%）

| 协议 | p 值 | 判断 |
|------|------|------|
| P5 | 0.0005 | 早期富集显著 |
| P2 | 0.0019 | 早期富集显著 |
| P0 | 0.043 | 临界显著 |
| P4 / P1 / P3 | 0.13–0.32 | 与随机无法区分 |

RandomDecoy 前 1% 命中 0（P4/P5）在纯随机下发生概率约 0.76%，故 P4/P5 在随机诱饵上的失败是**真实**的，不是小样本噪声。

## 结论：Π* = P2（gnina CNNaffinity）

- **不选 P5**：True 最强，但 Random EF@1% 显著为 0；临床库更接近随机诱饵场景，用 P5 有系统性风险。
- **不选 P0**：两侧最均衡，但预注册为负对照读出，仅作交叉参照。
- **P1/P3/P4**：与随机无显著差异或覆盖不全，排除。
- **P2**：True 富集显著且 Random 非零、覆盖完整 → **生产排序读出**。

## 主张边界（写作须遵守）

- 绝对富集中等（AUC≈0.58，EF@1%≈2.5）；结论为**计算假说排序**，不是可靠活性预测或强 VS。
- 名单 = hypothesis-generating；需实验验证。
- P5 仅作敏感性分析报告，不作生产协议。
