# 课题改构：原目的不成立之后文章问什么

> 2026-08-25。不重锁 Π\*，不事后抬 EF，不发明 MD 数字，不做湿实验前提下的改稿决策。  
> 本文件取代“用对接排出活性 → 得到双靶候选”作为文章目的。

## 1. 原目的为什么不成立

原设计是一条因果链：

1. 在诱饵集上选出能**排序 URAT1 活性**的对接读出；
2. 把该读出迁到临床库，与 NLRP3 结构分做 AND 门控；
3. 得到同一分子覆盖两个病理节点的**候选**。

第 1 步已经失败，第 3 步就不能再当文章目的。

| 已核实的事实 | 对“候选双靶分子”的含义 |
|---|---|
| TrueDecoy：P2 AUC ≈ 0.58，EF@1% ≈ 2.59 | 最多是类似物偏置下的弱早期富集，不是活性检索器 |
| RandomDecoy：EF@1% ≈ 0.22，超几何 p ≈ 0.99 | 更接近临床库的对照上，P2 **不优于随机** |
| 自对接 Top-1 RMSD 4.16 Å；lesinurad 生产姿 Arg477 ≈ 14 Å | P2 也不是构象金标准 |
| 阳性 469 个都是 CHEMBL6120 的 URAT1 IC50，但 lesinurad / benzbromarone / dotinurad **不在阳性里** | 基准考的是专利类似物（p≥6），不是口袋配体和教科书药 |
| 临床库上 lesinurad、verinurad 未进 τ=90 | 百分位门控**没有回收**已知促尿酸药 |
| NLRP3 分类 AUROC 0.89，但阳性率高、分数饱和，EF@10% 接近理论上限 | 缩库臂也不是强发现器 |
| 无湿实验 | 没有任何正交活性可以把弱排序补成候选 |

软化用词（“计算假说”“待验证候选”）**救不了这条链**。审稿人问的是：排序器若排不出活性，名单为什么比随机抽 7 个类药分子更值得拿去测？现有数字给不出肯定答案。

因此：**文章目的不能再是“获得候选双靶分子”。**  
双节点医学问题仍然成立；失败的是“对接百分位 = 两端活性证据”。

## 2. 不要用的三条补救

| 补救 | 为何更糟 |
|---|---|
| 看过临床名单后把 Π\* 改成 P4/P5/P0 | 事后换协议；RandomDecoy 上 P5 前 1% 为零；P0 预注册为负对照 |
| 改诱饵、改 p≥6、把 lesinurad 加回阳性再重选协议 | 等于重做第 1 步；冻结的 EF 不能事后做高 |
| 保留 7 个名字当正文产品，只把“抑制剂”改成“假说” | 产品形态仍是 hit 文，证据仍是失败的排序器；Mol Divers 审稿人会按 hit 文审，JCAMD 审稿人会按方法文审，两边都不干净 |

课题不是“没有分子所以空了”，是**选分子的理由断了**。

## 3. 推荐改构（一篇文，两个层级）

**新的一句话目的：**

> 在预注册条件下检验：开源对接能否作为痛风 URAT1 臂的活性检索器；若不能，临床库双节点百分位漏斗还剩下什么可发表的方法学结论，以及化学上仍可讨论的姿态假说必须满足什么、不能声称什么。

这是**方法学主文 + 应用作为阴性对照/审计**，不是命中发现文。

### 层级 A（正文主贡献，现有数字已经够）

回答三个具体问题：

1. **协议。** 六种读出在 TrueDecoy / RandomDecoy 上谁能用。结论保持冻结：P2 按预注册规则胜出，但绝对能力只是中等（TrueDecoy）到与随机不可分（RandomDecoy）。P5 被否决。不重锁。
2. **标签。** 阳性集是不是“URAT1 抑制剂阳性药”？是 CHEMBL6120 的 IC50≤1 µM，主要是专利类似物；9DKB 配体 lesinurad 和 benzbromarone、dotinurad 因切法/冲突不在阳性里。所以“排不出活性”有两层：打分弱，以及基准没有在考教科书药。
3. **迁移。** 把该读出迁到临床库、做双百分位 AND 之后，已知促尿酸药不进门控。这不是“库选错了”，而是：**失败的活性检索器迁到应用库，不会变成发现引擎。**

这三块已经构成 *JCAMD* 可审的原研：转运体口袋上的协议锁定、诱饵类型敏感性、标签病理、以及一次真实临床库迁移。不需要湿实验。

### 层级 B（降级产品，不再当目的）

7 个优选 + GSK / Vecabrutinib **保留在结果里，改角色**：

- 它们是“锁定弱排序器 + 化学规则之后漏斗吐出的名单”，用来展示**若仍把百分位当活性证据会得到什么**。
- 操作定义改为：**双结构百分位交集 ∩ 类药规则**，不再写成“双节点计算候选”。
- GSK-3008348 可以留在讨论里作为**羧酸姿态假说**（酸根、贴近 URAT1 已知配体化学），依据是化学motif + 将来的对照校准 MD，**不是** S_U=97.5。
- Vecabrutinib 不再当 URAT1 跟进：不是酸、无促尿酸药理、入选只因为 CNN 百分位。NLRP3 侧模型分高，最多写成“炎症臂上的临床分子审计”，不写成双节点跟进。

裸 Pareto 大环继续当审计负例。Levotofisopam / Tegoprazan / 旧 P4 名单继续不进正文产品。

### 可选的第三条建设性规则（不重对接、不重锁 P2）

若还想在讨论里给实验者一个**比百分位名单更干净的假说定义**（明确不是本漏斗的生产门控）：

> 临床分子若要进入“值得测 URAT1 摄取”的化学假说，至少需要 **羧酸（或等价酸根）且生产/修复姿能靠近 Arg477**，而不是 CNN 上十分位。NLRP3 侧仍只是细胞 IL-1 分类器缩库，不能当 NACHT 结合证据。

这条规则会偏向 GSK 这类酸，排掉 Vecabrutinib。它**不能**回写进主表替代 τ=90，否则又是看过名单后改门控。只能作为 Discussion 的前瞻，或将来另开一篇。

## 4. 文章骨架（建议先投 JCAMD）

标题方向（不要写 discovered / dual inhibitors / candidates identified）：

*Protocol-first evaluation of URAT1 docking as an activity retriever, and why percentile gates cannot nominate dual-node gout hypotheses from a clinical library*

| 节 | 写什么 | 不写什么 |
|---|---|---|
| 引言 | 痛风需要双节点；计算上证据不对称；本文问对接能否当 URAT1 检索器，以及不能时漏斗该怎么读 | 本文将鉴定临床双靶候选 |
| 方法 | 现有 Methods 几乎可留；把“生产排序”改成“预注册读出，用于检验迁移，不用于鉴定活性” | 把 P2 写成已验证的 VS 引擎 |
| 结果 1 | 双诱饵、配对 bootstrap、自对接（现 R1–R2） | 用 TrueDecoy 显著来暗示 RandomDecoy 也行 |
| 结果 2 | 阳性集构成：469、骨架集中、lesinurad 不在阳性、冲突剔除 | 把 469 写成阳性药物金标准 |
| 结果 3 | 临床库迁移：漏斗计数、已知药对照表、7 名单作为**失败排序器的产出审计** | 7 个双节点候选、两个跟进要去测 |
| 结果 4 | 姿态 QC：优选在盒内；lesinurad 丢盐桥 → 百分位≠结合模式 | 姿态支持双靶 |
| 讨论 | 原目的不成立的逻辑；标签与打分两层失败；双节点医学问题仍在，但需要摄取实验或酸根/Arg477 规则，而不是 CNN 门控 | 假说足够软就可以点名跟进 |
| 结论 | 开源对接在本设定下不能作为 URAT1 活性检索器；百分位 AND 不能当作双靶提名；临床库名单仅审计 | 筛选结果在计算上合理，7 个是问题的答案 |

*Molecular Diversity* 近三年要的是点名 potential inhibitors + 100 ns。本改构与该模板冲突，**主投 JCAMD**。MD 有合格对照轨迹后再作为姿态压力测试补进，不把 RMSD 写成亲和力，也不用 MD 挽救百分位名单。

## 5. 现有材料怎么用

| 现有块 | 去向 |
|---|---|
| P0–P5、True/Random、超几何、配对 bootstrap | **主结果，加重** |
| 阳性 469 的标签审计（靶点对、lesinurad 缺席、类似物 27%） | **新主结果**，补进 Results |
| 8319→1588→1580 漏斗 | 迁移实验，证明弱检索器迁到应用库 |
| 已知痛风药对照表 | 主结果，不是“误读”附录 |
| 7 个名字 + τ 敏感性 | SI 或结果末表，标题改为 audit list |
| GSK 羧酸 / Vecabrutinib | 讨论：酸根假说 vs 百分位假说的对比，后者放弃 |
| MD 六体系 | 对照（晶体 lesinurad、NP3-146）必须跑；候选体系仅当讨论酸根假说时保留 GSK；Vecabrutinib@9DKB 不再作为必须 |
| NLRP3 ML | 缩库工具 + 饱和局限，不当发现引擎 |

## 6. 主张对照（改构后）

| 可以说 | 不可以说 |
|---|---|
| 预注册对接读出无法在 RandomDecoy 上检索 URAT1 活性 | 发现/鉴定了双靶候选 |
| 临床库百分位门控是一次阴性迁移实验 | 7 个优选是该科学问题的答案 |
| 阳性标签是 p≥6 的 URAT1 IC50，不是临床阳性药金标准 | 对接已选出能排序活性的方法（P2）所以可以筛库 |
| GSK 的羧酸化学仍可作姿态假说，不来自百分位 | Vecabrutinib 是双节点跟进分子 |
| 双节点仍是值得做的实验问题 | 计算漏斗已经给出可证伪的双节点候选 |

## 7. 和上次“P2 不能用”改稿的差别

先前把整篇改成“P2 不能用、撤回名单”，读起来像撤稿声明，产品空了。  
本次改构**承认原目的失败**，但把失败本身做成可审贡献：协议比较 + 标签病理 + 临床库阴性迁移。名单还在，角色换成审计。这不是再找一套词保住 hit 文。
