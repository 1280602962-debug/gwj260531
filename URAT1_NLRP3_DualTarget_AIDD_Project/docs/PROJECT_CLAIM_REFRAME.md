# 课题主张重锁：P2 不能当虚拟筛选活性读出

> 2026-08-25。不重选 Π\*（不改成 P0/P4/P5），但 **撤回“用 P2 百分位做双节点 hit 鉴定”**。
> 与 [`MANUSCRIPT.md`](MANUSCRIPT.md) 同步。旧的 Mol Divers“命名 7 个候选”计划（[`MOL_DIVERS_REVISION_PLAN.md`](MOL_DIVERS_REVISION_PLAN.md)）降为历史备忘，不再指导正文主产品。

## 1. 判定

P2（gnina CNNaffinity）在 TrueDecoy 上 AUC 0.58、EF@1% 2.59；在 RandomDecoy 上 AUC 0.54、EF@1% 0.22（CI 含 0，p = 0.99）。临床库更接近 RandomDecoy。该读出 **不能用于虚拟筛选活性判定、也不能用于百分位门控 hit 名单**。

当时规则下 P2 仍是唯一幸存者（P1/P3/P4 在 True 上失败，P5 在 Random 上零命中，P0 预注册为负对照）。这只说明淘汰赛有冠军，不说明冠军能用。更干净的预注册结论应是：六个读出均未达到多样化库可用的 VS 门槛，**对接排名不进入主结论。**

禁止：事后改锁 P0；放宽 τ 制造更多“命中”；用 MD/MM-GBSA 补富集；把 CNNaffinity 8.x 写成 pKi。

## 2. 课题改成什么

**主问题（方法学 / 阴性结果）：** 在与临床库无关的 TrueDecoy + RandomDecoy 上，现有 URAT1 对接/重打分读出能否支持多样化临床库的活性筛选？

**主答案：** 不能。RandomDecoy 上无富集；已知促尿酸药在 P2 池内不进上端；lesinurad 的 P2 第一构象丢失 Arg477 盐桥。双节点计算 hit 不能从本漏斗的对接百分位得出。

**次要、降级的记录（SI / 方法附录，不是正文产品）：**

- 临床库 8319 → NLRP3 分类器缩库 1588 → P2 双靶表 1579 有效分数：流程可复现，但缩库分数饱和、对接分不富集。
- 若仍对 P2 双分前 10% 做化学过滤，会得到 7 个名字（含 GSK-3008348、Vecabrutinib）。这是 **弱读出尾部的启发式湿实验面板**，不是富集 hit 名单，正文不称为优选候选或双节点计算候选。
- 裸 Pareto 四大环：对接偏置的负例。

**湿实验若做：** 纳入标准不能再是 \(S_U\ge 90\)。应预先规定化学/药理规则（例如临床库羧酸 + 已知 URAT1 对照；NLRP3 侧另选 IL-1 模型高分或工具化合物），与 P2 排名脱钩。GSK-3008348 可以因羧酸进入 URAT1 摄取面板，Vecabrutinib 可以因 BTK/炎症文献进入 IL-1 面板——**各自作为单端探索，不声称对接已证明双节点。**

**MD：** 六体系可以继续跑，但目的改成：晶体对照能否维持；P2 选出来的姿会不会立刻离开口袋。合格 ≠ 活性，更 ≠ 双靶。对照失败则该靶不解释。

## 3. 期刊

*Molecular Diversity* 近三年模板要命名 hit。本文主产品改为阴性协议评价后，更贴 **JCAMD / JCIM / 计算方法** 栏目。Mol Divers 仅当审稿人接受“对接读出不够用”的警示文时再投。

## 4. 正文主结果顺序（改后）

1. 诱饵泄漏审计（Random 无近邻泄漏 → 弱富集不是因为诱饵太近）。
2. P0–P5：无一达到多样化库可用门槛；P2 仅为规则幸存者。
3. 把该弱读出迁到临床库：已知 URAT1 药不回收；大环占据 Pareto。
4. 因此不从百分位提名 hit。7 分子表放 SI，标明启发式面板。
5. 姿态 QC + MD 计划：协议诊断，不是 lead 验证。

## 5. 一句话贡献（替换旧句）

预先锁定的 TrueDecoy/RandomDecoy 比较表明，gnina CNNaffinity 等 URAT1 对接读出不足以在多样化临床库上做活性筛选；据此，痛风双节点重定位不能从本漏斗的对接百分位鉴定候选，而应改为与排名脱钩的湿实验面板或新的 URAT1 评价方法。
