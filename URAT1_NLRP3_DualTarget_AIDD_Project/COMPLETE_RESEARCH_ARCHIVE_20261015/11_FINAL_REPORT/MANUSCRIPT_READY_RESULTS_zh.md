# 可直接写入文稿的结果句

下列句子里的数字都有归档文件。写的时候不要加“活性已被预测”这类延伸。

临床库 8319 个化合物来自 ChEMBL Explore Drugs 的分期与 ATC 导出。NLRP3 v1 分类器在五折骨架交叉验证上的平均 AUROC 是 0.8934、平均 AUPRC 是 0.9143。阈值 0.5 给出已存档的 1588 个化合物。同一临床库里只有 5 个落在训练适用域内。

URAT1 回归模型的合并折外 R² 是 0.508、Spearman 是 0.726。它没有用于临床库排序。lesinurad 和 dotinurad 的预测分别是 5.64 和 5.07，都低于 pActivity 6。

在 9839 个 URAT1 基准分子上，真诱饵集 EF@1% 最高的是重打在 GNINA 姿势上的 RTMScore（2.80），其次是 CNNaffinity（2.54）。Vina 是 0.43，minimizedAffinity 是 0.42。CNNaffinity 被用于后来已关闭的排序路线。RTMScore 因为随机诱饵集 EF@1% 为 0 没有进入生产。

生产协议上，lesinurad 三个种子的 CNNscore 选中姿势 RMSD 是 4.30、4.31 和 4.88 Å。只有种子 42 的九个姿势里存在 1.18 Å 的姿势。NP3-146 三个种子的 top-1 RMSD 是 0.82、0.67 和 0.68 Å。

A2 几何门的阳性似然比是 0.999，A1 是 2.20。正式准入用的是 A2 加上 NLRP3 完整结构门，至少两个种子双通过。156 个分子里 54 个达到这一步，与化学合格表相交得 37 个，冻结为 12 个主候选和 21 个备用。

第三阶段 B 完成 194 次对接。32 个新分子中 13 个结构与化学标记都通过，8 个结构通过但化学标记不通过，11 个结构未合格。已冻结的 33 个候选在同一规则下仍然全部通过。没有实验测量支持其中任何一个分子的双靶抑制。
