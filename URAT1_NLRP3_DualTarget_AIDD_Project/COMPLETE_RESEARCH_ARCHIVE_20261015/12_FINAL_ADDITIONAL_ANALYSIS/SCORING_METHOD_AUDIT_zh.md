# 六种评分

数据是已存的 9839 行 `mol_protocol_scores.csv`。没有新对接。评分方向和 Top-K 在计算前固定：P0、P2、P4、P5 越高越好；P1 Vina 与 P3 minimizedAffinity 越低越好。`k = max(1, floor(0.01 n))` 或 `floor(0.05 n)`。并列名次用稳定 mergesort，相同分数保持原文件顺序。

真诱饵和随机诱饵都是计算诱饵。真诱饵没有实验阴性证据，标签不能写成测定无活性。

## 覆盖与各自人群

真诱饵基准 5156 行（469 个活性，4687 个诱饵）。P0、P2、P3 覆盖 5156/5156。P1 为 5149，P5 为 5148，P4 为 5044。随机诱饵基准 5152 行；P4 只有 4407，覆盖 0.855，是六种方法里缺口最大的。

P2 与 P5 的共同人群：真诱饵基准 5148（468 活性，4680 诱饵），随机诱饵基准 5147（468 活性，4679 诱饵）。配对比较只用这个共同人群。各方法自己的指标另表报告，二者不混用。

在各自人群、真诱饵基准、按上述取整规则：

## P2 与 P5 的配对比较

共同人群上，Δ 定义为 P5 − P2。分层、成对 bootstrap 2000 次。种子 17、29、42、71、101 只改变随机数，不是五次独立实验。点估计在五个种子上相同。

真诱饵共同人群：ΔAUROC = 0.011，五个种子的 95% 区间都大约在 −0.013 到 0.035，包含 0。ΔPR-AUC = 0.004，区间包含 0。ΔEF1% = 0.216，区间大约从 −1.51 到 2.16，包含 0。ΔEF5% = 0.556，区间也包含 0。

随机诱饵共同人群：ΔAUROC = 0.014，ΔPR-AUC = 0.003，区间都包含 0。ΔEF1% = −0.216，区间大约从 −1.08 到 0，不支持 P5 更好。ΔEF5% = 0.428，区间包含 0。

没有用两个独立置信区间是否重叠来代替这个配对差。

## 姿势来源，以及为什么没有用这些分数提名

P0、P2、P3 来自同一次 GNINA 搜索，分数不同。P5 是在 GNINA 姿势上另做 RTM，和 P2 是同一姿势来源、不同分数。P1 与 P4 来自 Vina 姿势。P4 对 P2 则是姿势和分数都不同。生产协议的 `cnn_scoring` 是 rescore，不是 CNN 引导了整个搜索。

Rank 路线关闭，是因为自由自对接里按 CNNscore 选出的 lesinurad 姿势 RMSD 大于 2 Å，不是因为后来又找到了更好的活性模型。CNNaffinity 覆盖完整，所以曾被那条已关闭的路线使用；它没有成为酸筛选的最终提名分数。P5 在真诱饵集的早期富集看起来较高，但配对区间包含 0，而且随机诱饵集的 EF1% 为 0，所以没有用它替换提名规则。A2 加上 NLRP3 结构门是几何可及性筛选，不是新的活性预测模型。
