# 候选选择依据

主表 `ALL_COMPOUNDS_MASTER_INDEX.csv` 有 8319 行。每个临床化合物都在，未进入后续步骤的标记为相应的 `final_status`，没有从总表删除。

## 冻结名单当时为什么这样选

这是 2026-09-05 的决定，不是第三阶段 B 的决定。

1. 156 个已对接分子里，A2 与 NLRP3 完整结构门在至少两个种子上同时通过的有 54 个。
2. 这 54 个与当时化学合格表的交集是 37 个。
3. 37 个里、种子 42 的 A1 也通过、并且不是结构对照的，成为 12 个主候选：Lanifibranor、Tonapofylline、Caficrestat、Admilparant、Lintitript、Spiroglumide、Cavosonstat、Runcaciguat、Fulimetibant、PF-03882845、PSI-697、CR-3465。其中 Tonapofylline 和 Admilparant 是 2 个双通过种子，其余是 3 个。配置把“2 个也可以”写成了冻结规则，不是事后例外。
4. 37 个里没有进入 A1 主分支、并且不是 β-内酰胺的，成为 21 个备用。其中包括 lesinurad 和 verinurad。它们在 A1 下因为 CNNscore 第一姿势远离晶体羧酸位置而没有进主候选。
5. GSK-3008348 是结构对照，不在候选里。三个头孢因为 β-内酰胺不在备用里。
6. 三个只因药名规则被排除、结构上其实合格的分子（MK-5108、PIROMIDIC ACID、PRADOFLOXACIN）留在反事实表里，没有被提名。药名规则是已接受的历史局限，不是本次新加的。

PF-03882845 进入分子动力学预注册，是因为冻结规则把它放在主候选，并且计划只允许一个动力学对象。不是因为它的 CNNaffinity 最大。

## 其余分子为什么没有入选

| 状态 | 数量 | 原因 |
| --- | --- | --- |
| 临床库未过 NLRP3 0.5 | 6692 | 历史 v1 概率低于阈值 |
| 1588 池中不是酸性等价 | 1285 | 酸 SMARTS 未命中 |
| 酸性池未过化学软过滤 | 147 | 分子量、极性表面积或氢键计数 |
| 156 里对接了但未进冻结名单 | 123 | 结构种子不足，或化学标记、对照、β-内酰胺、药名规则 |
| 第三阶段 A 排除 | 7 | 非羧酸，规则不适用 |
| 第三阶段 B 结构未合格 | 11 | 对接完成，双通过种子少于 2 |
| 第三阶段 B 结构过、化学不过 | 8 | 冻结的 β-内酰胺或 PAINS/Brenk |
| 第三阶段 B 结构与化学都过 | 13 | 新计算，不是冻结成员 |

13 个新分子与 33 个冻结候选没有 ID 重叠。它们是同一套几何和化学规则下的增补观察，不是对 12/21 的替换，也没有按对接分数重新排序。

## 排序方法各自的人群

机器学习排名的人群是 8319。Rank 路线百分位的人群是合并后的 1580。结构门的人群是 156 加后来的 32。三者方向、准备和缺失值处理都不同，`RANKING_TRANSITIONS.csv` 把它们并列，是为了看到一个分子在各阶段的位置，不是为了把名次相加。CNNscore、CNNaffinity 和 Vina 没有相加。
