# 模型边界

1. 0.8934 是 v1 五折 AUROC 的平均值。v2 合并外层测试是 0.8896。两数都不是临床化合物的真实活性概率。
2. 临床库 8319 个化合物里 5 个落在适用域内。全部冻结候选和全部第三阶段 B 新分子都在域外。
3. 1588 的成员表已冻结。补充材料重训得到 1377。不要把二者当成同一次计算。
4. v2 的 1525 与历史 1588 的 Jaccard 是 0.670。第三阶段只从差异里取出 39 个化学通过分子做范围审计，没有重做全库对接。
5. URAT1 回归的 R² 是 0.508，且对 lesinurad 和 dotinurad 的预测低于文献活性。它没有参与候选排序。
6. 类别不平衡使 NLRP3 的 EF@10% 上限约为 1.65。1.57 不能单独写成强区分。
7. 训练集与临床库的骨架重叠、测定来源偏差和概率校正，v1 没有一份与 1588 同时生成的完整审计。v2 的泄漏检查只覆盖 v2 自己的划分。
