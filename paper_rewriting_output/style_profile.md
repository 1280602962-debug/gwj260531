# Style Profile（立项/技术报告）

## Tone
- 贡献优先、审稿人意识、边界清晰
- 中文用户沟通；关键术语保留英文（kinact/KI、mPAE、DFG-in）

## Structure Preference
1. 贡献句 → 为何需要 → 证据与缺口 → 推进路线 → 不做清单
2. 计算与湿实验分层；WSL 与集群/许可分层
3. 疾病叙事放在「探针用途」而非「已验证适应症」

## Forbidden Patterns
- 指标堆砌无贡献映射
- 回顾性 AF3 富集写成发现
- 用 CC-90001/DSS pan-JNK 结果证明 JNK2 治疗优势
- 复活 Δsel/Gly87 作为主选择性证据
