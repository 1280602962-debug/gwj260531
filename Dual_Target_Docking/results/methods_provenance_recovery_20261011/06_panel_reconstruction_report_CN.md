# 八对评价集的构建证据

八对的解决程度都是 PARTIAL。成员和正式类别可以追溯，抽样顺序没有完整复现。没有改种子，也没有增删分子去凑齐沉积表。

先前敏感性目录中“严格 6.5/5.5 不是 805 条纳入规则”这句话需要按靶点对改写。Track-B 五对和 AChE/BChE 的构建脚本使用严格 6.5/5.5 并排除灰区。EGFR/HER2 和 PIK3CA/mTOR 的构建脚本使用 θ=6.0。八对进入正式分析后的标签都是 θ=6.0。这句话只在本报告更正，不改旧文件。

证据表：`05_panel_construction_evidence.csv`。脚本读取 `d824eb6b` 的构建程序和 `a0ef2726` 的沉积面板，并与正式 805 条交叉。类别重叠在本轮重新核对：AChE/BChE 的 98 个共同分子类别差异为 0，EGFR/HER2 的 109 个共同分子类别差异为 0，PIK3CA/mTOR 的 48 个分子类别差异为 0。Track-B 沉积面板上 strict 类与 `theta6_class` 的差异为 0（550/550）。

PIK3CA/mTOR 的配额是 dual 18、A_only 14、B_only 12、neither 4。名称含 PROTAC 或 rapalog 的条目在脚本中被排除。指定种子分子的名单在 `build_pik3ca_mtor_panel48.py`，本次没有改名单。

## 对正式结果的影响

805 条的成员和 θ=6.0 类别与上述沉积关系一致，没有发现需要改标签才能解释的集合错误。AChE 的一次重放失败说明“读到脚本”还不等于“恢复了当时抽出的那 100 人”。EGFR 与 PIK3CA 的候选遍历顺序依赖当时的 API 或缓存，本次没有恢复。
