# 稿件修改提示

本轮没有修改稿件或补充材料。下列句子只是后续可选用的写法。

正文若提到化学多样性，应写成冻结评价集上的事后敏感性分析，而不是八对分子原有的统一抽样规则。EGFR/HER2 历史构建中的骨架上限、AChE/BChE 以 ChEMBL 编号前缀代替骨架的做法，都不能改写成当前 CAP5。正式人群的主结果继续使用未过滤的 867 条合格观察。

CAP5 适合放在补充材料。建议同时给出 `point_change_class` 和 `evidence_status`，并保留点估计、区间和样本量。0.02 带宽不能写成显著性或等效性界值。需要写明排除由骨架重复和冻结哈希决定，不按对接分数保留；无环分子不占非空骨架名额；同一骨架在不同类别中不合并。

Module D 应说明是在 CAP5 名单上重新拟合，排除成员既不训练也不测试，fold 没有重分。原本缺 fold 的成员沿用原规则退出化学 OOF，编号见 `CAP5_MODULE_D_FOLD_AUDIT.csv`。Module I 使用 CAP5 自己的八对方法差值；较小名单上的 Top-k 要单独说明 k，不能直接称为原 Top-10。

本轮未重评的五随机种子、替代受体、外部验证和其他 Stage 2 模块，应写“未在本轮重评”，不要补写 CAP5 数字。正文不需要因为 CAP5 替换 PIK3CA/mTOR 的 Q110 主结果：该 pair 没有分子被排除，M0 `summary_min` 仍是 0.5800781250，区间仍包含 0.5。
