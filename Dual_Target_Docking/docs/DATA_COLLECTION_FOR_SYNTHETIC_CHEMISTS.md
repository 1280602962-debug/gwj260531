# 数据怎么收集（给小分子合成方向同事看的说明）

这份说明尽量不用计算黑话。  
目标只有一个：**把「哪个分子、对哪个靶、活不活、活到什么程度」整理成电脑能用的表格**，后面对接和打分才能跑。

你不需要会对接软件。你需要会的是：查文献、查公开数据库、整理实验室本子上的活性、按规则填表。

完整课题背景见 [`PROJECT_MASTER_PLAN.md`](PROJECT_MASTER_PLAN.md)。

---

## 0. 先用一分钟搞懂我们在收集什么

想象你们在筛「一箭双雕」的分子：希望**同一个化合物**对靶点 A 和靶点 B 都够好。

计算要回答的问题是：

> 如果只看电脑对接分数，会不会经常把「其实只对一个靶很强」的分子误当成双靶好分子？

所以我们要准备的，不是「越多分子越好」，而是下面四类**已经知道答案**的分子（最好两端都测过）：

| 类型 | 人话 | 为什么要 |
|------|------|----------|
| **双活** | 两个靶都够强 | 正例：我们希望排在前面的 |
| **只活 A** | A 强、B 弱（B 测过了，确认弱） | 最重要的「易混进来的假双靶」 |
| **只活 B** | B 强、A 弱 | 同上 |
| **双弱** | 两个靶都测过，都弱 | 明确的阴性 |

**铁规矩：**  
「没测过」≠「没活性」。  
没测过的分子，**不要**当成阴性填进去。宁可空着，也不要瞎标。

---

## 1. 你们要准备几张表（像 Excel 就行）

建议建 4 个工作表（或 4 个 csv）。名字可以叫：

1. **分子总表**（每个化合物一行）  
2. **活性明细表**（一个分子对一个靶、一次实验一行；两端各一行）  
3. **文献双靶分子表**（从论文抠出来的、明确按双靶设计的分子）  
4. **实验室自家分子表**（NLRP3 / JNK1 那批，最后用来「盲测」，不要提前泄露给训练）

计算同事后面会把表接进对接流程。你先保证：**结构对、数字对、来源能追溯**。

---

## 2. 一张「分子总表」里必须有什么

每一行 = 一个化合物。

| 列名（可中文） | 填什么 | 例子 / 注意 |
|----------------|--------|-------------|
| 内部编号 | 你们习惯的编号 | GWJ-001 |
| 结构式 | 能画出来的结构；最好另存 **SMILES**（化学信息学用的一行结构码） | 不会写 SMILES 就画 ChemDraw，让计算同事转 |
| 中文/通用名 | 有就写 | — |
| 靶点对 | 这一行对应哪两个靶 | 如 NLRP3 + JNK1 |
| 设计方式 | 这个分子当初怎么做成「双靶」的 | 见下一节 |
| 是否文献明确双靶设计 | 是 / 否 | 论文标题或摘要写了 dual / dual-target 才算「是」 |
| 文献 DOI | 能打开的论文链接或 DOI | 方便复查 |
| 备注 | 系列、母核、批次等 | 「和 GWJ-003 同一母核」很重要 |

### 设计方式怎么填（合成同事最熟）

用你们日常说法即可，建议统一成三类：

| 填法 | 人话 |
|------|------|
| **融合型（fused）** | 两段药效团「焊」成一个骨架，中间几乎没有长链 |
| **连接型（linked）** | 两段药效团用一段 linker 连起来 |
| **拼合/重叠型（merged）** | 共用一块结构，看起来像一个药但兼顾两靶 |

不确定就写「待定」+ 备注结构特点，**不要硬猜**。

---

## 3. 「活性明细表」怎么填（最核心）

每一行 = **某一个分子 + 某一个靶 + 某一次实验读数**。

| 列名 | 填什么 | 注意 |
|------|--------|------|
| 内部编号 | 和总表一致 | |
| 靶点名字 | 如 JNK1、NLRP3 | 写全称或统一缩写，全表一致 |
| 实验类型 | 酶活 / 结合 / 细胞通路 / 细胞表型 | **尽量分开写，不要混在一列当同一件事** |
| 读数 | IC50、抑制率%、Kd 等 | 原样保留单位 |
| 单位 | nM、μM、% 等 | |
| 浓度条件 | 如果是单点抑制率，写清浓度 | 「10 μM 下抑制 80%」 |
| 文献或实验记录 | DOI、ChEMBL 编号、或实验室本编号 | **必须能回溯** |
| 年份 | 发表年或实验日期 | 自家分子尤其重要（后面按时间盲测） |

### 怎么判断「强 / 弱」（先用一个简单尺子）

计算正式跑之前，课题组要**共同定一个阈值**。建议先用下面这套（可再改，但要全组统一）：

- 若有 **IC50 / Ki**：  
  - **强**：≤ 1 μM（可写成 pIC50 ≥ 6）  
  - **弱**：≥ 10 μM（或测了但基本不活）  
  - **中间地带**：单独标记「灰区」，第一版分析可以先不用，或单独讨论  
- 若只有 **单点抑制率**：不要和 IC50 强行比；单独一列，并注明浓度。第一版公开集**优先用有 IC50 的**。

对**同一个分子**：

- A 强且 B 强 → 标成 **双活**  
- A 强且 B 弱（B 必须测过）→ **只活 A**  
- B 强且 A 弱 → **只活 B**  
- A 弱且 B 弱（两端都测过）→ **双弱**  
- 有一端没测 → **不要贴阴性标签**，写「缺测」

## 4. 数据从哪来：三条线，合成同事各干什么

### 线路 A：公开数据库里「碰巧两端都有数」的分子（量大，质量参差）

**目的：** 撑起公开评测集的体量。

**谁主做：** 计算同事拉库；合成同事**抽查和纠错**。

**合成同事具体干什么：**

1. 和计算同事一起先定 **2～3 对靶**（建议：一对是你们关心的 NLRP3–JNK1 作盲测专用；另外至少再选 1～2 对**公开数据多**的靶，比如常见激酶对，专门用来做公开表）。  
2. 计算从 ChEMBL / BindingDB 拉出「同一分子对两个靶都有记录」的清单后，你抽查：  
   - 是不是真的同一个化合物（结构有没有对错）  
   - 实验是不是酶活/结合（细胞数据另标，别和酶活混成一类）  
   - IC50 单位有没有写错（nM / μM 搞反最常见）  
3. 把明显离谱的行标红或删掉，并写原因。

**你不需要：** 自己从零学数据库接口。

---

### 线路 B：文献里「作者明确按双靶设计」的分子（量少，但最真）

**目的：** 金标准小集合；并标清融合型 / 连接型。

**谁主做：** **合成 / 药化同事最合适**（你们读双靶论文最顺）。

**怎么干（逐步）：**

1. **搜论文**（PubMed / Google Scholar / SciFinder 均可）  
   关键词示例：  
   `dual inhibitor` + 靶点名；`dual-target`；`bifunctional`（注意和 PROTAC 区分）；中文「双靶抑制剂」。  
2. **入选标准（同时满足更好）：**  
   - 文中明确说是双靶 / dual  
   - 最好有结构式  
   - 最好两端都有体外活性数字  
   - 若有晶体或对接图，记一下，但不是必须  
3. **每个分子抄进「文献双靶分子表」：**  
   - 结构（ChemDraw → 交给计算转 SMILES）  
   - 两个靶的活性数字 + 单位 + 实验类型  
   - 设计方式（融合 / 连接 / 拼合）  
   - DOI、化合物在文中的编号（Compound 12 等）  
4. **建议数量：** 先认真做 **30～80 个分子**就很好；宁少勿滥。  
5. **PROTAC / 降解剂：** 先别和普通双靶小分子混在一张主表里；另开一页，标「特殊机制」。

---

### 线路 C：你们实验室自己的 NLRP3 / JNK1 分子（最后考试用）

**目的：** 当「期末考试卷」——公开方法在自家分子上排得准不准。  
**原则：** 这些分子**不要**用来调模型参数；单独存放。

**合成同事具体干什么：**

1. 列出所有相关化合物（融合型、连接型都要）。  
2. 按实验室本子整理：  
   - 结构、合成日期、批次  
   - 细胞活性（写清细胞系、读出指标、浓度、重复次数）  
   - 若有酶活/结合，单独一列，越全越好  
   - 细胞毒、初步 ADME/PK 若有，另表记录（用于「细胞好但体内差」的案例分析，**不是**用来训练「预测 PK」）  
3. 尽量补上对照信息（有就写，没有也如实写「无」）：  
   - 只有单靶战头的对照分子  
   - 两药联用对照  
   - 空白 / 溶剂对照  
4. **按合成或测试时间排序**，方便做「用早期分子建方法、用晚期分子考试」。

## 5. 推荐你们两周内就动手的流程

### 第 1 天：开会定规矩（1 小时）

全组当场写死：

1. 公开评测用哪 **2～3 对靶**  
2. 「强 / 弱」阈值（例如 ≤1 μM 算强）  
3. Excel 列名按本文统一  
4. 谁负责线路 B（文献），谁负责线路 C（实验室），谁负责线路 A 抽查  

### 第 1 周：先做「金标准小表」+「自家表」

| 人 | 任务 | 完成标准 |
|----|------|----------|
| 合成 A | 文献双靶分子 ≥30 个 | 每行有结构、两端活性或明确缺哪端、DOI、设计方式 |
| 合成 B | 实验室分子全登记 | 每行有结构、日期、细胞数据、缺测处写「缺」 |
| 计算 | 搭空表模板 + 转 SMILES | 所有结构能被程序读入 |

### 第 2 周：公开库配对表 + 抽查

| 人 | 任务 |
|----|------|
| 计算 | 拉出「两端都有 IC50」的配对清单 |
| 合成 | 抽查 50～100 行：单位、实验类型、是否同物 |
| 全组 | 统计四类分子各有多少；若「双活」太少，就增加一对公开靶或降低期刊预期 |

## 6. 一张「够不够用」的人话清单

第一版公开分析，建议至少看到：

| 类别 | 建议数量级（每个公开靶点对） | 说明 |
|------|------------------------------|------|
| 双活 | 尽量几十个以上 | 太少统计不稳 |
| 只活 A / 只活 B | 尽量和双活同级或更多 | **这是最关键的对比组** |
| 双弱 | 有更好 | 没有也可先用「明确阴性」补充 |
| 文献金标准 | 全部靶点对合计 30～80 | 质量优先 |
| 实验室盲测 | 你们现有多少算多少 | 诚实登记，缺测写缺测 |

如果「只活 A / 只活 B」几乎没有：  
后面无法证明「电脑是不是爱把单靶分子误当成双靶」——这张表就要优先补。

---

## 7. 合成同事最容易踩的坑

1. **把没测的当成没活性** → 严禁。  
2. **细胞活性和酶活混成一列** → 分开；细胞单独用于盲测/附录。  
3. **nM 和 μM 写反** → 填表后抽查数量级（一般酶活不会动不动就「0.001 nM」满天飞）。  
4. **同一分子多个编号没合并** → 用结构合并，不要只靠内部号。  
5. **连接型分子和 PROTAC 混在一起** → 机制不同，分开。  
6. **只收双活、不收单活** → 单活才是打假用的「刁难题」。  
7. **结构只有图片、没有可编辑文件** → 至少 ChemDraw，方便转成程序用结构。

## 8. 你交出去的东西长什么样（验收标准）

给计算同事一个文件夹即可，例如：

```text
data_collection/
  01_分子总表.xlsx
  02_活性明细表.xlsx
  03_文献双靶金标准.xlsx
  04_实验室NLRP3_JNK1.xlsx
  structures/          （ChemDraw 或 mol 文件，按内部编号命名）
  README.txt           （阈值约定、日期、负责人）
```

`README.txt` 里用白话写清：

- 强/弱怎么定的  
- 哪些表可以公开、哪些仅内部  
- 实验室表是否允许用于调参（默认：**不允许**）

---

## 9. 和计算分工的一句话

- **合成同事：** 保证「分子是谁、测了什么、数字对不对、设计类型对不对、来源能不能找回」。  
- **计算同事：** 保证「结构能算、对接能跑、表格能自动检查、没测的不会被当成阴性」。

你不需要理解对接分数怎么加。你只需要把**真实的分子和真实的活性**按上面的规矩摆好。
