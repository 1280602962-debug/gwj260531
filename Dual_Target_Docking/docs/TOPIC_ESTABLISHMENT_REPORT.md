## 2. 「双靶存在的问题」——结论是如何得到的

### 2.1 先分清：问题有两层，不能混谈

| 层级 | 问题表述 | 主要伤害 | 证据成熟度（立项时） |
|------|----------|----------|----------------------|
| **层甲：对接与类型** | 融合型、连接型分子难易不同；连接型构象多、两端共晶极少 | 姿态不准、类型分治困难 | **部分已知**（结构常识 + 共晶稀缺已核实） |
| **层乙：分数怎么合** | 两端各打一次分后，简单相加/平均，容易把「只强一端」抬成双靶候选 | 名单污染、合成资源浪费 | **逻辑强、文献有近亲；本库尚未用数据打假表坐实** |

本课题**主攻层乙**；层甲降为子问题与加分项（文献金标准 + 双端共晶姿态质检）。

### 2.2 推导链（从现象 → 可检验命题）

下面按「观察 → 机制推断 → 可证伪命题」写出，避免把假说写成事实。

#### 步骤一：实务默认做法（观察）

双靶虚拟筛选的常见操作是：

1. 同一分子对靶甲、靶乙**各做一次独立对接**；  
2. 得到两个分数后，用**相加、平均、取较小值或排名平均**合成一个「双靶分」；  
3. 按该分排序，挑选靠前分子进入合成或实验。

这一操作在药化计算与多靶筛选实践中普遍存在；本仓库方案与调研文档亦将其列为默认基线（而非个别实验室的偶然习惯）。

#### 步骤二：为何这种做法会系统性出错（机制推断）

推出「会出问题」靠三条同时成立的机制，而不是靠直觉：

1. **两边分数本来就不好比**  
   不同蛋白口袋、不同打分尺度，甲靶上的「−9」与乙靶上的「−9」含义不同。直接相加/平均，等于默认两边尺子已经对齐——这一默认通常不成立。

2. **药效不必对称**  
   真实双靶分子往往是「两端都够用」，不一定「两端分数一样高」。一端极强、一端勉强，简单平均仍可能很高；一端极强、一端很差，若另一端分数噪声偏高，平均分仍可能进前列。

3. **筛选名单关心的是决策错误，不是平均误差**  
   最贵的错误是：把**只对一个靶很强**的分子当成双靶苗子（假双靶）。随机无关分子（普通诱饵）太容易被分开，会让人误以为方法很好；**只强一端**的分子才是双靶任务的硬负例。

由此得到立项用的**核心假说（尚未用本项目数据证实）**：

> 在「两端都有活性标签」的分子集合上，朴素拼分会相对抬高「只强甲 / 只强乙」分子的名次；强调「两端都不能太差」、并先把两边分数放到同一套概率尺子上的方法，应能降低这种污染。

#### 步骤三：用什么证据支撑「值得当成课题」而不是空想

| 证据类型 | 内容 | 作用 |
|----------|------|------|
| **实验室语境** | 已有双靶设计分子与细胞读数；计算若继续简单拼分，名单易偏；短期难补齐系统亲和力与动物药效 | 说明**有真实使用场景**，适合做方法+基准，而不是硬写成功成药故事 |
| **领域近邻** | 已有「双靶对接分数融合」个案；已有单靶虚拟筛选「评测设定会翻转结论」的工作；已有对接打分泄漏与评测纪律类工作 | 说明缺口是「**配对分子 + 防假双靶 + 开放基准**」，不是从零发明对接 |
| **反面对照** | 双靶**生成**模型增多，但「怎么判别/排序才算双靶够格」的尺子仍弱 | 说明做**判别与评测**有独立价值 |
| **数据可行性抽查** | 已锁定三组公开靶点对，公开库上能分出双强 / 只强甲 / 只强乙 / 双弱（见靶点对选择报告） | 说明假说**有地方可测**，不是不可操作 |
| **技能审计** | 外部审计框架判定：问题位置强、零件可旧、主研究问题可证伪；与近邻工作中等重叠但可辩护 | 说明**值得做、未被判死**，但必须靠打假表立住 |

#### 步骤四：明确「现在还不能写进论文结果」的句子

下列句子在打假表出来之前，**只能当假说，不能当结论**：

- 「我们已经证明简单平均有害」；  
- 「校准短板一定优于朴素融合」；  
- 「对接排序等于真实双结合强弱」。

立项阶段允许的结论只有：

- **问题结构成立、可检验、有数据与场景支撑，因此值得开展。**

### 2.3 层甲（类型与对接准度）如何进入本推导

共晶目录表明：**同一双靶配体两端都有晶体的例子极少**。  
因此「按融合/连接把对接全面做准并大规模证明」在证据上先天不足——这不是否认问题重要，而是说明它**不宜单独作为冲高影响力方法文的主命题**。  
正确位置是：用少量姿态金标准做质检，用文献整理的设计类型做分层，回答「连接型是否更难、是否要分开处理」。

## 3. 为什么要开展这个课题

### 3.1 科学理由

1. **纠正默认协议可能存在的系统偏置**  
   若打假成立，影响的是双靶虚拟筛选的默认拼分习惯，而不是多报一个对接精度数字。

2. **把任务说清楚**  
   双靶筛选的关键决策是「像不像双靶」，不是「两边平均分高不高」。任务重定义本身构成可检验贡献。

3. **补开放评测**  
   缺少带四类标签、两套负例、防泄漏划分的配对基准时，不同文章的「双靶对接很好」无法公平比较。

### 3.2 应用理由（本实验室）

- 需要一条计算侧门槛：**先过「两端都还过得去」再加大合成与细胞投入**。  
- 私有细胞数据适合做**时间盲测排序参考**，不适合在缺亲和力时宣称「证明了双结合」。  
- 课题交付物是方法、基准与流程，与当前实验资源匹配。

### 3.3 可行性理由（已做的立项动作）

| 动作 | 含义 |
|------|------|
| 冻结三组公开靶点对 | 有规模、能分四类、能对接 |
| 文献池（百篇级 + 高分刊补充） | 可补设计类型与金标准分子 |
| 方案与审计 | 主问题、不做清单、证伪条件已写清 |
| 引擎选择原则 | 不靠新对接器立题；主引擎可复现即可 |

### 3.4 发表与风险理由

- **值得做：** 诊断型问题 + 开放基准，比「再卷对接精度榜」更贴高水平方法刊的叙事习惯；稳健药化计算刊可作为保底。  
- **主要风险：** 真双靶配对仍偏少；若所有融合方法一起垮，说明瓶颈在对接信息本身——这在方案里视为**可证伪成功**（题目被否，但科学上仍有结论）。  
- **一票否决式风险：** 把细胞活性当成双结合金标准、或宣称「全球首个」却无检索限定——立项时已禁止。

## 4. 与最初想法的对比：为何主线是「防假双靶」而不是「按类型对接更准」

| 维度 | 最初：类型化对接更准 | 现在：防假双靶拼分诊断 |
|------|----------------------|-------------------------|
| 直觉贴合度 | 高（合成更关心结构类型） | 中（更偏筛选决策） |
| 金标准 | 极缺（双端共晶少） | 可用公开配对活性（有局限但可规模化） |
| 可证伪表 | 难做大、难稳 | 一张打假表即可立住或打死 |
| 与「不新造对接软件」 | 易滑回调参工程 | 一致 |
| 作为主课题 | 更难冲「任务级」贡献 | **更值得作主线** |
| 作为副线 | — | **必须保留**：类型分层 + 姿态质检 |

**取舍结论（立项决策）：**  
主线做层乙（拼分与假双靶）；层甲作为子问题与质控，避免两个承诺绑死成一个无法完成的大题。

## 5. 课题边界（写进立项书用）

### 5.1 本课题承诺回答

- 在选定公开靶点对与统一对接协议下，朴素拼分是否更易抬高「只强一端」分子？  
- 校准后的短板式合并能否改善「双强相对只强一端」的排序？  
- 换靶点对、换真阴性/随机诱饵设定后，结论是否大体同向？

### 5.2 本课题不承诺回答

- 某个分子在生理条件下一定双结合；  
- 对接分数等于实验亲和力绝对值；  
- 公开库活性一定对应所选用的那一条晶体结构；  
- 已解决全部融合型/连接型的姿态精度问题；  
- 动物药效或成药性预测。

### 5.3 已知局限（立项时即承认）

- 公开活性与对接结构之间存在实验条件与构象错配；  
- 公开配对集多数缺少设计类型标签；  
- 因此排序结论是**协议内的相对诊断**，不是绝对药理真理。

这些局限不否定立项，但决定了**主张必须写窄**。

## 6. 立项判决（一页纸）

| 项 | 内容 |
|----|------|
| **问题** | 双靶筛选默认「两端对接 + 简单拼分」，在分数不可比与硬负例存在时，可能系统性制造假双靶候选。 |
| **问题来源** | 实务默认操作 + 机制分析 + 实验室需求 + 领域近邻缺口；**主害尚未被本项目数据证实**。 |
| **课题目标** | 建立可复现的双靶兼容性评测与排序协议，用打假表检验并纠正朴素拼分。 |
| **为何现在做** | 靶点对已可锁定、文献与方案已齐、审计认为可做且未被判死；继续空转文档收益低。 |
| **成功标准** | 严格划分下，朴素拼分的「只强一端」污染显著高于短板校准法；或二者一起失败并诚实报告对接信息不足。 |
| **失败可接受形态** | 打假不成立 → 收敛为「协议审计负结果 + 数据基准」或降级期刊，不硬写创新。 |

**最终一句话：**  
开展本课题，是因为双靶计算筛选里「假双靶」风险在逻辑与场景上足够真实、可用公开配对数据检验，且比「全面解决类型化对接精度」更具备可完成的证据形态；**是否真有害，必须以打假表为准，立项不等于已经证明。**
