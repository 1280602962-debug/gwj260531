# 14-slot receptor provenance

Date: 2026-09-18  
Machine table: `data/provenance/receptor_input_registry.csv`  
Rebuild: `python3 scripts/qa/build_receptor_input_registry.py`  
Rule: deposited PDBQT files are the receptors. This document does **not** reconstruct protonation, tautomer, or missing-loop protocols. Receptors were **not** re-prepared.

Eight pairs use 16 pair-slots and **14 unique PDB IDs** (JAK1 `6N7A` and PPARA `6LXA` are shared). Cognate RMSD source: `data/jcim_novelty_v0/tables/all14_cognate_rmsd_calcrrms_v1.csv`.

## Evidence vocabulary (only these three)

- **confirmed**: the named file exists on disk and was inspected, or a metadata field was read from that file (chains, water atoms, box JSON).
- **metadata_only**: a protocol, yaml, or recovered script describes a recipe, but there is no log/hash proving that the deposited file is that recipe's output.
- **not_recoverable**: no deposited file, script, or log supports the claim. Not invented here.

## Protein-preparation boundary

Protein-preparation **method** is `not_recoverable` for 13 of 14 unique PDBs. A recovered AChE script (`data/ache_bche_panel_v0/scripts/freeze_receptors_cognate_qc_v2.py`) calls `mk_prepare_receptor.py` for **4EY7** and **6ZWI**. Production BChE is **4BDS**, not 6ZWI. There is no log that deposited `ACHE_receptor.pdbqt` is that script's output. 4EY7 preparation method is therefore **metadata_only**. 4BDS remains **not_recoverable**.

This repository does **not** claim that all 14 receptors were generated by Meeko or by Schrödinger Protein Preparation Wizard.

## Boxes

EGFR/HER2 uses **corrected** cognate-heavy-atom boxes (`*_box_corrected.json`; status `current_primary_corrected_heavy_atom`). Uncorrected `3POZ_box.json` / `3RCD_box.json` remain on disk as **superseded** inputs.

Track-B boxes: cognate heavy-atom AABB + 5 Å, min edge 20 Å (`track_b_local_run_v1.yaml`).

PIK3CA and AChE boxes: deposited JSON; file existence is confirmed. Construction wording beyond the JSON is not invented.

## What must not be claimed

- A common Protein Preparation Wizard / pH / missing-loop protocol across 14 slots.
- That reproducing Vina scores from these PDBQT files equals re-preparing receptors from the original PDBs.
- That Meeko prepared every receptor.
