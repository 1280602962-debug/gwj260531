# 本文三条贡献（定稿用，不再加新口号）

本文是回顾性评价研究，不是新对接算法，也不是双靶药物发现。摘要、引言末段、讨论开头和投稿信只用下面三条。

| 条 | 本文做了什么 | 已有研究已回答什么 | 本文没有回答什么 |
|---|---|---|---|
| 1. 任务比较 | 固定同一评分通道，比较 dual–A-only、dual–B-only 与 dual–neither | 双靶筛选里单靶抑制剂可造成假阳性（Zhou 等）；不同基准负类会改变性能 | 没有提出新的四状态算法；没有证明“只改生物学定义、分子集合不变”时差值有多大 |
| 2. 竞争解释 | 同一交叉验证划分下，比较仅配体 ECFP4 与 ECFP4+对接 | 物化性质和二维结构本身可带标签信息 | 不能说对接分数来自二维结构，也不能说任何模型都用不上对接信息 |
| 3. 结构对应 | 看对应口袋是否优于非对应口袋，并在内部留出集上复查 | 激酶选择性基准检验相近口袋能否被结构方法分开 | 差值区间含 0 不等于口袋信息为零；也没有证明稳定的结构机制 |

不要再写成：普适双靶识别、新预测模型、或已经分离出结构贡献。
