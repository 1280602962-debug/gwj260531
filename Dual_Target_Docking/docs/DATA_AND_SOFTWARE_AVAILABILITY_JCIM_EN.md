# Data and Software Availability

## Data and Software Availability

Benchmark membership, experimental-state labels, receptor and docking-box definitions, per-ligand docking scores, analysis tables, and all scripts used to regenerate the reported statistics and figures are available in the `Dual_Target_Docking` directory of the public repository at https://github.com/1280602962-debug/gwj260531. `data/jcim_novelty_v0/tables/MASTER_RESULTS_TABLE.csv` indexes the principal numerical results and their source tables, including independent GNINA pose-generation scores (Table S32), PIK3CA occupancy shifts (Table S33), document-blocked CV (Tables S39–S40), the frozen literature-year split (Table S41), the assay-context metadata review (Table S42), BindingDB independence counts (Table S43), the θ = 6.0 pair census (Table S44), property-caliper matching (Table S45), AND-filter operating points (Table S46), ligand-only full-map AUROC (Table S47), reconstructed EGFR/HER2 cognate QC (Table S3), and the evaluation contract (`DUALFOURCLASS_EVALUATION_CONTRACT_v1.json`). SHA-256 checksums of manuscript-facing tables are in `REVISION_CHECKSUM_MANIFEST_v1.csv`. The ChEMBL supply audit was frozen on 2026-07-23; the high-confidence activity view was fetched on 2026-08-26. A versioned GitHub Release and Zenodo DOI will be issued from a tagged snapshot, not from this moving branch. The analysis environment and zero-docking reproduction commands are documented in the repository README.
