# Data and Software Availability

## Data and Software Availability

Panel membership, experimental-state labels, receptor and docking-box definitions, per-ligand score tables, analysis tables, and the scripts used to regenerate the reported statistics and figures are available in the `Dual_Target_Docking` directory of the public repository at https://github.com/1280602962-debug/gwj260531. All numerical analyses can be reproduced from the deposited score tables; raw production pose archives are not required for regeneration of the reported statistics. Typeset Supporting Information contains Tables S1–S13.
