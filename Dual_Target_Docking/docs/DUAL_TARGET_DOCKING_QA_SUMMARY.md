## 1. 双靶点对接在做什么？

**问：** 双靶点对接是不是把一个分子同时对接进两个蛋白形成三元复合物？

**答：** 一般不是。普通双靶点抑制剂（merged / fused / linked）通常是：

1. 同一配体分别对接靶点 A 与靶点 B（两个独立二元复合物）；
2. 再把两侧得分/姿态质量融合成“双靶兼容性”分数。

真正需要“桥接两个蛋白”的三元建模，主要出现在：

- PROTAC / 分子胶（ligand–E3–POI）；
- 少数同蛋白双价（bivalent）体系。

因此论文叙事上应区分：

| 对象 | 物理图景 | 打分目标 |
|------|----------|----------|
| 普通双靶抑制剂 | 两个独立二元复合物 | 两侧都够好、且优于单靶偏爱 |
| PROTAC / 双功能降解剂 | 可能涉及三元/桥接几何 | linker 几何、三元兼容、降解相关指标 |

## 2. 设计类型：linked / fused / merged

**问：** Morphy 分类对对接有什么含义？有没有按类型系统比较对接效果的文献？

**答：**

- **Merged**：共享药效团，两侧口袋重叠度高，更像“同一结合模式在两个靶上的迁移”。
- **Fused**：骨架紧凑耦合，构象自由度中等。
- **Linked**：两端药效团由 linker 连接，柔性高、应变与构象熵问题突出。

文献更多讨论化学设计与 ADME，**几乎没有**按 linked/fused/merged 系统对比对接成功率的公开基准。这是可发表的空白之一，但需要自建 benchmark，不能假装已有标准答案。

## 3. 现有软件/流程的核心问题

**问：** 双靶点对接最主要的科学/工程问题是什么？

**答：** 常见失败模式（按优先级）：

1. **假阳性放大**：两侧各自“看起来还行”的单靶假阳性，一乘就变成“双靶候选”。
2. **分数尺度不可比**：A、B 口袋物理化学差异大，原始 docking score 不能直接相加/取平均。
3. **缺少“两端都够好”的目标函数**：均值会掩盖“一端极好、一端很差”。
4. **姿态误差掩盖**：分数好但 pose 错，后续融合无意义。
5. **Linked 柔性/应变**：两端姿态各自最优，但整体应变/冲突未建模。
6. **PROTAC 特有**：缺 bridge / ternary 几何约束时，按普通双靶融合会系统性偏。

Zhou et al.（JCIM 2013）等对双激酶抑制剂的回顾表明：对接有用，但**假阳性偏高**，这与“双靶融合放大噪声”一致。

## 4. 创新点应放在哪里？

**问：** 还要不要自己训一个新的深度学习打分函数？OnionNet / DeepRMSD 等是否过时？

**答：**

- 采样器（Vina 等）与单靶深度学习打分（GNINA、RTMScore、OnionNet 系等）都在快速迭代；**再做一个通用 pose scorer 很难成为 JCIM 级增量**，除非有明确数据与任务优势。
- 更可持续的创新在 **任务层**：
  1. **靶点特异校准**：把原始分映射到可比较的 \(p(\text{active})\) 或 Z/rank 空间；
  2. **阈值-边距 softmin**：强调“两端都过线”，惩罚短板；
  3. **硬负样本排序**：双靶分子应高于 A-only / B-only；
  4. **姿态/不确定性门控**：低置信 pose 降权或剔除；
  5. **类型条件专家**：merged/fused/linked（PROTAC 单独一支）。

推荐路径：**复用成熟引擎（Vina / GNINA / RTMScore）+ 可解释的融合头**，而不是先重训大 GNN。

## 5. 算法纸 vs 新分子纸；能否不做湿实验？

**问：** 双靶分子不能公开、也很难补湿实验，还能发 JCIM 吗？PROTAC 公开数据能不能当验证？

**答：**

| 路线 | 可行性 | 条件 |
|------|--------|------|
| 新分子发现纸（声称找到可成药双靶分子） | 弱 | 通常需要实验/明确公开结构与活性 |
| **方法/算法纸**（双靶兼容性打分与排序） | 较强 | 公开 benchmark + 严格对照 + 可复现协议 |
| 用已发表 PROTAC 数据验证 | **部分可以** | 只支撑 linked / 双功能分支，**不能**替代普通双靶抑制剂结论 |

推荐叙事：

> Heterobifunctional / dual-compatibility scoring：用公开共晶 + 回顾性活性（含 PROTAC 子集）证明方法，而不是声称发现新双靶临床候选。

PROTAC ≠ 普通双靶抑制剂：前者验证 linker/三元相关模块；后者仍需 kinase 等双抑制体系或共晶代理任务。

## 6. 评价什么？分数和实验对不上怎么办？

**问：** 对接分和 IC50 相关性差，是不是方法失败？主指标该是什么？

**答：**

- 不要把 **Pearson(score, IC50)** 当主指标；对接更擅长相对排序与富集，而非绝对活性回归。
- 建议主指标：
  - PR-AUC / ROC-AUC（双活 vs 单活/非活）；
  - EF / BEDROC；
  - **dual-vs-single pairwise accuracy**（双靶分子是否稳定排在单靶偏爱分子之上）；
  - 适用时：pose RMSD / success rate（CASF 风格）。
- 分数与实验不一致时，优先检查：校准、阈值、负样本定义、pose 质量、靶点构象，而不是立刻换引擎。

数据划分建议：scaffold split、leave-series-out、leave-target-pair-out，避免同系列泄漏。

基线：mean、min、Z-score mean、rank fusion，以及 GNINA/RTMScore 的简单融合。

## 7. 共晶数据与编目策略

**问：** 有没有足够的双靶共晶？怎么分类？

**答：**

- **Tier A（两侧都有配体共晶）** 稀缺，不能靠“数 PDB 条目”夸大独立体系数（例如 LpxA/LpxD 多条目常为同体系重复）。
- 编目字段应包含：靶点对、配体、设计类型（linked/fused/merged）、结构完备度、是否同一配体两侧都有结构、文献来源。
- 种子目录见：`data/dual_target_structures/dual_target_cocrystal_catalog.csv`  
  示例：Mcl-1/Bcl-xL（3WIY/3WIZ）、LpxA/LpxD、PknA/PknB、EGFR/HER2（TAK-285）等。

公开共晶主要用于 **pose/兼容性代理任务**；活性排序仍需 ChEMBL/文献回顾集。

## 8. 论文应写什么（问题—指标—原则）

**问：** 若聚焦“现有软件问题、评价指标、设计原则”，怎么组织？

**答：** 建议三条主线：

1. **问题诊断**：假阳性放大、尺度不可比、短板掩盖、linked 应变、PROTAC 误用普通融合。
2. **指标设计**：为何不用单一 Pearson；为何强调 dual-vs-single 与富集。
3. **设计原则**：校准 → 短板敏感融合 → 硬负样本 → pose 门控 → 类型条件；引擎可插拔。

贡献声明宜写“任务级方法与评价框架”，避免夸大“全新对接算法”。

---

## 9. 科学有效性与可行性（收紧版）

**问：** 这套思路科学上站得住吗？和 PROTAC 混在一起会不会有问题？

**答：**

- **站得住的核心假设**：双靶抑制剂需要在两个靶上各自形成合理二元结合；融合两侧校准后的兼容性信号，比未校准的原始分相加更合理。
- **必须收紧**：不要把 PROTAC 三元问题写成普通双靶的通解；`bridge_ok` 等项主要服务双价/PROTAC，不默认加到所有 linked 双抑制剂。
- **可发表最小包**：
  - 公开数据协议 + 基线对比；
  - 至少一个非 PROTAC 双抑制回顾任务 +（可选）PROTAC 子集作为 linked 特化验证；
  - 消融：校准 / softmin / 硬负样本 / 门控 各自贡献；
  - 失败案例分析。

1. **主失败模式**优先打哪一个：假阳性放大，还是 linked 几何/应变？
2. **默认叙事**：以 merged/fused 激酶双靶为主，还是以 heterobifunctional/PROTAC 为主？
3. **主指标**锁定哪一个（建议：dual-vs-single pairwise + PR-AUC）？
4. **三元建模**是否纳入正文范围，还是仅附录/未来工作？
5. **最小可发表包**的数据规模与靶点对清单最终如何划定？

## 11. 推荐落地顺序（相对工作量，非日历）

1. 锁定任务定义与指标（小改文档即可）。
2. 整理公开回顾集 + 共晶代理集（数据工程为主）。
3. 实现：现成对接 → 靶点校准 → softmin/硬负样本融合 → 基线对比（实现中等，依赖对接吞吐）。
4. 消融与失败分析（分析为主）。
5. 若仍不足：再考虑类型条件头或轻量学习融合（增加建模复杂度）。

不建议一上来重训通用深度学习打分网络。

---

## 12. 一句话结论

双靶点对接的可发表增量，不在“再做一个通用 sampler/scorer”，而在 **可校准、短板敏感、能区分双靶与单靶偏爱的任务级融合与评价框架**；PROTAC 公开数据可验证双功能/linked 分支，但不能替代普通双靶抑制剂的结论。
