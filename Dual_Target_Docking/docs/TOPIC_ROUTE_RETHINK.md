# 课题路线重审：当前拼分叙事为何不稳，以及可选主线

> **日期：** 2026-07-23  
> **性质：** 对用户质疑的书面回应与路线重审（**不是**再推销原 NMI 拼分叙事）。  
> **核心态度：** 「若对接本身不准，拼分再合理也救不了双靶对接」——**成立**；把文章写成「找一个好拼分法」——**新颖性弱、主因果也偏了**。

---

## 1. 你的三点批评，哪些成立

| 批评 | 判定 | 说明 |
|------|------|------|
| 思路不新 | **基本成立** | 两端对接 + 分数/排名融合，2017–2018 已有完整案例（Pérez-Castillo、Jaiteh）；再报「校准一下再 softmin」很难撑成高水平方法创新。 |
| 对接坏了拼分救不了 | **成立** | 拼分只重新排列**已有**两端分数；不能修正错误口袋、错构象、连接型采不到的姿态。原方案把主创新放在拼分，等于默认「两端分里已有足够信息」——这一点**从未被证明**。 |
| 现在整体不靠谱 | **部分成立** | 公开库活性≠所选晶体、多数分子无设计类型、主害（平均抬假双靶）仍是假说 → 作为冲高分方法文，证据链偏虚；作为内部筛选 SOP 讨论可以，不宜假装已是稳课题。 |

**因此：** 不应继续把「Dual-VSDS + 打假朴素拼分」默认写成唯一主文；需要先重新选定**真正要解决的双靶问题**。

## 2. 双靶分子「到底有什么问题」（按近年综述归纳）

较近综述/系统分析（均可核对 DOI）里，反复出现的是下面几类问题——**多数不是「缺一个拼分公式」**：

| # | 问题 | 综述/分析怎么说 | 计算能碰哪一层 |
|---|------|-----------------|----------------|
| P1 | **靶点组合是否值得做**（协同 vs 毒性） | 理性多靶设计的第一步是靶组合，不是对接[^R1][^R2][^R3] | 网络/组学选靶；**不是本仓库现有对接主线** |
| P2 | **化学怎么做**：融合 / 拼合 / 连接；活性比、分子量、成药性 | Morphy 类分类仍是基础；近年仍强调两端药效团如何合并与平衡[^R1][^R4][^R5] | 类型条件建模、物化过滤；**对接只是一端工具** |
| P3 | **计算筛选假阳性高** | 对接找双靶时假阳性高、富集有限，需联用其他方法[^R6]；in silico MTDL 综述仍把对接当常用但非充分步骤[^R7] | 可做评测/过滤，但**单靠拼分不解决根因** |
| P4 | **设计仍偏「已知靶 + 旧骨架」** | 2024 *J. Med. Chem.* 系统挖双靶配体数据：靶病理关联与化学新颖性仍受限，潜力未挖尽[^R8] | 数据/化学空间分析；**不是拼分** |
| P5 | **生成多、可重复判别尺子少** | 生成式多靶增多；评测与选择性控制仍难[^R3][^R9] | 基准有空间，但必须回答「评什么」 |
| P6 | **实验验证贵**：两端生化 + 细胞 + 选择性面板 | 几乎所有药化综述的共同瓶颈 | 计算只能降候选量，不能代替 |

**一句话：** 领域认为双靶难，难在**靶组合、化学类型与成药性、假阳性、验证成本**；「缺一个更聪明的两端分数加权」**不是**综述里的中心命题。

## 3. 若对接不准，拼分叙事的逻辑断裂在哪

```text
真实双靶分子
    → 两端对接（可能姿态错、分数噪声大）
        → 拼分排序
            → 名单

拼分只能改「怎么排」
不能改「两端分是否含真信息」
```

因此：

- 把文章目的说成「找到好拼分」→ **因果放错层**；  
- 单靶质检不过关时谈双靶拼分创新 → **不成立**；  
- 连接型分子若根本对不好，拼分再漂亮也只是排噪声。

原 Dual-VSDS 叙事**最多**诚实改写成：  
「在两端对接**已经可用**的前提下，聚合规则会不会额外制造假双靶。」  
这是**条件句**，不是「解决双靶分子对接不准」。

## 4. 可选主文路线（按靠谱程度重排）

### 路线 A — 停「拼分创新」主叙事（建议默认）

- **做什么：** 保留数据与质检基建；不声称 NMI 级拼分方法创新。  
- **文章形态：** 协议/负结果/基准短文，或内部 SOP。  
- **诚实点：** 承认主害未证、新颖性不足。

### 路线 B — 回到你最初的问题（类型相关的对接/评估）

- **问题：** 融合型 vs 连接型，在同一协议下姿态恢复与筛选表现差在哪？要不要分治？  
- **证据：** 双端共晶极少（硬）+ 文献 curated 类型分子 + 单端共晶/交叉对接。  
- **期刊预期：** 更贴 JCIM / 药化计算，难靠「新采样器」冲顶。  
- **前提：** 接受样本量小、主张写窄。

### 路线 C — 以实验室体系为主的「计算—实验」个案（往往最贴你的资源）

- **问题：** 针对 NLRP3/JNK1（或已定公开对），融合 vs 连接系列在对接预测、两端活性、细胞读数上是否一致；计算能否事先挡住明显假双靶。  
- **创新：** 不在通用算法，而在**可重复的系列级工作流 + 对照设计**。  
- **风险：** 被看成普通药化+对接配图；需把对照（只强一端、联用 vs 双靶分子）做硬。

### 路线 D — 数据/化学空间文章（跟 2024 JMC 系统分析对齐）

- **问题：** 某病域或某靶对上，双靶配体的类型、物化、选择性缺口是什么。  
- **少做：** 对接拼分。  
- **多做：** 与 Proschak 2024 同类的结构化挖掘 + 你的文献 100+ 篇精标。

### 路线 E — 生成/设计（不建议现开主线）

POLYGON、扩散双靶生成等已占位；无湿实验与清晰判别标准时更虚。

## 5. 若重写「文章流程」，建议的最小靠谱骨架

在选定 B 或 C 之前，任何计算主文至少应改成：

1. **问题定义（一段）：** 只选 P2/P3/P6 中的一个，写死不解决什么。  
2. **先单靶可用性：** 共晶自对接 + 富集；不过关则停止双靶断言。  
3. **再双靶问题：**  
   - 若走 B：按类型报告姿态/富集差异；  
   - 若走 C：系列分子的计算排序 vs 两端实验一致性；  
   - **拼分仅作附录对比**，不作唯一创新。  
4. **硬负例：** 只强一端必须来自「测过且弱」。  
5. **主张上限：** 协议内相对结论；不写结合真理、不写全球首个。

---

## 6. 阶段性建议（给课题组拍板）

1. **暂停**把「校准短板拼分 + Dual-VSDS」当作默认冲高分主创新。  
2. **先开一次选题会**，在路线 B / C / D 中三选一（或 A 收缩）。  
3. 若你更在乎「对接准不准、类型怎么办」→ **优先 B 或 C**，不要再绕回拼分。  
4. 已做的靶点对冻结、文献池、共晶编目**仍有用**，但是**基建**，不是文章故事本身。

**判决句：**  
当前拼分主线**不能**回答「双靶分子对接不准」；它最多回答「分数怎么排」。在对接信息未经证明之前，整条「打假拼分」冲方法大文的路径**确实不靠谱**；应按上面 B/C/D 重定主问题后再写流程。
