# 高可比性确认：可行性检查（未完成确认分析）

目的：看现有记录能不能在实验/化学背景更接近的子集上，复查 EGFR/HER2 与 JAK1/TYK2 的任务差异。  
这不是新的对接，也不是已经完成的确认。

## 已有材料能覆盖什么

| 材料 | 覆盖 | 实际核实到哪一层 |
|---|---|---|
| 高置信人源单蛋白字段筛查 | EGFR/HER2、AChE/BChE、PIK3CA/mTOR | 数据库字段规则，不是逐篇读原文 |
| 优先配体测定背景表 | 上述三对中的 162 个优先配体 | 审核者名为 `local_agent_metadata_pass` |
| 7 个不确定配体的原文抽查 | EGFR/HER2 1 个、PIK3CA/mTOR 3 个、AChE/BChE 3 个 | 读了专利/综述/公开全文，**未改冻结标签** |
| JAK1/TYK2 | 不在上述优先复核范围 | 没有同等测定背景表 |

## 结论

还不能据此声称已经完成“同一研究或同一化学系列内的确认分析”。

缺少的是：按预定规则、不看对接结果，抽出实验方案和化学系列更可比的子集，并在该子集上重算方向性 AUROC 与对照差值。现有 7 条原文抽查不能代替这件事。

本轮不降低 BindingDB 门槛去造一个外部集，也不为寻找有利结果继续筛同一数据库。若以后做确认，应另建版本，并事先写纳入规则。
