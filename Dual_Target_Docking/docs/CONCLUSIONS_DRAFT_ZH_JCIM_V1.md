# Conclusions（中文工作稿 · JCIM Articles）

## 5. 结论

本研究在八个具有双端实验活性的人源靶对上系统考察了双靶分子对接评价设定及其判别来源，主要得出三项结论：

第一，固定同一靶点评分通道时，更换对照类别及其对应的化合物集合即可显著改变对双靶对接性能的判断。能够区分双靶活性与双端低活性配体，并不保证能够区分双靶活性与单靶选择性配体，二者反映了不同的判别问题。

第二，表观观察到的对接判别在相当程度上可由不使用受体结构的配体化学特征解释，加入对接评分后的判别增量较为有限；同时，对应口袋评分优势在未使用的留出集中未能稳定重现，表明回顾性判别不能简单直接归因于口袋特异性三维结构互补。

第三，回顾性双靶对接评价应分别明确报告两个方向的选择性判别任务，并常规引入配体化学基线与口袋对应性等对照实验以辅助解释。此类回顾性评价指标反映的是在已知实验标签集合中的区分能力，不能直接等同于前瞻性虚拟筛选中的真实命中能力。
