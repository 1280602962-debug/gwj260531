# Conclusions（中文工作稿 · JCIM Articles）

## 5. 结论

仅以 Dual versus neither 评价双靶对接，可能掩盖模型无法排除单靶选择性配体的问题。EGFR/HER2 的设定差距在独立 GNINA 姿态生成和五个 Vina 种子中均保留，但其幅度未在其他靶对上复现。对接加入支架分组 ECFP4 后最多改变 0.020 AUROC，替代受体还使两个 PIK3CA 相关靶对发生方向相反的位移。

因此，双靶虚拟筛选应同时报告两条方向性选择性对照、配体层化学基线、分组或留出敏感性以及替代受体结果。当前四靶对分析识别了评价失败模式；鉴于四个主 `summary_min` 区间均跨越 0.5，且没有 BindingDB 靶对通过冻结的外部门槛，它尚不能建立靶标通用性能或外部迁移能力。
