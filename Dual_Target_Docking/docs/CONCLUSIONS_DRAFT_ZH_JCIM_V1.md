# Conclusions（中文工作稿 · JCIM Articles）

## 5. 结论

在保持对接评分不变的情况下，改变双端实验状态的比较方式即可改变对双靶对接性能的判断，而且这种影响在不同靶对和评价方向之间并不一致。因此，dual-versus-neither 与 dual-versus-A-only、dual-versus-B-only 所反映的并不是同一评价任务的简单难度差异，而是不同的双靶判别问题。

进一步分析显示，部分回顾性判别可以由不使用受体结构的配体化学信息获得。对应口袋比较未能提供跨靶对、跨留出集稳定的结构对应优势；受体结构替换使个别靶对的方向性 AUROC 明显变化；替代评分会改变具体数值，而独立对接分析表明评价设定带来的 dual-versus-selective 与 dual-versus-neither 差异可以在另一套姿态生成流程下再现。基于这些结果，对于回顾性双靶对接评价，两个选择性方向应分别报告，并结合仅配体基线和结构归因分析判断表观判别的来源。此类回顾性指标反映的是已知实验状态配体之间的判别能力，不能直接等同于前瞻性虚拟筛选中的候选发现能力。
