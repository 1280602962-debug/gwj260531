## 给合成同事：怎么用这 100 篇

1. 按列表从上到下打开链接（越新越靠前）。
2. 只留下同时满足的文章：
   - 明确做**双靶**（或双酶/双受体）小分子；
   - 文中有**两端活性数字**（IC50 / Ki / 抑制率等）；
   - 有可画的结构式。
3. 填进 `文献双靶金标准` 表（见数据收集说明）。
4. 标题备注为「降解剂/PROTAC类」的，先放到另一张表，不要和普通双靶抑制剂混用。
5. 目标仍是先认真登记 **30–80 个分子**；这 100 篇是候选池，不必篇篇都抄完。
