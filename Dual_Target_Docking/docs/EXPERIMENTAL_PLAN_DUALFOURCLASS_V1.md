# DualFourClass 后续实验总规划（v1）

> 约束：可大批对接；**无湿实验**。  
> 目标结果：相对普通双端对接融合（`vina_mean`），有一套**架构无关**的决策/评分协议，能更好区分 **dual vs A-only/B-only**，且增益在统计上可辩护。  
> 期刊预期：JCIM / J. Cheminform.（不做 NMI 默认）。  
> 日期：2026-07-28  
> 依据：failure typology v0、decision ablation 阴性、bootstrap CI、功效估算、架构/归因难点讨论。

---

## 0. 一句话产品

交付 **DualFourClass-Bench + Decision Protocol**：

- 多对公开靶、四类活性标签面板  
- 对接 → top-K → 重打分 →（可选）ML 决策头  
- 主评测架构无关；架构与端归因只做分层/诊断  
- 公开数据 + 协议 YAML + 带 CI 的排行榜  

**不是：** 新采样器、乘客/moiety 主线、湿实验命中故事。

---

## 1. 必须写进所有实验的两大难点

### D1 — 双靶架构种类多、难标注
- **主标签只用四类活性**（Dual / A_only / B_only / neither）。  
- 架构仅三分类粗分层：`compact_ATP` / `clear_linker` / `unknown`，允许大量 unknown。  
- 标 `literature_assigned` / `heuristic` / `unassigned`；**启发式不得作主结论过滤条件**。  
- 面板选取：同 Murcko 骨架配额上限（建议 ≤3–5），避免单一 chemotype 主导。

### D2 — 难归因“哪块结构影响哪个蛋白”
不做不可靠自动切片段。固定三级归因：

| 级别 | 内容 | 回答什么 |
|------|------|----------|
| L1 端水平 | 两端分数、短板端、特征消融（去 A 端/去 B 端） | 决策依赖哪一端分数 |
| L2 姿态分型 | hinge/占用/clash；T1/T2/T5 配额抽样 | 失败来自分数、姿态还是化学型交叉 |
| L3 近邻对照 | 同系列 A-only↔dual↔B-only 已有分子对照 | 结构微小差异如何改变两端表现 |

ML 强制消融：`分数 only` vs `分数+指纹`；若只有 +指纹才显著 → 报告 chemotype 捷径，不宣称归因成功。

## 2. 冻结指标与成功标准

### 主指标（所有阶段通用）
- AUROC：**Dual vs rest**（或 Dual vs A∪B，一对靶内预先选一种写死）  
- Top10：dual 数、A_only / B_only / hardneg 数  
- 不确定性：配对 ligand-bootstrap **95% CI**（B≥2000）  
- 主读数臂并列：`vina_mean` 与协议臂（`rtm_min_z` 或更优臂）

### 预冻结成功标准
| 关卡 | Go | No-Go |
|------|----|-------|
| **S1** EGFR 扩至 ~100–120 | `ΔAUROC(rtm_min_z − vina_mean)` CI 排除 0 | 不显著 → 不堆方法幻想；降 claim 或仅做基准发布 |
| **S2** ≥3 对靶 | 至少 2/3 对点估计正向；或 pooled 显著 | 全面无增益 → 收诊断文 |
| **S3** 方法层（GNINA/共识/ML） | held-out 对上优于 `vina_mean` **且**不低于裸 `rtm_min_z`（CI 可辩护） | 无增益 → 主文卖基准+分型，方法弱写 |
| **S4** 归因诚实 | 分数-only 仍有增益，或明确承认指纹捷径 | 不得隐瞒 |

### 明确不做
- 再调 shortfall/clash 刷小面板  
- warning flags / 架构标签进入 gated score  
- 无 leave-one-pair-out 的 ML 刷分  
- 宣称 C4 已闭环或可投 NMI

## 4. 阶段细则

### 阶段 0 — 冻结（文档，无对接）
- [x] 功效估算、CI、消融阴性、分型（已有）  
- [ ] 本文作为权威实验规划  
- [ ] 挂接：架构/归因检查清单进 SOP  

**产出：** 本文件；SOP 引用。

### 阶段 1 — EGFR 扩面板小赌（优先开工）
**目的：** 用最低成本验证“提升能否显著”。  

**动作：**
1. 按 panel40 同规则扩至 **N≈100–120**（补硬负；骨架配额；架构粗标可后置）。  
2. 协议不变：3POZ/3RCD，E=8，seed=20260727，n_modes=9，RTM best-of-9。  
3. 重算主指标 + 配对 bootstrap Δ CI。  
4. 端水平表 + 抽样 T2/T5 个案更新。  

**判定：** S1。  
**产出：** 扩展名单、分数表、`STAGE1_VERDICT.md`。

### 阶段 2 — 多对靶（对接可实现；无湿实验）
**目标规模：** 总 **6–8 对**。  

| 角色 | 建议 | 每对 N |
|------|------|--------|
| 锚定 | EGFR/HER2（扩后） | 100–120 |
| 弱/异质性对照 | PIK3CA/mTOR | 维持 ~48（不强制扩） |
| 易做补充 | PARP1/PARP2 或 CDK2/CDK9 等 | 80–120 |
| 异质加分 | AChE/BChE、Mcl-1/Bcl-xL 等 | 80–120 |

**每对固定流水线：**
结构冻结 → cognate QC（对特异 E）→ 四类面板 → 批量对接 → RTM → 指标+CI → 分型配额个案。

**架构/归因：** 每对至少完成 L1 全表 + L2 抽样；主指标不按架构过滤。  

**判定：** S2。  
**产出：** 多对靶总表、跨对靶森林图数据、分型库。

### 阶段 3 — 方法攻坚（抬 Δ；在足够 N 之后）
顺序固定，逐步加复杂度：

1. **第二引擎**（GNINA 优先）同面板重跑/重打分  
2. **多通道共识**（Vina / RTM / GNINA；深挖 rank 共识苗头）  
3. **端特异校准**（交叉验证，不按个案拧阈值）  
4. **姿态/相互作用门控**（PoseBusters 类；不拧 clash 打 T2）  
5. **轻量 ML 决策头**（仅当 ≥3 对靶）：  
   - 特征：两端 top-K 分数±姿态代理  
   - 验证：leave-one-pair-out  
   - 消融：分数 only vs +指纹  

**判定：** S3 + S4。  
**产出：** 方法消融表、held-out 对结论。

### 阶段 4 — 主动学习（配对接算力，不配湿实验）
在阶段 2/3 补样时启用：

- 冷启动每对 40–60 → 模型 → 查询（不确定 dual vs A-only + 硬负挖掘 + 骨架多样性）  
- **对照：** 同等对接预算的随机扩展  
- **指标：** 达到显著所需对接次数、最终 ΔAUROC  

**产出：** AL vs Random 曲线；写入基准构建 Methods。

### 阶段 5 — 打包与投稿
- 公开：面板、标签规则、构型、分数、脚本、CI 排行榜  
- 主文结构：任务定义 → 普通融合失败 → 协议/方法 → 跨对靶 CI → 失败分型与归因边界 → Limitations（无湿实验、架构 unknown、异质性）  
- 投：JCIM / J. Cheminform.
