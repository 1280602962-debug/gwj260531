## 2. 现在最需要干什么（只做这一枪）

### 目标
用 **最小、有共晶锚点的实验** 回答 Q1（附带触及 Q2/Q3）：

> 乘客项是否足够大，掩蔽后能否改善「假双靶」排序？

### 最小实验包（约：结构 QC + 小面板，不做全 ChEMBL）

1. **分子（宁少勿杂）**  
   - 必含：**TAK-285**（双端共晶）  
   - 再选 **5–10** 个文献明确双药效团 / 有 SAR 的 EGFR–HER2 dual  
   - 再选 **5–10** 个 **A-only**（两端都测；尽量挑「看起来不像双头」的紧凑单靶）  
   - 可选少量 B-only  

2. **协议**  
   - 受体：3POZ / 3RCD；引擎：Vina（固定盒子与种子）  
   - TAK-285 自对接 RMSD 过关后再往下  

3. **划分**  
   - 仅对有把握的分子做人+共晶/SAR 标注；切不清就丢掉  
   - 输出：`moiety_A / moiety_B / shared` + `S_whole / S_moiety / S_passenger`  

4. **读数（事先写死）**  
   - H1：A-only 弱端 `S_passenger` 不可忽略（相对 whole 有可见占比）  
   - H2：掩蔽后 A-only 弱端主分下降，强端仍在  
   - H3：`fuse_min_moiety` 相对 `fuse_mean_whole` 降低 A-only 进入 top 分位的比例  

### 决策树（实验后只许走一条）

| 结果 | 下一步 |
|------|--------|
| **Go**：H1–H3 成立 | 扩 EGFR/HER2 四类面板 → 第二对公开靶 → 再谈基准/投稿 |
| **弱**：乘客有信号但不稳 | 换异质靶对重做最小实验；暂缓 NMI |
| **No-Go**：乘客不显著 / moiety 无增益 | **停止包装乘客主线**；退回「校准+短板融合尺子」或诚实换题 |

**在此实验完成前：不写全文、不冲 NMI、不再开新叙事文档。**
