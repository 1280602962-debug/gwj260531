## 2. 为什么反复提问也没先看到「调查不完整」

这不是数字算错，是**抽样框被误读成宇宙**。

J0（2026-07-29）自己写得很清楚：

- 候选名单 52 对（含别名），当时两边都有 `mols_*.json` 的只有 **49**。
- ChEMBL REST 当时 HTTP 500，**只审计已缓存字典**。
- `j0_fetch_queue.csv` 另列 **20 个从未抓取的靶**（KDR、AXL、MERTK、BRAF/MEK、SRC/ABL1 等）。
- 结论句是：「49 对可审计对象里，严格硬负两端 ≥50 的只有 4 对」。

这句话**在 49 对这个框里是对的**。错误发生在后续把这句话用成：

> 公开数据里只有这几个够厚的双靶对 / 评价集已经代表 ChEMBL。

反复检查时，问题几乎都落在：

- 已对接四对的 AUROC、CI、图、负类定义；
- 是否胡编数字；
- 稿件措辞是否过强。

很少有人问：「49 对名单从哪来？API 挂了的 20 个靶后来补了吗？全库同样规则下有多少对？」  
只要不打开抽样框，J0 内部计数、Figure 1C 左柱、Table S44 都会显得自洽。dump 普查后才看到：同样数值门下厚对是 **86**，常规跨类最厚的是从未进 J0 的 **CREBBP/BRD4**（min HN = 270）。

同类盲区还会再出现，只要问题只打在「已经冻住的那一张表」上。下面第 6 节列出仍可能被同样方式漏掉的点。

## 4. 本次抽查：流程是否合理、有没有文献依据

### 4.1 标签与四状态（合理，且有依据）

- pChEMBL 作统一近似、max 聚合、θ = 6.0 主标签、严格 6.5/5.5 只用于供给门：与 J0 协议一致。
- 负类文献背景：DUD / DUD-E（物化匹配 decoy）、LIT-PCBA（实验非活性）、近期 TrueDecoy vs 随机 decoy 会改方法排序。方向性硬负（A-only / B-only）是对 Zhou 2013 双靶对接评价的加严，不是新打分函数。
- 未测 ≠ 无活性（完整病例 14.5%–34.0%）已写进局限。合理。

### 4.2 对接协议（行业常规，覆盖范围有限）

- AutoDock Vina 1.2.7、ETKDG+MMFF、Meeko、共晶定盒外扩 5 Å / 最短 20 Å、best-of-9 RMSD < 2 Å 作为**搜索覆盖**而非 top-1 验证：与常见 docking benchmark 做法一致。
- 未系统枚举质子化/互变异构/多种子构象、单一受体构象：必须作为局限，不是隐藏缺陷。F2/F10 质子化检查在计划里被明确推迟，未授权本期执行。
- exhaustiveness：仅 PIK3CA/mTOR = 16（共晶 QC 备用），其余主表面板 = 8。跨对比较混合了搜索设置，稿中应继续点名，不要说成统一生产设置。
- 4JT6 分辨率 3.60 Å：因更高分辨率 mTOR 结构多为 FRB/8PPZ 错误位点而保留。这是**有理由的例外**，不是漏检；审稿人仍可能质疑 ATP 位点模板质量。

### 4.3 新五对（先门后对接，合理）

顺序是：dump 普查 → G1–G5 → 身份审计 → 位点人工确认 → 共晶 RMSD → 生产 Vina。这正是 2WXF 事件后补上的协议。

- 新十个受体 Layer-2 文献/几何复核通过；Layer-3 八个普通新受体 best-of-9 PASS。
- CTSK/CTSS 可评但可逆共价，排除普通 Vina：正确。
- CREBBP/BRD4 最厚但 CREBBP 有 HAT + 溴结构域，未声明结构域，G5 失败：正确，不要看分后再塞回来。
- 五对 dump max 与面板 pChEMBL：**0/545 不一致**；holdout ID 与冻结面板 MATCH；JAK1/JAK2 实抽 20/20/18。

独立系统数是 **6 套蛋白系统、8 行靶对**（JAK1 共享、PPARA 共享），不是 8 个独立体系。主稿写「八个靶对案例、不平均」可以；不能写成八个独立重复。

### B. 方法句漏写（中；审稿人对照 PDB 会问）

1. **9V8H 是三元复合物**（PPARγ LBD + rosiglitazone + PG08-NL 肽）。对接计划要求保留肽、去掉水与 BRL，并在 Methods 写一句。当前中英文主稿只写 `9V8H / 6LXA（BRL / EPA）`，**没有肽/三元**。这不是打错蛋白，但比「普通二元 LBD」更特殊；7AWC 二元模板曾被考虑后拒绝。应补一句，否则 PPARG/PPARA 是唯一 CI 完全高于 0.5 的一对，口袋实现会先被质疑。
2. 新受体准备与原三对不完全相同（有的 `read_pdb` 已含氢，有的从 ATOM/TER 抽）。主稿对 AChE/BChE 写了，对 F2/JAK/PPAR 写得较粗。

### C. 已知开放技术债（低–中；已记录，不要当没看见）

2. CTSK/CTSS 共价配体准备文档内部仍有矛盾；该对未进 Vina，修协议需要书面修订。

### D. 科学边界（必须继续当局限，不要升级成「又发现造假」）

## 7. 实验流程对照（简表）

| 步骤 | 是否合理 | 参考文献/惯例 | 备注 |
