## 使用说明（给合成同事）

1. **优先抄**：设计类型为「连接型/杂合型」或「融合/拼合型」，且活性为「含具体浓度/IC50」的条目。  
2. **PROTAC/降解剂**：单独一张表，不要和普通双靶抑制剂混用。  
3. **「单个小分子…需看全文」**：打开全文看结构，再标 fused / linked / merged。  
4. 金标准仍建议先登记 **30–80 个分子**；本清单是高质量候选池。
