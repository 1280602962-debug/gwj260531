# Discussion · Limitations（中文工作稿片段）

> 位置：Discussion 末段或 Discussion 下 *Limitations* 小节（JCIM 常见）。  
> 仅列仓库可支撑的局限；不编造未做实验。与 Methods 2.1、2.5、2.6（2.6.7–2.6.9）、Results 3.2 / 3.4–3.11 交叉引用。

---

本文有若干局限需明确。第一，评价集仅含四对靶标，其中 EGFR/HER2 为供给受限案例而非严格厚面板；结论不得外推为“全部双靶对接任务”的通论。第二，活性标签取自 ChEMBL 的**最大** pChEMBL 聚合，存在 activity inflation：同一配体–靶标若跨 assay 波动，取最大会抬高表观活性并可能扩大 dual 类。冻结缓存未保留逐条 assay 的中位数、置信度或物种字段，因而**现有数据包无法**完成 max 对 median、confidence≥8 或 Homo sapiens 过滤的敏感性重算（`T0_SKIPS.md`）；该比较需重新拉取 assay 级记录后方可补做，本稿不虚构其结果。第三，面板建造时 AChE/BChE 与 PIK3CA/PIK3CB 用严格 6.5/5.5 规则、EGFR/HER2 与 PIK3CA/mTOR 用 θ = 6.0；为避免“不同对用不同阈值”的观感，正文 Table 2 已统一改用单一 θ = 6.0 规则报告全部四对（对前两对，θ = 6.0 与严格规则给出完全相同的分类与 AUROC，见 Table S4），更严格/更宽松的阈值网格仅作支持性敏感性分析，其中严格规则下 EGFR/HER2 与 PIK3CA/mTOR 的 B_only 过少，标记 underpowered。第四（面板构成层），现有配体/支架 bootstrap（B = 2000）描述的是固定面板内的不确定度；面板外 unused-pool holdout（Results 3.9；Table S8）已对三对靶标完成同协议对接验证，但仍共享同一 ChEMBL 抓取批次，不是跨数据库独立验证，且 AChE/BChE 与 PIK3CA/PIK3CB 在 holdout 上仍功效不足或不过基线。第五，RTMScore 取 Vina 九姿态最优，而 GNINA 仅对 mode 1 rescore，通道对照不对称，不能解释为三引擎公平赛马。第六，受体准备采用 meeko 默认路径，未另做 PDBFixer 补全或 Reduce 质子化枚举，组氨酸互变异构与辅因子处理边界见 Methods 2.4。第七，PIK3CA/mTOR 相对重原子数基线的优势在点估计上存在，但其 Δ 的 95% 置信区间仍包含 0，不足以支持“显著优于平凡描述符”的主张。第八，支架分组交叉验证中多数支架接近单例，对同系物泄漏的压制有限；二维指纹基线高 AUROC 表明标签与化学型相关，不能单独证明口袋物理特异性。第九，跨对结构决定因素分析（Results 3.6）所用的全链序列一致性是整体结构相似度的粗粒度代理，不是经结构叠合限定的口袋残基级 RMSD 或相互作用指纹（PLIF）相似度，也未做残基级口袋对应校验；该分析样本量仅 n = 4，为描述性对照，不支持正式相关性或显著性主张。第十，结构稳健性（Results 3.10；Table S9）显示：替代 PIK3CA 晶体（4JPS/5DXT）在通过 cognate QC 后仍使 PM48 summary_min 明显下降（受体依赖）；mTOR 换 4JSX 后点估计仍高于 0.5 但优势减弱——不能把 4L23/4JT6 上的信号宣传为结构不变。第十一，受体依赖的结构机制分析（Results 3.11；Table S10）表明这批 PIK3CA 沉积结构彼此的整链 Cα 差异明显大于这批 mTOR 沉积结构彼此的差异，与换晶体后的不对称方向一致，但 5DXT 的口袋局域 Cα 保守（0.343 Å）而 summary_min 仍崩溃，说明 Cα 层面的口袋几何不足以完全解释受体依赖；侧链构象、质子化或搜索空间等因素未获残基级或相互作用指纹证据，不作已解决主张。第十二，holdout 上三对均出现错口袋对照不低于口袋匹配，用不依赖打分函数的姿态几何量（`contact_count`）单独复现该模式（Results 3.9；Table S11），指向配体尺寸/埋藏程度混淆；但同一定义下主面板仍是口袋匹配明显高于错口袋（Table S6），二者的反差未获解释，如实报告为未解决的开放问题，不得选择性引用其中一侧掩盖另一侧。第十三，本研究为计算评测，未包含湿实验验证。
