# BindingDB article dumps used for the 7-uncertain-ligand pass

These files are **BindingDB article pages** (ChEMBL-curated enzyme-inhibition
hits for one publication), not publisher PDFs. DOI downloads of Folkes,
Elmenier, Bass, Ma, Sang, Cheng, Shi, and Yang resolved to BindingDB HTML
or a reCAPTCHA interstitial. They are kept here as the evidence that was
actually read on 2026-08-27.

Do not treat a review-article dump (Elmenier, Bass) as a primary measurement.
Trace those values to Folkes 2008 (see `Folkes_2008_JMC_BindingDB_entry2822.txt`).

The Cheng dump does not contain alpelisib / p70S6K; that frozen mTOR row
remains ChEMBL-metadata only until the publisher SI is available.
