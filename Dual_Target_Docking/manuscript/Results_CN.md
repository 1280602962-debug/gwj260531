# 结果

八对靶点按固定顺序编号：1 EGFR/HER2，2 JAK1/JAK2，3 JAK1/TYK2，4 PIK3CA/mTOR，5 AChE/BChE，6 F2/F10，7 PPARG/PPARA，8 PPARA/PPARD。方向任务中，D_vs_A 使用 B 端分数区分 dual 与 A_only，D_vs_B 使用 A 端分数区分 dual 与 B_only。summary_min 是这两个方向 AUROC 的较小值。

## R1. 八对靶点挑战集的标签构成

本研究评价的是实验标签构成的方向任务，不是天然化合物库的命中率。Table 1 给出八对的 A/B 靶点、冻结 PDB 和四类标签人数。合格且有类别的 pair 内观察共 805 条，其中 dual 234、A_only 238、B_only 232、neither 101。dual 可以进入两个方向，因此标签方向记录为 938 条，neither 不进入这两个任务。805 不是 805 个互不共享的小分子，跨靶点对可以共享配体实体。

807 行人群表在这 805 条之外，还保留 EGFR/HER2 的 EH120_059 和 AChE/BChE 的 AB_087 两条 activity_eligible=0、类别为空的记录；它们不是 neither。原 mapping 为 808 行，多出的一行是 AChE/BChE 的 AB_040，它是 AB_046 的 alias。阈值、合格性和 alias 规则见 Scheme 1 与补充方法。三层用途不同：938 条标签方向记录用于组成描述，934 条正式 M0 方向记录用于 PRIMARY，928 条共同折外记录用于化学模型和 chemistry-matched M0。每臂人数和缺失名单见 Table S2。

## R2. 双方向表现与评分工作流差异

Figure 1a 显示，M0 的两个方向并不对称。16 个方向点估计中，4 个低于 0.5，1 个恰为 0.5。EGFR/HER2 的 D_vs_A 为 0.6274，D_vs_B 为 0.2467，summary_min 因此为 0.2467。F2/F10 的两个方向都低，分别为 0.4082 和 0.3623，summary_min 为 0.3623。PIK3CA/mTOR 的 D_vs_B 点估计恰为 0.5000。这些是点估计与已有区间的报告，不是按点值宣布显著失败。JAK1/JAK2 的 summary_min 区间来自 summary_min 自身行，上界为 0.7246，不等于较弱臂 D_vs_A 的上界 0.7275。

Figure 1b 使用 PRIMARY 已有的四个配对差值，而不是把各方法自身人群的 AUROC 相减。M2−M0 的 summary_min 差值在 F2/F10 为 0.2471，95% 区间 0.0654 至 0.3896；在 PPARG/PPARA 为 −0.2915，区间 −0.4380 至 −0.1104。同一对照可以在不同靶点对上改变符号。M1b−M1 是同一保存姿势集合上的重排对照，并带有已计算的配对区间。它不同于后文仅作 supporting 的 M1b−M0 点估计和。M3−M0 比较的是独立对接工作流与 M0，不是单纯搜索算法效应。五方法的自身结果见 Table S3 和 Figure S4，配对差值见 Table S4。

## R3. 负类组成改变部分方向的判别难度

Figure 2 在同一 dual 集合上比较单靶负类和 neither。差值为 neither−single。16 个臂中 11 个点为正、5 个为负，14 个配对区间包含 0。EGFR/HER2 的 D_vs_B 为 0.5004，区间 0.3025 至 0.6819；JAK1/TYK2 的 D_vs_B 为 0.3839，区间 0.1953 至 0.5693。这两个方向上，neither 比单靶负类更容易与 dual 分开。其余方向保留正负和宽区间，不能据此说所有单靶负类都更难，也不能把含 0 的区间写成等效。

PIK3CA/mTOR 的 neither 在两个臂都是 4 人，区间很宽。完整人数和区间见 Table S5。

## R4. 化学标签可预测性与有限的 M0 增量

Figure 3 的三个化学模型和 chemistry-matched M0 使用同一第 3 层成员，共 928 条方向记录。ECFP4 的折外 AUROC 为 0.6633 至 0.9678，16 个臂都高于同成员 matched M0 的点估计。加入 M0 后的增量是 ECFP4+M0−ECFP4：11 个为负、4 个为正、1 个为 0，范围 -0.0238 至 0.0363。最大正点在 F2/F10 的 D_vs_B，零点在 PIK3CA/mTOR 的 D_vs_B。

化学模型在训练折上使用这些标签，M0 没有针对这些标签训练。二者的对照说明当前固定分折和模型下的可预测性与增量，不是同等训练条件的算法竞赛。Figure 3 没有区间，小的正增量不能写成稳定增益，小的负增量也不能写成显著损失。高 ECFP4 点估计也不说明已经找到来源偏差、数据泄漏或结合机制的原因。描述符和异类相似度只描述第 1 层组成，见 Figures S1–S2、Figure S3 和 Tables S7–S9。

## R5. 口袋对应提供的局部评分证据

Figure 4 在同一组成员上比较规定口袋和对侧口袋。D_vs_A 的正确口袋是 B，D_vs_B 的正确口袋是 A。差值为 correct−wrong。16 个臂中 11 个点为正、4 个为负，JAK1/JAK2 的 D_vs_A 恰为 0；14 个区间包含 0。AChE/BChE 的 D_vs_A 为 0.1659，区间 0.0548 至 0.2830；PPARA/PPARD 的 D_vs_A 为 0.2354，区间 0.0693 至 0.4043。

16 个臂的错口袋额外减员都是 0。AChE/BChE D_vs_A 的 A_only 从标签层 27 人到正式 M0 的 25 人，发生在进入口袋对照之前，原因是 M0 超时，不是对侧口袋再删人。该对照只描述冻结口袋指定下的评分差异，不证明结合机制、姿势正确性或关键残基。完整成员见 Table S6。

## R6. 种子与受体条件的敏感性

Figure 5a 只显示 summary_min 的五个种子。种子为 17、29、42、71 和 101，24 个汇总都有 5 个有限点。图中的竖线是已保存的最小值到最大值，标注的 IQR 是该指标自己的 linear P75−P25，不是置信区间。两个方向的完整结果在 Figure S5，汇总在 Tables S10–S11。

PIK3CA/mTOR 的 summary_min 为 0.4815 至 0.5833，IQR 为 0.0694。它的 auc_B IQR 是 0.0079，不能用来描述 summary_min。EGFR/HER2 的 summary_min 为 0.2305 至 0.2467，F2/F10 为 0.3594 至 0.3682；这两对的低表现没有因为更换种子而明显抬高。

除 AChE/BChE 外，七对的五种子有效人数不变。AChE/BChE 在 seed 17 的 A_only 为 24，其余种子为 25，因为 AB_046 在 BChE/4BDS 于 seed 17 超时。因此只有这一对的种子差异同时包含分数和成员变化。

替代受体只覆盖四对、八个条件，见 Figure 5b、Figure S6 和 Table S12。未替换端的八行差值都是计算得到的 0，只说明复制后只替换指定一端这一构造是一致的，不说明两个受体等效。受影响端有 7 个区间包含 0。PIK3CA/mTOR 的 ALT_4JT5 替换 B 端，受影响端差值为 0.1230，区间 0.0040 至 0.2659；summary_min 的点差值仍为 0，因为未替换的 A 端 0.5000 仍是较小值。该 summary_min 区间为 0 至 0.0952，不是零宽度。

## R7. 方向判别变化与联合名单组成可一致或背离

联合名单来自 dual、A_only 和 B_only 构成的挑战集。名次使用两端 average midrank 的 worst rank，k 为 ceil(0.10×N)。Figure 6 的每个面板使用该方法与 M0 自己的共同成员。横轴是已有 summary_min 差值，纵轴是 Top-k 中单靶占比的变化，图中以百分点显示。预期同时有利的方向是横轴为正、纵轴为负。

M2 在 F2/F10 的 summary_min 差值为 0.2471，共同 Top-10 的 dual 数由 4 增至 7。PPARA/PPARD 为 0.1582，dual 由 3 增至 6。PPARG/PPARA 为 −0.2915，dual 由 6 降至 4。这三对的方向差值和名单变化同向。PIK3CA/mTOR 的 summary_min 差值为 0.1032，但共同 Top-5 的 dual 数由 4 降至 3。方向判别提高并不保证名单中 dual 增多。k 较小的名单里，一个分子就会带来较大的比例变化。

四态按舍入前点值计数，顺序为一致改善、一致变差、不一致、无变化：M1 为 2/2/2/2，M1b 为 3/3/1/1，M2 为 4/3/1/0，M3 为 3/2/2/1。四种状态在全部比较中都出现，但 M2 没有无变化。无变化指两项差值至少有一项恰为 0，不是两项都不变。M1b 的横轴是三组成员核对后已有 PRIMARY 点估计之和，不另带区间。各比较的 N、k 和 dual 数见 Table 2；方法自身的 M0 名单和四态计数见 Figure S8 与 Table S17。这些比例描述构造挑战集，不是天然库命中率或独立验证。
