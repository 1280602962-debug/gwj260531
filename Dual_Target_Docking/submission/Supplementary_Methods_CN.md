# 补充方法与参数说明

## 1. 表格数据范围

正式标签使用两端未取整的最高合格 pChEMBL，阈值为 6.0。当前 867 条为靶点对层面的合格观察，不等于 867 个互不重复的全局分子。AB_040 为 AB_046 的别名，不独立计数；两条 activity_eligible=0 记录不属于 neither。Table S1 汇总构建记录与来源核查；完整成员和实验行见数据包。

来源核查支持标签与所用 ChEMBL 记录的一致性。855 条的全部标签决定型并列最大值具有 DOI、PubMed 或专利号，12 条缺少这些标识。跨文档聚合与测定终点差异可重叠。来源可追溯并不意味着所有读数来自相同实验条件。

## 2. 受体与对接区域

Table S2 从实际受体登记、准备清单及盒参数文件提取。正式结构共 14 个；JAK1 和 PPARA 各在两个靶点对中复用。当前受体敏感性结果仅含 AChE/BChE、F2/F10、PPARA/PPARD 的六种单端替换。

PDBFixer 1.12.0 用于已有残基缺失重原子处理，Meeko 0.7.1 用于受体 PDBQT。准备清单同时记录了观察片段模板、个别补加原子回退、PTR→TYR 处理及保留组分。表中链名采用 author chain ID；例如 JAK1 6N7A 保留 A、B 链，PPARG 9V8H 保留与登记一致的蛋白及肽组分。盒中心为共晶配体重原子坐标范围中点，各方向加 5 Å，最小边长 20 Å。

## 3. 生产配体与共晶重对接

生产配体的历史准备脚本使用 ETKDGv3、randomSeed=20260727、单次嵌入、最多 200 步 MMFF，以及 Meeko 0.7.1。既有配体沿用冻结 SDF/PDBQT；当前 101 个 Q110 配体的准备环境记录为 RDKit 2025.09.6。既有生产配体的方法记录与坐标重建证据范围见数据包中的 `08_ligand_preparation_report_CN.md`，不将重对接流程视为生产流程。

共晶重对接单独使用 20 个初始构象、ETKDGv3 seed 42、MMFF94s 优化并选择最低能量构象，必要时使用 UFF。Vina 对接种子为 17、29、42、71、101。RMSD 使用受体坐标系中的对称性感知重原子比较。Table S3 分别报告首位姿态和全部保存姿态中的最佳值，逐种子原始读数随包提供。

## 4. 对接与评分工作流

Vina 1.2.7 使用 vina 评分函数、exhaustiveness=16、num_modes=9、energy_range=6 kcal/mol、cpu=1。主要读数为 seed 42 的 mode 1，并取原始评分相反数。其他四个种子仅作敏感性分析，不挑选最佳种子。

GNINA 版本记录为 1.3.2 master:f23dd2b。固定姿态重评分使用 score_only、vina 经验评分与 CNNscore；S2 为 Vina mode 1，S4 为同次保存姿态中的最高 CNNscore。重评分坐标通过冻结 SDF 化学图及 Meeko 原子索引对应，不从空间距离猜测大环闭环。独立 GNINA 对接使用 seed 42、exhaustiveness=16、num_modes=9，以 CNNscore 排序，读取第一姿态。大环输入及原子映射的原始补充配置随包提供。

RTMScore 使用 `rtmscore_model1.pth`，固定 Vina mode 1，口袋截取距离为 10 Å，不进行模型集成。冻结环境记录为 Python 3.10.20、PyTorch 2.6.0。不同计算阶段环境分别记录，不将某个分析环境版本推定为全部历史准备环境版本。

## 5. 统计、人群与联合排序

方向性指标、置信区间、方法差值均从已验收结果复制。bootstrap 为 10,000 次、NumPy default_rng seed 271828，每个单元重置；dual 与两类单靶配体分层抽样，两个方向共用 dual 抽样。summary_min 在每次重采样中取较小方向。方法比较保留同一成员的配对关系，不通过两个独立区间是否重叠判断差异。

化学模型使用八项描述符、ECFP4 或 ECFP4＋Vina；指纹为 radius 2、2048 bit、useChirality=False、useFeatures=False。逻辑回归采用 L2、C=1、liblinear、max_iter=1000，缩放参数只在训练折拟合。既有固定五折分配和 Q110 的规范骨架排序循环分配均按当前文件保留。本次表格整理不拟合模型。

联合排名取两个靶点名次的较大值。单靶并列使用平均名次，联合并列按名次之和、全局分子 ID 排序，k=ceil(0.10N)。方法自身组成与相对 Vina 的共同成员比较分别展示。S4−S1 仅为支持性方向点估计，不新增置信区间；完整来源和成员关系随数据包保留。

## 6. CAP5 与严格子集

CAP5 在正式评价集固定后开展。pair×class 内同一非空 Murcko 骨架最多保留 5 个，4 条无环观察不受该上限约束，超额成员按预先固定且不读取评分的规则选择，不回补。867 条中保留 861 条、排除 6 条；化学模型沿用原折重新训练的已验收输出全部保留。CAP5 未重算五种子或替代受体结果。
