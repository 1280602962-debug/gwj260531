| 结果部分 | 核对结论 | 需要注意的呈现范围 |
| --- | --- | --- |
| 3.1 | 867 条观察、845 个全局配体实体、248/256/252/111 类别人数均一致；1004/1000/994 层级一致 | 靶点对观察与不同分子实体分别计数 |
| 3.2 | S1 的 16 个方向、summary_min 及文中列举的评分方法差值与区间一致 | summary_min 区间与每个方向的区间是不同的统计量；方法差来自各自共同成员 |

## 2. 建议修改的具体句子

| 位置 | 当前句子或措辞 | 判断及建议 |
| --- | --- | --- |
| 3.1 第 3 段 | “聚合活性值及四状态标签与冻结评价集一致” | 数值正确。投稿文字可写“聚合活性值及四状态标签与评价集一致”，去掉工作流程用语“冻结” |
| 3.1 第 3 段 | “855 条观察具有完整的指定文献标识” | “指定”不便于读者理解。可写“855 条观察的文献标识完整”，由 Table S1B 表注明确 DOI、PubMed 或专利标识及并列最大值规则 |
| 3.1 第 3 段 | “表明评价集包含不同来源及测量条件的实验记录” | 已直接核对的是文献来源和测定终点，并非所有具体实验条件。建议改为“评价集的文献来源与测定终点并不完全一致” |
| 3.1 末尾或 3.2 开头 | 没有报告 Methods 中的共晶重对接结果 | 建议增加 1–2 句并引 Table S3、Figure S1：70 个种子任务中，首位姿态有 42 个 RMSD <2 Å，保存姿态中最佳值有 66 个 <2 Å。8 个受体在五种子下首位姿态均达标，13 个受体在每个种子中均至少保存一个达标姿态；HER2 仅 1/5 种子满足后一标准。不能把这些结果概括为全部受体首位姿态均得到验证 |
| 3.2 第 3 段 | “不同靶点对均未表现出一致且具有明确区间支持的正向判别优势” | 可更直接写“八对靶点中，没有一对的 summary_min 95% 区间下限高于 0.5”。不将区间包含 0.5 写成等效或无效的证明 |
| 3.4 第 1、末段 | “冻结的交叉验证划分”“冻结模型设置” | 可写“固定的交叉验证划分”“预设模型设置”。保持本段对当前数据及当前划分的适用范围，不扩大为外部泛化结论 |
| 3.5 全节 | “规定口袋” | 统一替换为“对应口袋”，与 Methods、Table S6B 及新 Figure 6 一致 |
| 3.6 第 3 段 | “ECFP4 模型在全部 16 个方向上的折外 AUROC 变化均小于 0.02” | 数值成立；建议明确为“绝对变化均小于 0.02”。实际最大绝对变化为 0.01059065194 |
| 3.6 第 3 段 | “加入 Vina 评分后的增量也未出现新的明确优势（Table S9A,B）” | 当前 S9A、B 只含人数和 Vina 汇总，不能直接支持化学模型结论。已新增 Table S9D。建议改为“CAP5 下加入 Vina 后的 AUROC 增量范围仍为 −0.0164 至 0.0363（Table S9D）”；这些仍是点估计 |
| 3.6 CAP5 段后 | 未提及 PPARA/PPARD S5 的方向性区间变化 | 建议补一句：“PPARA/PPARD 的 S5 在 dual 与 A-only 比较中，95% 区间由 0.4922–0.7676 变为 0.5030–0.7772（Figure S8）。”这是一处区间边界变化，不自动解释为经多重比较调整后的显著改善 |
| 3.6 第 4 段 | “原 Q110 评价集” | 可统一写“110 分子评价集”；这只是当前评价集内部的严格子集比较，无须叙述历史扩展过程 |
| 3.7 第 2、4 段 | “同向变化”“共同下降” | 容易与原始纵轴的单靶占比方向混淆。建议统一写“一致改善”“一致变差”，其定义沿用 Methods |

summary_min 的说明：F2/F10 的 summary_min 区间上限为 0.4805，但其两个方向 AUROC 的区间上限分别为 0.5557、0.5049。因此，“summary_min 的区间低于 0.5”不能直接改写为“两个方向均显著低于 0.5”。本次保留既有区间，不另做检验或重算 bootstrap。

## 5. 图像技术规格与核对范围

全部新图由 Matplotlib 脚本绘制，未使用图像生成工具。每张提供可缩放 PDF、可编辑 SVG 和 600 dpi PNG。宽度为 7 in，采用可稳定嵌入的 DejaVu Sans TrueType 字体，最小可见文字 7.5 pt；参考线和数据线采用至少 0.5 pt 的设置。颜色同时配合点形、文字或纹理，不单靠红绿区分。

按 2026-10-27 查阅的 JCIM 作者指南 Appendix 2：彩色图至少 300 dpi；双栏宽度 300–504 pt；图及图注总深度最多 660 pt；最终文字不得小于 4.5 pt，线不得细于 0.5 pt。新图宽 504 pt，单图高度最高 532.8 pt，余量用于图注。最终排版仍应以 7 in 原生宽度放置，并结合实际图注确认总深度，不宜再大幅缩小。

官方来源：https://researcher-resources.acs.org/publish/author_guidelines?coden=jcisd8 （Appendix 2）。矢量文件、真实尺寸及文字/图例布局均需一起检查，不能只凭 PNG 的 dpi 判断可发表性。
