**图 1** 评价集的活性类别与实验活性记录覆盖情况。a，各靶点对中 dual、A-only、B-only 和 neither 的观察数。b，两端均有活性记录、文献标识完整、来源或终点混合及重复测量跨越阈值的观察数；颜色表示其在对应靶点对中的比例。各项标记可重叠。完整文献标识要求两端所有并列最大活性记录均具有 DOI、PubMed 或专利号。867 条靶点对–配体观察涉及 845 个不同配体实体

**图 2** Vina 的方向性判别与最小方向 AUROC。点和横线分别表示估计值及 95% 分层 bootstrap 置信区间。a，dual 与 A-only 使用靶点 B 评分，dual 与 B-only 使用靶点 A 评分。b，最小方向 AUROC；每次重采样均在两个方向中重新取较小值。虚线为 AUROC = 0.5 的参考线。最小值的区间不能解释为两个方向均高于或均低于 0.5

**图 3** 评分工作流之间最小方向 AUROC 的配对差值。a，S2−S1；b，S3−S1；c，S4−S2；d，S5−S1。每项比较使用其共同有效成员，横线表示 95% 配对 bootstrap 置信区间。S4−S2 评价保存姿态的 CNNscore 重排序，S5−S1 比较独立对接工作流

**图 4** 负类组成对 AUROC 的影响。a，使用单靶选择性配体或 neither 作为负类时的 AUROC；同一比较中保持 dual 成员和评分靶点不变。b，neither 负类减去单靶负类的 AUROC 差值及 95% bootstrap 置信区间。两种负类分别重采样，并共用 dual 的重采样。A-only 行使用靶点 B 评分，B-only 行使用靶点 A 评分；评分均为 Vina S1

**图 5** 配体化学模型与 Vina 的判别表现。a，理化描述符、ECFP4、ECFP4 + S1 与直接 Vina S1 评分在相同成员上的 AUROC；三个学习模型使用五折折外预测。b，AUROC(ECFP4 + S1)−AUROC(ECFP4)。图中仅显示估计值，化学模型比较未计算置信区间。dual 为正类；A-only 和 B-only 行分别对应靶点 B 和 A 的评分

**图 6** 对应与非对应口袋的比较。a，同一成员使用两种口袋评分所得的 AUROC。b，对应口袋减去非对应口袋的 AUROC 差值及 95% 配对 bootstrap 置信区间。A-only 行的对应靶点为 B，B-only 行为 A；评分均为 Vina S1

**图 7** 搜索随机种子与受体结构的敏感性。a，五个随机种子的 Vina 最小方向 AUROC；短横线表示最小至最大范围，黑色竖线表示中位数，该范围并非置信区间。各随机种子使用其有效成员；AChE/BChE 的种子 17 比种子 42 少一个 A-only 配体。b，六次单端受体替换中，受影响方向 AUROC 与最小方向 AUROC 的配对变化及 95% 置信区间；括号表示被替换的 A 或 B 端
